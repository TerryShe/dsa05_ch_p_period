# 异步周期业务下的上行子信道与功率分布式控制：场景规范 v1.0

本文是 dsa05 的通信场景依据。**v1.0 已于 2026-09-24 经用户确认冻结**：§8 的数值参数与三条建模假设（互信息反馈、默认参数、只计发射能耗且 SNR gap 为 0）构成研究工作点。工作点包括 N=4/6/8/12 四个变体，除 UE 数和各业务类的 UE 分配外完全相同，配置为 [`configs/scenario-v1-n{4,6,8,12}.toml`](../../configs/)。哈希与派生量见[冻结清单](scenario-v1-freeze.json)，由 `tests/test_frozen_scenario.py` 守护。任何参数或语义变化都应另立新版本和新配置文件，不在原文件上修改。v1.0 的语义实现与 v0.1 相同（提交 `f38457c`）。

## 1. 研究问题

圆形小区中心有一个 AP，N 个 UE 共享 K 个正交子信道，做上行传输。UE 周期性产生小包，各 UE 的到达相位互不对齐；每个包必须在本 UE 的下一次到达之前完整交付，否则丢弃。

每个时隙，每个 UE 只依据本地因果信息，自主选择**（子信道，发射功率）或 OFF**。**MCS 不再是动作**：速率由实际 SINR 按 Shannon 公式确定（见 §3.3）。

优化目标：**在每个 UE 的截止期违约率不超过 ε 的约束下，最小化平均发射能耗**（见 §6）。

## 2. 与 dsa04 的关系

| 项目 | dsa04 第一阶段 | dsa05 v1.0 |
|---|---|---|
| 动作 | 子信道 × 功率 × MCS | 子信道 × 功率 |
| 速率 | 离散 MCS，按 SINR 门限判 ACK/NACK | Shannon 互信息 τB·log₂(1+SINR)，HARQ-IR 累积 |
| 业务 | 起点一次性有限业务 | 异构周期、异步相位的小包，截止期＝下次到达，逾期丢弃 |
| 目标 | 最短全网完成时间 | 每 UE 违约率 ≤ ε 约束下最小化能耗 |
| 结束条件 | 全网业务清空 | 连续运行至技术时域 H |

几项继承关系：
- 拓扑模块直接复制自 dsa04 的 `topology.py`，行为不变。
- 截止期语义沿用 dsa04 `research/stage2-async-periodic` 分支中已确认的定义：槽边界的处理顺序、逾期丢弃、按截止期划定评价窗口。
- 选择去掉 MCS 的依据：dsa04 的 EXP-DCA-037 中，三种 Full 模型在长训后都完全放弃了 6 Mbps，选档学习没有成功；而逐 UE 固定 MCS 的条件明显更好。

## 3. 系统模型

### 3.1 拓扑与路损

UE 位置按面积在半径为 X 的圆盘内均匀采样：r=X√U，φ=2πV。一个实例内位置固定。路损为 g_i = 10^(−PL_ref/10)·[max(d_i,d_ref)/d_ref]^(−α)。拓扑记录保存坐标、增益及其 SHA-256，重放时只使用保存的数组。

### 3.2 信道接口

物理内核只接收 (N,K) 线性增益矩阵 g_{i,k}(t)，由 `ChannelModel.gains(slot)` 提供。
- v1.0 使用 `StaticChannel`：时不变、频率平坦，g_{i,k}=g_i。因此各子信道对同一 UE 是对称的，选择子信道只有避让干扰的作用。
- 后续的衰落模型（块瑞利、Gauss–Markov 频率选择性衰落等）实现同一个接口，并持有独立于拓扑和业务的随机流。内核与环境都不需要改动。

### 3.3 接收与服务量

各 UE 每个时隙只占用一个子信道，接收端把干扰当作噪声，没有 SIC：

SINR_i(t) = p_i g_{i,c_i} / (σ² + Σ_{j≠i, c_j=c_i} p_j g_{j,c_i})，其中 σ² = N₀ + 10lgB + NF（dBm）。

本时隙的服务量为互信息 S_i(t) = τB·log₂(1+SINR_i(t))。

**物理解释：HARQ-IR（无速率码）累积互信息模型。** UE 发送之前不需要知道 SINR；包的各次传输所累积的互信息达到包长 L 时即可解码。因此不再有"本时隙失败"的概念，取而代之的是"进度不足"。发送功率不为零的 UE 在整个时隙内都对同信道其他 UE 构成干扰。

v1.0 使用信息论上限，**SNR gap Γ=0 dB（已确认）**。实际编码的损失可在后续版本中以 Γ>0 表示。

### 3.4 能耗

E_i(t) = τ·p_i(t)。OFF 为严格 0 W。**v1.0 只计发射能耗，不计电路功耗（已确认）。**因此，单个 UE 把传输拉长、用较低功率发送，总会更省能耗；这种倾向只受截止期约束和同信道干扰制约。

## 4. 业务模型

### 4.1 周期与相位

UE 分属若干业务类，每类有周期 P（时隙数）和包长 L（bit）。UE 按配置中类的顺序依次分配；由于位置是 i.i.d. 的，这样分配并不会把某一类绑定到特定位置。

- 相位 φ_i 独立地取自 Uniform{0,…,P_i−1}，由独立的 `phase_seed` 控制；一个实例内固定，允许不同 UE 相位重合。
- 第 n 个包的到达时间 a_{i,n}=φ_i+nP_i，截止期 d_{i,n}=a_{i,n}+P_i，也就是下一次到达。
- "异步"只指到达相位不同；物理时隙是同步的。

### 4.2 槽边界的时序

时隙 t 占据 [t,t+1)。在边界 t+1 上依次执行：

1. 结算时隙 t 的服务量。若某个包的累积互信息达到包长，则该包完成，完成时刻 C=t+1。
2. 结算所有 d=t+1 的包：已完成的记为按期；未完成的记一次违约，剩余比特丢弃。
3. 释放所有 a=t+1 的新包。
4. 生成下一轮观测。

由此可得：
- 每个 UE 最多只有一个未完成的包；
- 没有待发包的 UE 被强制 OFF，等待下一次到达；
- 全网暂时空闲并不结束运行，只有技术时域 H 会截断；
- 每个已结算的包满足"累积交付＋丢弃＝包长"。

## 5. 动作与信息边界

**动作**：OFF，或（子信道 c，功率档 l≥1）。联合动作数为 1+K(L_p−1)，v1.0 为 1+4×5=21。功率档 0 是 OFF；数值 0 dBm 会是 1 mW 的有效发射，不是 OFF（v1.0 菜单不含 0 dBm）。

**Actor 可见的本地观测**（`UEObservation`）：

| 字段 | 含义 |
|---|---|
| `remaining_bits` | 当前包剩余的比特数（空闲时为 0） |
| `packet_bits`、`period_slots` | 本 UE 的业务参数，由本地业务源得知 |
| `slots_to_deadline` | 距本 UE 下一次到达的时隙数：有包时是当前包的剩余截止时间，空闲时是等待时长 |
| `previous_action` | 自己上一时隙的（子信道，功率档） |
| `previous_outcome` | NO_FEEDBACK / NO_TX / TX / DECODED |
| `previous_service_bits` | AP 回传的本 UE 上次传输的互信息 |
| `previous_rssi_w` | 上一时隙各子信道的公共 RSSI（含噪声） |

Actor 看不到 UE ID、全局时钟、其他 UE 的队列、相位或动作，也看不到拓扑。

**反馈假设（已确认）**：AP 每个时隙回传本 UE 的互信息，性质上相当于 CQI 或进度反馈。v1.0 回传精确浮点值，不做量化。UE 由这项反馈、自己已知的功率和公共 RSSI，可以推出自己的路径增益和各子信道的干扰水平（见 `baselines.estimate_link`）。这属于合法的本地信息。如果要收紧信息边界，可以去掉 `previous_service_bits`，形成只有 DECODED 反馈的变体。

**Critic**：仅在集中训练时使用，可以看到全局业务状态、增益和相位。

## 6. 优化目标

目标写成约束问题：

min_π  (1/(N·T)) E[Σ_t Σ_i E_i(t)]    s.t.  对每个 UE i，违约率 V_i ≤ ε

v1.0 冻结 ε=0.05，由配置中的 `[objective]` 字段记录。

环境**不计算奖励**，每个时隙只返回逐 UE 的能耗 `tx_energy_j`，以及本边界结算的按期数 `on_time` 和违约数 `violations`。训练器据此构造奖励（负能耗）和代价（违约），比如 Lagrangian MAPPO 或其他约束 MARL 方法。

采用逐 UE 约束而不是全网平均约束，是为了防止策略长期牺牲少数远端 UE。它需要逐 UE 的乘子或类似机制，这可以作为算法贡献的切入点。

## 7. 评价口径

- 预热 W ≥ 最大周期，时域为 H。
- 评价集合是 **W < d ≤ H 的全部包**。这个集合由到达表决定，与策略无关。截止期在 H 之后的包属于右删失，不计入。
- 能耗统计时隙 [W,H) 内的全部发射。

报告至少包括：
- 按期完成率 OCR；
- 最差 UE 的 OCR，以及各业务类的 OCR；
- 每 UE 平均发射功率；
- 每个按期包的能耗；
- 成功包的时延（均值和 P95）；
- 丢弃的比特数。

实现见 `metrics.window_summary`。

## 8. 冻结参数

四个配置 `configs/scenario-v1-n{4,6,8,12}.toml`（各自的 SHA-256 见冻结清单）。拓扑和相位的基础种子也在其中；实例 i 使用 `topology_seed+i` 与 `phase_seed+i`。训练、验证、测试各用哪些实例编号，由各实验协议另行冻结，不属于场景参数。

| 项目 | 取值 |
|---|---|
| K | 4 |
| 时隙 τ / 子信道带宽 B | 1 ms / 1 MHz |
| 噪声 | −174 dBm/Hz，NF 7 dB（σ² = −107 dBm） |
| 圆盘 / 路损 | 半径 100 m；1 m 处 40 dB；α=4 |
| 功率档 | OFF, 5, 10, 15, 19, 23 dBm（21 类联合动作） |
| 业务类 | fast：10 slots / 6144 bit；medium：20 / 12288；slow：40 / 24576 |
| 运行 | H=2000，W=200（评价 1800 时隙） |
| 约束 | ε=0.05（逐 UE） |

三类业务每 UE 的平均负载都是 614.4 bit/slot，因此总负载只随 N 变化。UE 按 fast/medium/slow 轮流分配：

| N | fast / medium / slow | 总负载 |
|---|---|---|
| 4 | 2 / 1 / 1 | 2.46 Mbit/s |
| 6 | 2 / 2 / 2 | 3.69 Mbit/s |
| 8 | 3 / 3 / 2 | 4.92 Mbit/s |
| 12 | 4 / 4 / 4 | 7.37 Mbit/s |

N=4 时 UE 数不超过子信道数，每个 UE 都可以独占一个子信道，没有竞争，可作为规模分析的轻载端和中央参照的核对点。

### 8.1 选定依据

**包长**：包长由 N=12 下的启发式包长扫描选定（2026-09-24，当时的菜单为 OFF/0/5/10/15/20/23 dBm，每档 4–8 个实例）。选定的是这样一个负载点：最高功率接入仍能满足 ε=5%，而本地降功率会使最差 UE 失约。表中包长倍数相对于 2048/4096/8192 bit，3× 即现值：

| 包长倍数 | random_max OCR / 最差 UE | sticky_max | lazy_pacing | 功率 mW/UE（random / lazy） |
|---|---|---|---|---|
| 1× | 1.000 / 1.000 | 1.000 / 1.000 | 1.000 / 0.994 | 17.9 / 13.3 |
| 3×（现值） | 0.999 / 0.995 | 0.998 / 0.990 | 0.854 / 0.565 | 46.1 / 43.4 |
| 4× | 0.944 / 0.857 | 0.975 / 0.906 | 0.636 / 0.049 | 82.0 / 62.3 |
| 5× | 0.734 / 0.298 | 0.844 / 0.625 | 0.490 / 0.000 | 128.6 / 65.7 |

**功率档**：用户提议 OFF/5/10/15/23，最终在其中加入 19 dBm。依据是 [`scripts/analyze_power_menu_quantization.py`](../../scripts/analyze_power_menu_quantization.py) 的理想化分析：无干扰，每 UE 在其周期内最多可用 P（N≤K）或 ⌊PK/N⌋（N>K）个时隙，计算离散菜单最小能耗与连续功率最小能耗之比（越接近 1 越好）：

| 功率档（dBm） | 动作数 | N=4 | N=6 | N=8 | N=12 |
|---|---|---|---|---|---|
| 0,5,10,15,20,23 | 25 | 1.167 | 1.318 | 1.302 | 1.548 |
| 5,10,15,23 | 17 | 1.195 | 1.334 | 1.314 | 2.115 |
| **5,10,15,19,23** | **21** | 1.195 | 1.334 | 1.314 | **1.435** |
| 6,12,18,23 | 17 | 1.285 | 1.362 | 1.520 | 1.458 |

去掉 0 dBm 只让 N=4 的能耗比增加约 2.4%（1.167→1.195）。15→23 dBm 之间 8 dB 的空档在 N≤8 时无影响，但 N=12 时远端 UE 所需功率落入其中，会被迫用 23 dBm。加入 19 dBm 后，N=12 的损失降到四种菜单中最低，其余 N 与 4 档菜单持平。比值的一部分来自时隙数必须取整，不全是功率量化造成的。

**冻结菜单下的启发式参照**（非正式，每个 N 8 个实例，`policy_seed` 1）：

| N | random_max OCR / 最差 UE / mW | sticky_max | lazy_pacing OCR / 最差 UE / mW |
|---|---|---|---|
| 4 | 1.000 / 1.000 / 30.4 | 1.000 / 1.000 / 32.6 | 0.996 / 0.964 / 17.5 |
| 6 | 1.000 / 1.000 / 30.8 | 1.000 / 1.000 / 33.2 | 0.996 / 0.972 / 17.2 |
| 8 | 1.000 / 1.000 / 34.6 | 0.999 / 0.998 / 38.3 | 0.989 / 0.951 / 21.4 |
| 12 | 0.999 / 0.995 / 46.1 | 0.998 / 0.990 / 53.0 | 0.857 / 0.549 / 42.4 |

- N≤8 时，本地降功率能省约 40–45% 的能耗，最差 UE 刚好落在 ε=5% 的边缘。
- N=12 时，降功率带来的并发干扰使最差 UE 的 OCR 跌到约 0.55，最高功率接入虽满足约束但很耗能。

"满足约束"与"节能"之间的张力随 N 增大而加剧，这就是本场景的研究对象。上述数字只是集成检查，不是研究证据。

## 9. 开放问题与下一步

1. **中央参照**：N≤K（N=4）已完成精确最优，见[报告](../results/central-reference-n4_20260924/report.md)。N>K 仍需要在给定到达表和 TIN 干扰下，求能耗最小化（带截止期约束）的下界或可行解。这是非凸问题，可以考虑按超周期建立混合整数模型，或用 SCA 做松弛。它决定了 MARL 与最优之间的差距能否量化，论文必需。
2. **衰落扩展**：实现块瑞利或频率选择性的 `ChannelModel`，并决定 UE 是否掌握本地 CSI。
3. **训练适配**：
   - 特征编码，例如 remaining/L、slots_to_deadline/P；
   - 约束 MARL 的奖励和代价通道；
   - 把 dsa04 的 CSG Actor 移植到 25 类动作；
   - 跨周期保留 GRU 记忆。
4. **基线**：本地启发式之外，还需要文献中的强基线，例如带功率爬升的多信道 ALOHA、截止期感知的随机接入，以及 IPPO/MAPPO 和约束 MARL 方法。
5. **规模与泛化**：N=4/6/8/12 已是 v1.0 的冻结变体；训练外的拓扑与相位属于 v1.0 内的测试；其他负载或 N 值会改变参数，应另行登记为新变体。

v1.0 明确不包含、留给以后版本的内容：SNR gap Γ>0、互信息反馈量化、电路功耗、衰落信道。
