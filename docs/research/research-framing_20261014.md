# DSA05 研究框架（第 4 版）：面向生存时间要求的分布式保护协调与关键状态训练

状态：**第 4 版修订草案**。2026-10-14 按用户指示统一核心主张、对照判据与依据；后续实验设计和确认协议的落实见 §7–§9。

本文件是研究框架（实验记录），规定研究目标、问题、贡献假设、指标与比较对象，供实验设计与协议修订使用。论文的表述在写作时另行决定，不直接取自本文件。

## 0. 修订说明

**为什么改**：

1. **第 3 版的核心表述没有得到足够的支持**（RES-DSA05-EXP011B，开发阶段）：
   - 加一层 L1 摘要并据此协调，最差 UE 违约率（P2）显著降低（U 对 M，N = 8–12 上低 23–28%，五个种子方向一致）；
   - 未检出紧迫内容相对占用内容或学习消息的独立优势；这不是等效性证据。学习响应也未显示相对手写规则的优势，M+Y 在 N = 12 上显著优于 U。
2. **研究目标改为"用 RL 解决一个实际的工程问题"**（2026-10-14 用户确定）。问题分析可以支撑方法，但不作为主要贡献。
3. **找到了一个具体的工程需求，并有数据支持它在本场景中是非平凡的**：
   - 工业时间敏感通信的生存时间要求（3GPP TS 22.104）；
   - 逐包重放显示违约明显成串出现；集中式参照提示存在改善空间。现有方法虽降低了部分条件违约风险，但连续失败仍明显存在，原训练目标未显式控制服务中断（RES-DSA05-SURVIVAL-CHECK）。
4. **场景先修订为 v2.1**（最小 UE–AP 距离 10 m，2026-10-14 冻结）。主场景保持周期业务（2026-10-14 用户决定）。

**与第 3 版的关系**：

| 第 3 版 | 第 4 版 |
|---|---|
| 核心：紧迫状态摘要驱动的协调 | 核心：面向生存时间要求的分布式保护协调，关键状态训练作为支撑机制 |
| 首要指标：P2（最差 UE 违约率） | 首要指标：最差 UE 的不可用度；P2 改为非劣检验指标 |
| L1 摘要的内容：紧迫（slack < 3） | L1 摘要保留链路与接收模型，内容改为"处于生存时间状态" |
| 场景 v2.0 | 场景 v2.1 |
| 主要实验：EXP-011、EXP-011b、EXP-012（XR-SBPC 改编） | 主要实验：EXP-012（新编号，生存时间）；外部学习对照按问题相关性选定（§6） |

- 第 3 版的实验结果（EXP-006 至 EXP-011b）数值与原判据的判定保持不变，作为 v2.0 上的开发阶段依据；本版收敛超出证据的解释，不把旧结果改写为新假设的验证。
- 首要指标是在读过开发数据（EXP-011b 的评估集与逐包重放）之后改的。正式结论只来自修订后的协议下对确认集的一次读取（§8）。
- **本次修订的边界**：本框架规定后续研究的主张和验证要求；不追溯改变 EXP-012 第 2 版已批准的先导门槛、训练设置和结果判定。新增对照及确认判据须按 §7 登记后实施。

## 1. 研究目标

**核心表述（第 4 版）**：面向具有生存时间要求的工业周期上行，研究干扰耦合下的分布式保护协调。设备利用本地生存状态与低开销公共广播，自主选择子信道、功率与发送时机；关键状态训练用于改善策略学习。研究目标是在相对 M+S 的预设可靠性非劣界限内，获得比开发阶段选定并冻结的强规则对照更低的最差设备不可用度，并通过目标匹配的学习对照、消融与行为诊断，检验协调和训练机制的增量价值。

- **工程问题**：生存时间（TS 22.104）。设备的传输间隔即业务周期；连续违约超过生存时间，服务中断，直到下一个包送达。
- **对象**：工业周期上行，共享 K 个子信道（类比共享或超配的配置授权资源），衰落、TIN 干扰、HARQ-IR 跨时隙累积（场景 v2.1）。
- **方法的角色**：学习策略在设备上分布式执行，使用本地观测与 AP 每时隙广播的 K 比特摘要；不是无公共反馈的纯本地策略。
- **成败**：在确认集上同时通过对冻结主对照 B\* 的不可用度优势检验，以及相对 M+S 的可靠性非劣检验（§5.4）。B\* 仅指 §6 固定规则集合中的开发阶段整体优胜者，不代表所有现有方法中或每个负载下的最优方法。
- **主张边界**：非劣容许的相对退化界限为 10%，不等于零损失；本框架不承诺硬生存时间约束保证，也不以当前功率保护规则的结果推断优于标准 PDCP 复制。

## 2. 要解决的困难

| 困难 | 在本问题中的体现 | 依据 |
|---|---|---|
| 违约成串，且与衰落相关 | 一次违约后，下一个包违约的概率为 10–15%，平均违约率只有 0.016–0.10%；相邻违约对是"每个 UE 违约数不变、位置随机"参照的 4–14 倍 | RES-DSA05-SURVIVAL-CHECK（v2.0，已读切片） |
| 多设备保护可能相互冲突 | 一个设备加强发送或占用更好的子信道，可能提高其他设备的失败风险；需要检验协同保护是否优于各自保护 | 干扰耦合的场景结构；旧紧迫摘要的诊断提供动机，生存保护中的具体机制尚待验证 |
| 他人状态不可直接观测 | 本地观测不包含其他设备的生存状态；公共信号能否补充有用信息，需要与无广播及规则对照比较 | 第 3 版 §3 与探针 B3s 支持一般协调价值，不直接证明新生存标志的独立价值 |
| 关键状态稀少，可能造成训练不足 | 违约之后的包只占全部包的约 0.02–0.1%，却贡献约 10–15% 的违约；旧规则少量干预即产生明显收益 | RES-DSA05-EXP011B、RES-DSA05-SURVIVAL-CHECK；稀少是观察事实，训练信号不足是待验证解释 |

## 3. 已有证据（描述性，只用已读集合）

- **EXP-011b（v2.0，exp011b-eval128）**：U 对 M 的 P2 显著降低（原判据为"有效"）；所测自然部署与补充近 AP 集中，所有方法均未触发饿死判据；未检出 U 相对 O、L 的额外优势；M+Y 在 N = 12 上显著优于 U；隐去广播后 U 的 P2 变差 37–70%。未显著不能解释为等效，遮蔽实验也不能单独证明紧迫语义独有的价值。
- **逐包重放（v2.0，同一切片）**：
  - 生存时间取一个周期时，N = 8–12 上学习方法有 7–24% 的部署在 20 秒内至少中断一次，是独立参照的 2–5 倍；
  - 在该切片中，N_EDF 的违约几乎全部属于物理上无法送达的包（N = 8、10、12 分别为 53/53、63/64、68/70）。这提示存在协调改善空间，不证明相同的收益能由有限信息分布式策略实现，也不证明 N_EDF 最优；
  - U、M+Y 降低了平均违约率，也降低了部分条件违约风险。例如 N = 12 时，违约后下一包违约概率从 M 的 13.3% 降至 U 的 9.6%、M+Y 的 9.5%。连续失败仍明显存在，旧训练目标未显式控制中断发生与持续时间。
- **v2.1 的量级检查**：v2.1 与 v2.0 只在 6–18% 的部署上不同；在未受影响的部署上，两版的每个回合逐 UE 违约数完全相同（RES-DSA05-V21-PHASE0）。
- 以上都是开发阶段的描述性证据，不作为第 4 版假设的检验。

## 4. 贡献与可检验的假设

### 4.1 不作为贡献的部分

文献依据见 [LIT-DSA05-RL-ENGINEERING](literature-rl-engineering_20261014.md)、[论文库](../../papers/README.md) 2026-10-14 一节，以及下列补充的一手来源。

- 生存时间或连续中断作为 RL 的目标：[网络侧分层 RL（PIMRC 2023）](https://arxiv.org/abs/2307.13415)与[单链路 in-X SAC](https://arxiv.org/abs/2507.12031)已有工作。区别应落实到设备自主接入及干扰耦合下的协调，不能声称首次用 RL 或 MARL 处理生存时间。
- 逐设备约束状态（对偶、虚拟队列、欠账）进入策略并在线更新：SALA（TSP 2022）、HeLyMARL、LyMARL-DS 等。
- 按紧迫性让路的原则；AP 广播紧迫信息驱动分布式接入（[uMRA-HAPPO，GLOBECOM 2025](../../papers/uMRA-HAPPO-GLOBECOM2025/analysis.md)）。
- 问题状态收集与混合重启：[ε-Retrain（AAMAS 2025）](https://arxiv.org/abs/2406.08315)收集未满足行为偏好的状态区域，在标准初态与这些区域之间按概率切换；[RARE：Safe Reinforcement Learning Through Regret and State Restorations in Evaluation Stages（ICAPS 2024 的 RDDPS 工作坊）](https://icaps24.icaps-conference.org/program/workshops/rddps-papers/Gros-RDDPS24.pdf)已有基于安全评估、状态恢复与 regret 的训练设计。保存关键状态再训练本身不是 C4 的独立算法创新。
- 峰值年龄与成功更新间隔约束：[Safe DRL for Resource Allocation with Peak AoI Violation Guarantees](https://arxiv.org/abs/2507.08653)是相关近邻。送达时延可变时，连续违约计数与 AoI 门限的对应需推导，不能未经定义就写成完全等价。
- 第 3 版中"紧迫内容优于占用内容"（EXP-011b 未支持）。

第 4 版使用已有机制解决具体工程困难。贡献需要由公平对照和可复现的协调行为支撑，不能仅凭组件组合、场景不同或单个总分改善成立。

### 4.2 主要贡献与支撑机制：分布式保护协调（SC）

- **主要贡献假设**：在有限信息下协调设备的生存保护，减少保护动作对其他设备的干扰，使自然部署分布上的最差设备不可用度优于冻结的强规则对照。
- **支撑机制假设**：关键状态训练在相同交互预算下改善学习。C4 的实用价值、训练效率及算法新颖性分开判断；单独胜过 SC−B 只能说明本任务中的增量价值。

| 组件 | 对应的困难（§2） | 内容 |
|---|---|---|
| C1 生存状态输入 | 违约成串 | 设备把自己的连续违约数作为输入 |
| C2 生存标志广播 | 他人状态不可直接观测；保护可能相互冲突 | 每次发送附带 1 比特"我处于生存时间状态"，AP 按子信道 OR 汇总后广播 K 比特（链路与接收模型同 EXP-011，θ_f = −10 dB） |
| C3 按中断时隙计的训练代价 | 目标与需求对齐 | 每个处于中断的设备-时隙代价 λ_d；它是代理目标，不提供约束保证 |
| C4 关键状态分支训练 | 关键状态稀少 | 设备进入生存时间状态时保存仿真快照，部分回合从快照分支，提高关键状态的训练样本比例；PPO 重放恢复快照的循环隐状态 |

- **需要区分的替代解释**：只改奖励是否已经足够（M-S）；新奖励加简单让路是否已经足够（M-S+S）；公共广播与显式状态是否有增量（SC−F、SC−K）；重点训练是否有效（SC−B）。SC 分别胜过 M-S 和 M+S，不能替代对 M-S+S 的检验。
- **机制证据**：结合中断次数、持续时间与行为诊断，区分减少中断进入和加快中断恢复；检查正常设备的避让以及多个危险设备之间的资源冲突。不能仅凭消融退化推断特定协调行为已被证明。SC−K 检验显式状态编码的作用，不等于删除 RNN 历史和自身广播中所有生存信息。
- **C4 的证据范围**：先报告实际关键状态曝光、总环境交互量、训练耗时和自然分布评估。若将 C4 升为主要算法贡献，需补充 ε-Retrain 式通用混合重启或预算匹配的随机状态分支等近邻对照；否则将其定位为有文献依据的训练手段。
- **标准机制边界**：[TS 38.300 §16.8](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/17.13.00_60/ts_138300v171300p.pdf)描述由配置授权重传调度触发生存状态，并激活相应 RLC 实体用于 PDCP 复制。本文的功率保护规则没有实现这些流程；其结果不代表标准机制性能。PDCP 复制也不等同于在本仿真中同时使用两个子信道；§16.1.3 涉及不同载波上的复制传输路径。当前框架不主张优于标准复制或降低其资源代价。

### 4.3 可检验的假设（框架层面）

本节用于后续设计修订和正式确认。EXP-012 第 2 版已有的 H1 与关口 A 按其原定义执行；不能把其中对 M+S 的比较自动记为本框架对 B\* 的验证。

| 编号 | 假设 |
|---|---|
| H1（主） | SC 的 Q_U 在预先冻结的负载集合上优于开发阶段选定并冻结的强规则 B\*；B\* 的候选和选择规则见 §6 |
| H2（定位） | SC 相对 M、M-S、U 及一个目标、信息和预算匹配的外部学习方法的表现；只有相应优势得到支持时，才声称超越该学习对照 |
| H3（来源，分别检验） | SC−F、SC−K、SC−B 分别检验广播、显式状态编码与分支训练的增量；不预设每个组件必然必要，未获支持的部分不列为已证贡献 |
| H4（主，与 H1 联合判定） | 相对固定参照 M+S，P2 与全部 UE 平均违约率的均值比的 95% 区间上限均低于 1.10；不扩写成相对 B\* 或所有方法均非劣 |
| H5（资源代价，描述） | 报告 SC、B\* 与反应式功率保护规则的功率和占空比，并与各自的 Q_U 一起解释取舍；不外推到标准复制开销 |

## 5. 指标（读取确认集之前在协议修订中冻结）

定义同 EXP-012 设计 §2.1（时间以时隙边界计）。

### 5.1 首要指标：最差设备的不可用度

- **服务中断**：从第 s + 1 个连续违约包的截止期开始，到之后第一个成功送达的包的**实际送达时刻**结束；生存时间状态（第一次违约到中断开始）不算不可用。
- **不可用度** U_i：评估窗口内处于中断的时隙比例；**可用度** A_i = 1 − U_i。
- **首要统计量 Q_U**：每个部署中 max_i U_i 的部署平均；方法间的配对差值与两层 bootstrap 区间。
- **生存时间**：主条件 s = 1 个传输间隔，s = 2 为评价阈值敏感性：对同一 s = 1 策略的同一轨迹重新计分，不声称验证了针对 s = 2 重新优化的策略。若另行训练，须单独登记。
- **标准映射**：[TS 22.104 表 5.2-1 与附录 C.3](https://www.etsi.org/deliver/etsi_ts/122100_122199/122104/18.03.00_60/ts_122104v180300p.pdf)给出生存时间等于传输周期的用例，以及周期 8 ms、生存时间 16 ms 的用例。本场景采用周期倍数的抽象，不据此声称复现了某一标准用例的全部参数或达到其服务指标。

### 5.2 辅助指标

- **重要**：最差设备的中断次数 Q_O（中断的频繁程度，与按时间计的不可用度互补）。
- 单次中断持续时间及其分布，用于区分预防中断与加快恢复；跨窗口的截断和删失单独标记。Q_U 与 Q_O 的最差设备可能不同，不能把两项部署均值直接相除当作平均中断时长。
- 全部设备的平均不可用度；至少出现一次中断的部署比例；违约之后下一个包的违约概率。
- **非劣检验指标**：P2 与全部设备的平均违约率（H4）。
- 资源代价：平均发射功率、占空比（H5）。
- 第 3 版的 P2、F_{0.01} 与 N\*_{0.01} 继续报告，作为与前序工作的衔接。

### 5.3 统计

- 沿用协议 v2：两层 bootstrap，部署在方法间配对，学习方法的训练种子各自重抽，10,000 次，种子 20,260,930。
- 中断在 20 秒的回合中较少，Q_U 的区间可能较宽；评估切片的规模在 EXP-012 与协议修订中写定。
- B\* 的选择只使用开发数据，确认集不再选择规则、检查点或负载。零分母、零事件等边界处理在协议中写定；两种方法均为零不能解释为有相对改善。

### 5.4 研究成败的判据（框架层面）

1. **有效性（H1）**：在确认集上，配对差值 Q_U(SC) − Q_U(B\*) 在冻结的每个核心负载上，95% 区间上限均 < 0。核心负载拟沿用 N = 8、10、12，确认协议中冻结；仅部分负载成立时只报告该范围的证据，不算整体通过。固定报告 Q_U(SC) − Q_U(M+S) 以衔接 EXP-012，但不能以它替代对 B\* 的主比较。
2. **可靠性非劣（H4）**：在相同核心负载上，SC/M+S 的 P2 均值比、全部 UE 平均违约率均值比，95% 区间上限都 < 1.10。这是相对 M+S、允许 10% 退化界限的非劣，不是零损失，也不自动证明相对 B\* 非劣。
3. **联合判定**：只有 H1 与 H4 同时通过，才支持 §1 的主效果表述。仅 H1 通过时写"不可用度改善，可靠性非劣未建立"；H4 未通过不自动证明有害。其他规则、学习方法和参照结果完整报告；若 SC 不优于某个学习对照，不声称超过该方法或达到总体最优。
4. **来源与贡献边界（H3）**：预先写定、冻结方法后的开发评估可用于消融证据。若依据其结果再次改方法，不能沿用旧消融证明最终版本；需补独立验证。若 C4 保留为核心贡献，确认清单优先保留 SC−B；若其增量未建立，则收敛对应主张。无需要求所有历史参照和全部消融都显著劣于 SC。
5. **服务达标与资源代价**：报告可用度分布及 H5。指标改善不等于满足标准用例的绝对可用度要求，资源更少也须结合服务水平解释。
