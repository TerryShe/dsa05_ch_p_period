# 固定 OBS 下的 MARL 文献与 DSA05 后续路线

## 1. 判断与研究边界

**继续在现有 OBS 下研究 MARL 有充分理由。** EXP006 已证明学习能提高中等负载的可靠性；它没有证明剩余差距必然需要新增信息。下一步应优先检验训练目标、尾部覆盖、历史表示和信用估计，而不是把一次方法的不足解释成信息论不可能性。

按用户本次要求，执行时维持 [scenario-v2.md §4](scenario-v2.md) 的信息来源：自己的当前 K 维 CSI、自己的包/周期/截止期、自己的过去动作/结果/服务，以及上一时隙公共 RSSI。不给真实 N、UE ID、全局时钟、其他 UE 的队列/增益/紧迫性、当前联合干扰或保护广播。

本次建议还采用更严格的实施起点：保持 Actor 的原始输入字段和维度；新增辅助 head、权重、风险统计或向量价值均先放在训练端。已有 GRU 的 hidden state 可以继续存储本地历史。单独增加从历史计算的 embedding 没有增加外部信息，但改变内部网络接口；本笔记优先选择只监督现有 hidden state 的做法。

训练端仍可以使用完整当前状态、联合动作、已完成轨迹结果、模拟器反事实和训练实例难度。关键是这些量不能成为执行 Actor 的输入，也不能通过真实未来 CSI 决定当前动作。

## 3. EXP006 提供了什么证据

事实来自[正式测试报告](../results/exp006-test_20261002/report.md)：

| 结果 | 支持的判断 | 不能推出的判断 |
|---|---|---|
| ε=0.01 时 MARL 与 best_local 的 N* 都是 6 | 当前方法没有达到容量主假设 | 无新增 OBS 的所有方法都不可能提高容量 |
| N=8/10/12 的 F_0.01 配对增益约 0.07/0.19/0.25 | 当前 OBS 下存在可学习的协调收益 | 模型已精确知道其他 UE 的紧迫性 |
| ε=0.05 时容量 12 对 8 | 学习确实改善了可靠性/承载能力 | 可以用 5% 结果代替 1% 主结论 |
| 少数远端快类 UE 影响严格门槛 | 尾部与最差 UE 是重要诊断对象 | 所有失败都由不可避免的物理衰落造成 |
| C 只在短训筛选中落后于 A | 该实现和预算下 C 较弱 | 逐 UE 约束与公平训练没有价值 |

报告中“保护差距”的表述是对现有策略失败形态的解释，不能视为对所有本地历史策略的下界或不可能性证明。这里不修改历史报告，只限定它在后续立论中的使用范围。

### 3.1 现有奖励与主指标存在结构性差别

当前 A 的团队奖励近似为

\[
r_t=-\frac1N\sum_i c_i(t).
\]

若 UE i 每 P_i 时隙一个包、稳态包违约概率为 q_i，则长期平均罚分约正比于

\[
\frac1N\sum_i\frac{q_i}{P_i}.
\]

在相同包违约率下，快类对每时隙罚分的贡献约为慢类的 4 倍。这与业务类别权重有关，而主评价要求每个 UE 都达到相同包违约率门槛。就算快类已经得到更高事件权重，团队均值仍可能牺牲少数弱 UE；**问题不只是再给快类加权，而是平均值与所有 UE 合格的区别。**

一个必要的低成本对照是 r_t=−(1/N)Σ_i(P_i/P_ref)c_i(t)，使稳态均值对 q_i 的权重一致。它是目标尺度校准，既不保证逐 UE 达标，也不应当作主算法创新。

### 3.2 600 时隙训练与 20,000 时隙统计不同

600 时隙内快/中/慢类约产生 60/30/15 个包。慢类一个违约就对应约 6.7%，无法稳定估计 1%。若直接按 ⌊0.01M_i⌋ 计算训练额度，三类短回合额度都为 0，正式指标的额度比值不可直接复用。

应把环境统计时域、GRU 重置时点与反向传播片段长度分别设计：可以使用更长回合、跨片段保持 hidden state，以短片段训练；代价是状态重放和价值自举更需校验。长时域不要求一次反向传播覆盖完整 20,000 时隙。

### 3.3 先排除价值尺度与选模代理的影响

代码当前归一化优势，但回归原始价值目标。风险损失、训练对偶和类别重加权都可能改变 Critic 尺度；因此先以 ValueNorm 等方法建立稳定基线。C 的短训失败不能据此归因于约束思想本身。

原 S 是多 N 的平均 F，主结论却由 N* 的首次门槛穿越决定。新实验应预先写定选模规则，同时记录门槛附近 F、最差 UE 余量和 S，避免训练只改善高负载均值而主容量没有变化。不要在已读测试集上重新选择旧检查点。

## 4. 最值得研究的三条路线

### 路线 A：逐 UE 归一化与部署尾部对齐

参考 Coherent PG、SOTO、RiskQ、WCMASAC，以及已有 DCGFRA 的 min-max 目标。

完整正式回合中令 A_i=⌊εM_i⌋、X=max_i V_i/A_i；现有正式评估所有 A_i>0。则

\[
F_\epsilon(N)=\Pr(X\le1).
\]

这里 **ε=1% 是逐 UE 包违约率，尾部比例 5% 来自部署可行率 95%**。可探索：

- 周期归一化的平均违约率，作为必要基础对照；
- 训练部署内的最差 UE 或平滑最大违约率，关注用户间差异；
- 部署层 X 的 upper-CVaR_0.05 或其他明确的尾部代理，关注部署间差异。

对 X 的 upper-CVaR_0.05≤1 是较保守的充分条件，不等价于 F≥0.95。有限样本、离散分位点和极端衰落都可能让它过度保守。短窗口只能使用替代统计量，必须注明与正式 X 的差别，并在长训练/验证轨迹检查这种替代是否有效。

不能把这几个层次混在一起：公平预期效用 φ(E[R])、单个部署公平 E[φ(R)]、团队折扣回报的 CVaR、部署 X 的 CVaR 是不同目标。训练权重只存在于训练系统，执行 Actor 无需获得全局风险量。

**论文潜力最高的是这条主线。** 但“MAPPO + CVaR”已有大量先例；需要具体处理截止期积累、业务尺度、干扰外部性与部署尾部，并建立对应的推导和消融。

### 路线 B：用训练用预测任务改善现有 GRU

参考 LIAM；先把辅助 decoder/head 接在现有 GRU hidden state 上。它读取的仍是同一段本地历史，执行不需要 decoder。

分层对照：无辅助任务；预测已有的下一步 RSSI/自身服务反馈；训练时监督每信道其他 UE 的聚合活跃或紧迫需求分布。第三项使用特权训练标签，但执行不使用这些真值。

标签应对 UE 排列不变，不能用固定 UE 身份列表。聚合 RSSI 不可唯一识别队列，因此优先预测条件分布，并检验校准，而不是声称恢复隐藏状态。

原 LIAM 的其他策略固定；DSA05 所有 UE 同时学习，需要处理目标的非平稳性。等参数 GRU、现有反馈预测与特权监督之间的消融必不可少。

**有算法贡献潜力，但必须证明表示服务于截止期决策。** 重建分数提高而 F 不变，只能说明预测更准，不能证明协调改善。

### 路线 C：给本地动作更有针对性的训练信用

参考 GPAE、DAE、DOP、COMA、Dr.Reinforce；后续可借鉴 RUDDER 的时间归因。

优先实现/评估 GPAE on-policy 作为近期基线，因为它保留 PPO 与共享 Actor。它需要训练侧的 E Q^i(s,a_−i) head，并非复制团队 GAE。先不加入 replay，防止把信用收益与更多数据复用混淆。

训练用模拟器反事实仍值得研究，但不沿用 EXP-003 的旧动机。应重新问：UE i 的 OFF、换信道或降功率对**新的风险目标**有何边际影响？如何把这个影响回传，而非只统计即时互信息增加？反事实状态价值误差也要计入。

需要明确：

- 合法动作无关基线可改变梯度方差，不会自己把平均目标改成最差 UE 目标；
- 多步差分或启发式信用可能改变梯度，DAE 对此有明确权衡；
- 只使用 UE 自己的违约奖励可能忽略它对其他 UE 的干扰，不能把团队风险拆成互不相关的自利成本；
- 时间信用与智能体信用是两个维度；RUDDER 本身没有解决哪个 UE 应得到信用；
- 未折扣奖励总和守恒并不保证当前 γ=0.99 的目标守恒。

**最有价值的组合是明确风险目标后做信用改善。** 先分别验证目标和信用的效果，再组合，才能说明贡献来自哪里。

## 5. 建议的实验顺序

以下是阅读后的候选路线，尚未形成冻结实验设计，也未实施或训练算法。

| 阶段 | 主要比较 | 解决的问题 | 进入下一阶段的证据 |
|---|---|---|---|
| 基线校准 | 原 A、A+ValueNorm、周期归一化奖励；统计时域单独比较 | 是否存在尺度、类别和时域混淆 | Critic 训练稳定，长验证指标可解释 |
| 目标筛选 | 归一化均值、最差 UE 代理、部署尾部代理 | 主指标是否受目标失配限制 | 门槛附近 F 与最差 UE 余量改善 |
| 信用筛选 | 同一目标下 GAE、GPAE on-policy、DAE/模型反事实候选 | 归因是否限制学习 | 同预算更稳定或样本效率更高 |
| 表示筛选 | 相同目标与优势下，已有 GRU 的无辅助/反馈预测/聚合监督 | 本地历史是否被利用不足 | 预测校准与可靠性增益同时存在 |
| 泛化与确认 | 固定方法、固定选模、备用确认集 | 结果是否可推广 | 多种子、配对置信区间与完整 F 曲线 |

PLR 可先作为独立训练采样消融：均匀采样、静态困难分层、普通 PLR、截止期学习潜力评分。不要一开始把它与全部新损失叠加。Actor 不接收难度或部署编号。

混合 N 的总时隙、各 N 采样比例、有效 UE 数、模拟器反事实调用、辅助模型开销及调参预算都需记录。环境时隙相同与 wall-clock 相同代表不同的比较，两者均有价值。

## 6. 评价与论文证据要求

主评价继续使用固定场景的 F_0.01 与 N*_0.01；F_0.05、平均违约率和 S 是补充，不能替代主门槛。

建议同时报告：最差 UE 违约率与额度余量；各业务类别和弱信道组的结果；逐 UE 优势的差异/方差；风险或辅助预测的校准；碰撞、功率和避让的条件关系；训练时隙与计算时间。预测失败 UE 的指标不能只在失败样本中统计，也要有总体分母。

功率降低和发送次数减少可能来自更快完成，而非主动保护别人。若提出干扰保护机制，应按自身增益、剩余服务/截止期条件分析，并用训练/诊断反事实检验外部影响。

统计按训练种子与部署两层处理；同一个模型改训练用诊断或比较共用种子的方案时，明确是否配对，不能默认为独立抽种子。N* 的 bootstrap 应在所有 N 上联合重抽，并报告阈值附近 F 的区间。

[协议 v2](marl-protocol-v2.md) 的原 test 已读取。新方法只用 train 池训练、dev/validation 开发；新的最终确认需从 30,000 起备用池另选尚未使用的实例并预登记。SOTO 或新采样方法都不允许把已发现的测试困难实例纳入训练。未确认前的增益只能标为开发/验证结果。

从目标期刊论文的贡献标准看，单纯换算法、增加网络或更多训练预算通常不够。更清楚的候选论题是：**在既有本地信息边界下，把异步截止期的逐 UE 风险与训练信用相连，提高部署可靠性与承载能力。** 需要证明该连接为何有效、何时受限，并通过单因素消融、强本地规则、因果集中参照与独立确认支撑。当前文献支持这是值得验证的路线，尚不支持宣称已经具备新的方法增益或理论保证。

## 7. 未作为主路线的检索结果

- [HAPPO/HATRPO，ICLR 2022](https://openreview.net/pdf?id=EcGGFkNTxdJ)：顺序更新和独立异构参数有参考价值，但不是当前共享、匿名、混合 N 策略的直接替换；本次不增加其 PDF 归档。
- [Learning to Cooperate with Minimal Observability，AAAI 2026](https://ojs.aaai.org/index.php/AAAI/article/view/40194)：研究伙伴选择和社会困境，仍有第三方互动观察；与无线团队奖励、当前 OBS 不同，不把其结论作为本地信息不可能性的证据。
- 需要邻居共识、消息传递或原样执行全局 self-attention 的方案，不作为当前主算法路线。已有 SACC、DePAint 等笔记继续用来说明信息假设差别。

现有无线问题文献仍需保留，[DCGFRA](../../papers/DCGFRA-2024/analysis.md) 的最差用户目标、[MARLSPA](../../papers/MARLSPA-TCOM2025/analysis.md) 的循环策略与[DMRL-DSA](../../papers/DMRL-DSA-TWC2019/analysis.md) 的本地反馈学习是重要领域对照。本次补充方法侧文献，不声称完成所有最新相关工作的穷尽性检索。
