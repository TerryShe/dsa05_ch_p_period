# DSA05 实验状态、V2 研究价值与投稿条件综合评估

**判断：当前 V2 值得继续，有条件形成 TCCN 层次的完整研究；现在还不能说创新已经成立，也不宜直接按现有证据投 TCCN/TCOM。** 最有价值的问题是：在衰落、异步截止期与干扰耦合下，哪些紧迫信息值得传、以什么真实通信代价传、能保护哪些弱 UE。仅“MAPPO 多输入一个比特、可靠性上升”说服力偏弱。

本评估先检索本库，再查作者/机构、会议/出版社和 arXiv 原始来源。实验判断依据工作树、设计与报告、已存在的输出元数据；没有启动训练或评估，没有读取新的确认集样本，没有改动已批准框架、协议或实验代码。审计开始时 EXP-011 实现尚未提交；本次工作期间仓库另有更新，终检已推进到 `bf56735`（第 0 阶段实现）。以下状态已据此更新，测试通过数引用实现记录，并非本次重新运行。文献阅读范围逐篇声明；没有复现论文结果，检索也不构成穷尽性新颖性证明。

### 1.1 最重要的正式负结果

v2-confirm2 上，M / A-mix / best_local 的 N* 都是 6，N_EDF=20。N=8 的 F 分别为 0.941 / 0.935 / 0.862；M−A-mix 为 +0.006，95% 区间 [−0.011,+0.026]。学习相对规则的连续可靠性收益真实存在，但困难采样相对原学习方案的容量提升没有得到确认。不能为了新目标而把旧预注册失败改写为成功。

### 1.2 新指标下还有多少空间

现在首要指标是

\[
P2(N)=\mathbb E_{部署}\left[\max_i V_i/M_i\right],
\]

即每部署最差 UE 违约率的部署均值。F_0.01 是所有 UE 都满足 1% 服务要求的部署比例；两者不是一回事。以下是**同一已读 exp010-eval512 上的描述性汇总**，学习法先按训练种子计算再取平均，不是新确认结果，也不是 U 的结果。

| CG | 0.004601 | 0.008746 | 0.015453 |
| CG-opt | 0.004197 | 0.006825 | 0.009799 |
| best_local | 0.001692 | 0.005018 | 0.011907 |

### 1.3 确认集与阶段边界

输出元数据存在 178 个 v2-confirm2 评估块，与 89,000 回合报告一致；未发现 v2-confirm1 或 exp011-eval512 评估块。当前最新登记是：v2-confirm1（30,000–30,499）留作最终确认，exp011-eval512（5,000–5,511）作 EXP-011 新开发评估。旧报告“从31,000起另取”的描述已被[改登记](exp008-registration.md)和 rev3 覆盖。同编号 V1 集合采用不同场景种子，不等于 V2 已用过。

改为 P2 发生在看过 V2 test/confirm2 之后，属于合理的新研究阶段，但应披露这一事实。最终确认之前仍须冻结新版统计协议、方法/检查点、接收条件、负载和主检验，不能使用已读结果追认显著性。

## 2. V2 的研究价值与期刊判断

| 维度 | 判断 | 理由 |
|---|---|---|
| 问题重要性 | 高 | 弱 UE 的截止期可靠性、部分观测与动态干扰是实际通信控制问题 |
| 当前机制新颖性 | 中等、尚待证实 | 具体摘要和接收条件可能有价值；紧迫优先、学习信令、多信道 MARL 均已有覆盖 |
| 现有证据质量 | 旧任务较强，新机制不足 | 冻结集合、负结果、强基线和诊断良好；EXP-011/012 结果尚缺 |
| TCCN 适配 | 较高，条件性可争取 | 感知—学习—决策与通信协议贡献吻合；需完整证明摘要的通信价值 |
| TCOM 适配 | 有可能，当前更欠缺 | 若补出信令检测/信息压缩/可靠性代价的定量机制会更有说服力；仅学习仿真增益较薄 |

TCCN 官方范围同时要求智能实体方法和原创通信/网络贡献；TCOM 接收通信领域理论和实验推进。上述强弱是本次研究判断，不是“TCOM 一定要求定理”“TCCN 只需仿真”的官方规则，也不是录用概率。[TCCN 范围](https://www.comsoc.org/publications/journals/ieee-transactions-cognitive-communications-and-networking)、[TCOM 范围](https://www.comsoc.org/publications/journals/ieee-transactions-communications)

### 2.1 已不能当作创新点的内容

- 异步周期、截止期和分布式 MARL：SeqDQN；更接近动作与累积服务的是 XR-SBPC、MARLV2X。
- 最差用户丢包目标、资源和功率联合选择：DCGFRA，已正式发表于 TCCN 2025。
- 根据紧迫性提高接入优先级、公共信号协调：SMART TCCN 2021，不止旧笔记中的 SPAWC 2019。
- 多信道、截止期、MAPPO 加通信与无通信对照：ECPO GLOBECOM 2023 已有。
- 学习控制消息、减少信令和解释消息—动作关系：Valcarce、Mota、Uyoata 等已有不同形式。
- BS 逐资源广播、分布式学习、控制消息损失敏感性：新查到的 REEMAC TMLCN 2026 已有。因此也不应笼统声称“首次研究接收条件”。
- 广播资源选择和价值、让低价值传输退让：PGDS 的已读预印本已有，正式 ToN 2026 摘要也描述价值退让；终版详细开销处理尚未核读。

逐项区别及原始链接见[文献索引](../../papers/README.md)与各篇 analysis。尤其不要再使用旧 V1 笔记中的“DSA05 节能、别人只求可靠性”作为当前 V2 的差异。

### 2.2 最值得保留的贡献候选

建议把主张收紧为：**面向跨时隙累积服务的异步上行，将对弱 UE 有决策价值的紧迫状态压缩为资源级公共摘要；在明确检测错误、时延与资源预算下，量化其对最差 UE 按期可靠性的收益和失效区域。**

要同时回答三个问题：为什么传紧迫性比传占用更有用；为何需要学习响应而不是简单让路；给这个摘要真实控制资源后收益还剩多少。若其中某项被否定，应相应改写贡献，不应通过增加网络模块掩盖负结果。

我不建议把“固定 OBS 已到信息论极限”作为起点。多种训练失败和 IL 失败只排除已尝试路线。可补一个受限两 UE 子问题：构造本地历史相同、他人紧迫状态不同且最优动作冲突的情形，推导无摘要决策的最小期望损失，再分析有噪摘要能降低多少。**这是待完成的理论研究建议，不是本次证明，也不代表一般 V2 的下界。**

## 3. 投稿前最关键的缺口

### 3.1 “低 SNR 可读”不能只由仿真假设保证

EXP-011 主条件 −10 dB 来自粗处理增益估算；当前没有链路级证据，不计误警、标志资源及下行广播错误。阈值扫描可以说明算法依赖什么接收能力，不能证明该接收能力可实现。

需要至少一条可核验链：控制序列长度/功率/同步及 CSI 条件 → 漏检与误警概率 → AP 聚合和广播误差/时延 → P2 净变化。碰撞与近远效应下，“分别读出每个 UE 后 OR”与“直接检测某类序列是否存在”是不同接收机，必须明确实际做哪一种。数据传输 SINR 门限不自动等于控制检测器的门限。[短包检测论文](../../papers/SP-Detect-ICASSP2018/analysis.md)、[衰落有限块长论文](../../papers/SP-Fading-TCOM2016/analysis.md)

### 3.2 语义比特数、总信令量和空口资源要分开

K+1 是“每 UE 附带一位 + 公共 K 位”的局部口径；全网每时隙新增有效载荷应按 **K + n_tx(t)** 计（若每次发送都携带一位），不能说全网恒为 K+1。若只统计置 1 的标志，还要交代 0 的编码与检测成本。已有 CSI、RSSI、私有反馈是共同底座，但 CG 与全信息方法的底座并不相同，应分别列清。

5N 是 DSA05 对全体 21 动作按 UE 固定长编码的预算，不是 XR-SBPC 原论文测出的无线开销；其原方案观察的是邻居动作。紧迫信息和邻居动作信息是不同内容，不天然具有信息包含关系。

O 不需上行紧迫比特，U/L 需要；目前“同比特”更准确指同下行摘要大小、同接收门限或共同预算上限。论文需给实际 bit/slot、控制 RE/slot 或时频占比、下行覆盖/错误及配置成本摊销。NR SR、DCI 2_4 只能作为类比，未实现就不能写成标准兼容产品。

### 3.3 必须补齐信息匹配的竞争比较

先完成 EXP-011 的 U/M/M+Y/O/L/U0，再做 EXP-012 的 SAC 三信息变体。旧 V1 的 SAC 负结果不能代替新可靠性目标的对照。若 U 与 M+Y 相当，贡献应把规则协议放到重要位置；若 O 与 U 相当，不能声称紧迫语义必要；若 L 输，只说明当前训练预算/方法未学好，不能排除更强学习通信。[DIAL](../../papers/DIAL-NeurIPS2016/analysis.md)、[ECPO](../../papers/ECPO-GLOBECOM2023/analysis.md)

### 3.4 指标与“边界”的表述要准确

N_EDF 是可实现的集中式因果启发式参照，**不是严格可靠性上界**。CG-opt 也是预算内优化的特定静态方案，不能代表所有配置授权能力。L0、L1、静态 CG、邻居动作最好称信息配置矩阵，不称有严格包含关系的线性阶梯。

P2 取有限包数下的最大值，对 N、回合长度和最困难部署敏感。最难 5% 部署贡献均值的 45%–63% 已在框架记录；应展示分布、逐种子结果和不可达包敏感性。3 个训练种子是当前设计，不应宣传为充分覆盖所有算法不确定性。1% 仿真服务门槛也不等于已经验证工业 URLLC 的更严格可靠性。

混合 N 训练、按 N 选检查点是已批准流程；它不等于一个固定模型直接推广至任意 N。至少补已计划的多普勒敏感性，若声称可部署还需看频率相关、CSI 误差、摘要老化等。不得把有限主设置的成功扩写成普遍保障。

### 3.5 第 0 阶段发现的具体核查项

当前设计要求 O 的“自身上一时隙上行比特”恒为 0；但 `SummaryLink.own_previous` 返回 `self.sent`，occupancy 模式对发送者生成 1，训练器和评估策略直接把它拼入 context。因此 O 实际得到上一时隙是否发送的重复编码。它没有增加全局信息，但偏离已登记输入定义，应在正式训练前修正或明确登记。本次没有修改该工作中的代码。

证据：[设计 §2.5](../experiment-designs/011-urgency-information-coordination_20261010.md)、[urgency.py](../../src/dsa_period/urgency.py)、[policy.py](../../src/dsa_period/marl/policy.py)、[trainer_v2.py](../../src/dsa_period/marl/trainer_v2.py)，在 `bf56735` 终检仍如此。此外，90% 分位究竟按各训练种子求后平均还是种子×部署混合求，需要统一定义；广播隐去消融虽使用取值 0，仍可能改变条件观测/轨迹分布，不能仅凭“0 曾出现过”排除分布偏移。[Pitfalls AAMAS2019](../../papers/Pitfalls-AAMAS2019/analysis.md) 是这一诊断局限的直接方法依据。

| P2 | [LazySched](../../papers/LazySched-ToN2002/analysis.md)、[CalcEE](../../papers/CalcEE-ToN2009/analysis.md)、[FRL-EE](../../papers/FRL-EE-2010/analysis.md)、[RLPC](../../papers/RLPC-2022/analysis.md) | V1 能耗或后续能耗—可靠性取舍；当前 V2 不应抢占主要阅读预算 |

## 5. 新补文献与对定位的改变

新增逐篇笔记和下载状态统一见 [papers/README.md](../../papers/README.md) 的 2026-10-10 专节；其中原始论文标题、作者、年份、版本、URL、阅读范围和具体适配建议均在各自 analysis.md 中。

本次新增 **15 篇分析，其中 14 篇 PDF 下载成功、1 篇待获取**。最应优先精读的是 SeqDQN、SMART 期刊版、ECPO、LPPC、PGDS、短包检测和 REEMAC。DIAL/SchedNet 支撑更强的学习消息比较，Pitfalls 约束机制解释；CG-TSN 支撑更强的非学习协议比较；有限块长衰落与能耗衰落优化提供理论及互补方向。REEMAC 已读作者公开全文网页，PDF 因 IEEE/作者公开下载端点拒绝而未取得，不能计入已下载数量。

本次对已有定位做出以下实质修正：

1. **SMART 应读 TCCN2021 扩展版**，其公共传输税比“只根据自己紧迫性”更接近公共摘要协调。
2. **Valcarce2021、Mota2022、Uyoata2025 不是同一种学习信令**：固定 BS 专家/预定义消息的使用、双端联合学习、学习上报时机要分开。Uyoata 的约八倍开销减少是消息次数，不是编码后 bit/RE；其成功率也不是 DSA05 的 P2。
3. **Mostafa 的 ECPO 已覆盖多信道截止期任务及 MAPPO 通信消融**，这是原来摘要级阅读低估的重要近邻。
4. **REEMAC2026 已考虑多类控制消息丢失**，DSA05 可争取的是具体紧迫语义在弱信号与截止期保护中的作用，不是泛泛的丢包鲁棒性。
5. **C-FAST 已能预先协调异构周期而无需逐包信令**；不能把低开销的周期协调专属于学习方案。
6. **Zafer–Modiano 的衰落节能模型不能直接作 V2 的严格最优界**：终端惩罚、功率约束与速率模型有差异，移用前需重新推导。
7. **PGDS 是广播后退让机制的直接近邻**，已读预印本交换比 V2 更细的资源与价值信息且未计信令成本；有意义的比较是更少信息、延迟/检测误差下的性能代价。不能未经终版核对就把预印本的全部局限归给 ToN 终版。

## 6. 值得研究的相关方向及投入顺序

| 顺序 | 方向 | 为什么值得做 | 对应论文与最小可交付结果 |
|---|---|---|---|
| 1 | 有误检测的紧迫摘要与控制资源联合设计 | 正好补核心主张最大的证据缺口；能把简单比特输入变成可评估的通信机制 | SP-Detect、SP-Fading、REEMAC；给出块长/能量—漏检/误警—P2 的净收益曲线 |
| 2 | 摘要内容、分辨率与信息价值 | 明确一位究竟保留了什么，能否用两位等级改善多个紧急 UE 的竞争 | DCGFRA、DIAL、ECPO；先完成 U/O/L，再另立多级 slack、权重或债务摘要实验 |
| 3 | 事件触发与消息新鲜度 | 当前广播每时隙持续发送，而真正干预很少；减少持续开销有实际价值 | LPPC、SchedNet；比较触发阈值、缓存摘要/过期机制、突发多紧急 UE 情形 |
| 4 | 配置授权 + 紧急例外的混合协议 | 周期可预测性应利用，动态衰落只在必要时补偿；可能比纯随机接入更实用 | CG-TSN、PT-CD、CG-URLLC；预配置正常路径，摘要触发借道/重配，计入配置摊销 |
| 5 | 信息受限下的可解释性能界 | 能从“某个训练器失败”推进到有边界的结构性解释，尤其有助于 TCOM 定位 | TimelyFlows、DecDeadline、SMART、PGDS；先证明小规模子问题，明确扩展到完整模型的限制 |
| 6 | 公平/尾部风险目标与模型辅助训练 | 避免容易服务或高频产生成功包的 UE 掩盖少数困难 UE，可能减少样本浪费；不能把V1的长周期失败归因直接搬到V2 | DCGFRA、GPAE、CoherentPG/WCMASAC；固定信息比较 max-UE 或平滑代理，区分训练目标收益与摘要收益 |
| 7 | 衰落下能耗—可靠性及电路成本 | 适合 V1 后续独立主线，当前混进 V2 会使结论分散 | FadingEE、FRL-EE、RLPC；统一发射/控制/电路成本后画 Pareto 曲线 |

不建议同时推进全部方向。**先做完 EXP-011/012，并补方向1；再按结果选择方向2或4。** 若 U 输给规则，规则协议仍可能有通信研究价值；若净资源收益消失，应将工作收缩为信息价值诊断，而非宣称低开销可部署协议。

## 7. 可执行的投稿门槛

这不是额外更改预注册判据，而是论文完整性检查：

1. EXP-011 第 0 阶段已提交且记录测试通过，正式训练前处理 §3.5 的定义偏差；随后按照登记运行并如实判读 U、内容对照和规则响应。
2. EXP-012 提供至少两类学习算法的信息匹配比较；对最强合理控制对照无回避。
3. 把低 SNR 接收能力变成有检测/开销依据的模型，给误警、延迟、下行丢失和资源扣除后的结果；无法完成则删去“已实现低 SNR 可靠读出”的表述。
4. 新协议与方法清单冻结后，一次使用 v2-confirm1；旧结果仅作研究动机和开发证据。
5. 用机制与适用范围组织论文：收益来自哪里、付出多少成本、何时失败。不是堆更多网络模块，也不是只展示跨过1%门槛。

若这些成立，建议优先按 TCCN 的智能通信协议论文组织；若再有清晰的检测—压缩—调度定量关系或受限场景理论界，TCOM 定位会更扎实。当前最准确的状态是：**基础设施和问题诊断成熟，候选创新已明确，决定期刊层次的新证据还在前面。**
