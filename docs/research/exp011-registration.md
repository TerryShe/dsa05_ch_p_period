# EXP-DSA05-011 的评估切片登记

本附录登记 EXP-DSA05-011（紧迫状态摘要与由它驱动的协调）使用的开发评估切片，依据[设计](../experiment-designs/011-urgency-information-coordination_20261010.md) §4.2。

- 协议 v2 的冻结核心、EXP-008、EXP-009 与 EXP-010 的登记都不变（重新生成后三份清单逐字节相同）。
- **机器清单**：[exp011-sets.json](exp011-sets.json)，由 `scripts/register_exp008_sets.py` 生成，`tests/test_exp011.py` 核对。

## exp011-eval512

| 项目 | 内容 |
|---|---|
| 实例 | 开发池 5,000–5,511（半开区间 [5000, 5512)），512 个部署 |
| N | 6、8、10、12、16 |
| 执行 | 每个部署 1 次，完整 20,200 时隙回合 |
| 种子 | 开发池编码 0，v2 的执行、衰落种子基准与逐 UE 派生，所有方法共用 |
| 用途 | 只用于本实验的评估：主判据 D_N（§5.2）、次要判据与描述（§5.3）。不用于任何检查点选择；学习方法的检查点在 exp009-screen256 上按 P2 选择（设计 §4.1） |
| 读取方式 | `evaluate_capacity --split dev --screen exp011-eval512 --grid N --formal`，需干净的已提交工作树 |

- `splits_v2.check_dev_range` 拒绝任何与 5,000–5,511 重叠的普通开发评估。
- 接收条件网格（设计 §3.5）只在 N = 8、10、12 上读取本切片，是登记网格的子集。
- 本实验不读取任何确认集，结论是开发阶段的决策依据。

## 登记时的使用核查（2026-10-10）

- v2 开发实例只用过 0–63、1,000–1,399、2,000–2,255、3,000–3,255、4,000–4,511。
- `outputs/` 与 `docs/` 中没有任何文件引用开发实例 5,000–9,999（设计起草时核查）。
- 第 0 阶段的检查只用训练池与已用过的开发实例 0–63、1,000–1,399。
