# DSA05 研究框架：低开销紧迫状态摘要驱动的分布式协调

状态：**已批准（第 3 版，2026-10-10）**。

- 第 1 版批准时用户决定：ε = 0.01；最终确认集为 v2-confirm1（§9）。
- 第 2 版（同日，用户批准）：首要指标改为最差 UE 违约率（P2），F_{0.01}（P1）改作服务达标评价；成败判据不再依赖 1% 门槛，负载范围也不再按门槛划定（§5）。选择依据见 §3.3 末尾。
- 第 3 版（同日，用户批准；按用户提出的核心表述）：
  - 原来分开的 C1（信息需求）与 C2（协调机制）合并为一条核心贡献：紧迫状态摘要，以及由它驱动的协调；并把"收益来自哪里、在什么条件下成立"作为要回答的问题（§1、§4）。
  - 补充检索表明，按紧迫性让路的原则与学习信令都不新（文献笔记 §1.5、§2），§4.1 相应扩充。
  - 新增信息开销对 P2 的前沿、接收条件测试与"信息 × 算法"对照（§5.3、§5.5、§6、§7）。
  - 更正第 2 版的一处错误：§6.1 与 §7 写"每个 N 分别训练"，实际沿用的流程是混合 N 训练、按 N 选检查点（EXP-009 第 1 步按预先写定的规则保留了混合训练）。
- §9 的其余各项在相应的实验设计或协议修订中决定。

- 本文件规定研究目标、要解决的困难、贡献假设、指标与比较对象，是后续实验设计与论文表述的依据。
- 它不改变场景 v2.0 与协议 v2 的任何冻结数值。需要修改协议的地方列在 §8，在读取下一个确认集之前另立协议修订。
- §3 的数值都来自已读集合，只作描述。

## 1. 研究目标

**核心表述（第 3 版）**：面向时变衰落下的异步周期上行，设计一种低开销、可在低信噪比下读出的紧迫状态摘要，以及由它驱动的分布式协调方法，降低最差 UE 的按期违约率；并通过信息匹配对照、机制诊断与接收条件测试，说明收益来自哪里，在什么负载与接收条件下成立。

- 针对时变衰落与多用户干扰下的**异步周期上行业务**，研究只用有限本地信息的**分布式资源分配**：每个 UE 决定子信道、发射功率与发送时机。
- 目标是提高有截止期的包的**按期交付可靠性**，**尤其关注可靠性最差的 UE**。
- 论文回答：一个方法怎样利用本地可得的信道状态、业务紧迫性与干扰反馈来做这三项决定；它带来多少可靠性增益，增益来自哪里。
- 比较对象：改编的现有学习方法，以及优化的配置授权基线 CG-opt。
- 考察不同的 UE 数 N，以评价负载适应性与可扩展性。
- 违约率目标（1%）仍是服务要求之一，用于服务达标评价；**研究成败看最差 UE 违约率的改善，不论改善是否跨过 1%**（§5.5）。

## 2. 要解决的困难

**UE 只能获得有限的本地信息，却必须在截止期前完成传输；与此同时，信道在变化，其他 UE 的资源选择又会改变干扰。算法需要协调信道机会、业务紧迫性与相互干扰，才能提高按期交付可靠性。**

三个因素在场景 v2.0 中的具体形式：

| 因素 | 场景 v2.0 中的体现 | UE 本地能看到的 | UE 看不到的 |
|---|---|---|---|
| 信道机会 | Jakes 衰落，f_D = 10 Hz；4 个子信道彼此独立；相干时间与业务窗口（10–40 ms）同量级 | 本时隙自己在各子信道上的增益 | — |
| 业务紧迫性 | 周期 10 / 20 / 40 ms，相位异步；截止期为下一次到达；一个包跨时隙累积互信息 | 自己的剩余比特、距截止期的时隙数 | **其他 UE 有多紧迫** |
| 相互干扰 | 单 AP 接收，TIN 解码，按子信道的 SINR | 上一时隙各子信道的公共 RSSI、自己上一次发送的结果 | 其他 UE 本时隙的选择（同时决策） |

**为什么三者必须一起协调**（已有证据中的典型失败）：
- 一个不紧急、信道好的 UE 进入某个子信道，而一个紧急、信号弱的 UE 正在那里单独发送，结果后者失败。
- 进入者从 RSSI 上通常看得到有人占用（余量 3–10 dB），但看不出对方有多紧迫，而它自己的信道在那里又正好最好。
- 反过来，静态独占的配置授权消除了干扰，却不能跟随信道；它的失败集中在需要按信道选子信道的弱 UE 上。

## 3. 已有证据：瓶颈在哪里（描述性，只用已读集合）

### 3.1 信息阶梯上的位置

exp010-eval512（开发池 4,000–4,511，512 个部署），N = 8，ε = 0.01：

| 信息条件 | 方法 | F_{0.01}(8) |
|---|---|---|
| L2：统计信息，静态独占（TSCAI 加配置授权） | CG / **CG-opt** | 0.805 / **0.848** |
| L0：本地观测，手写规则 | best_local | 0.895 |
| L0：本地观测，模仿 N_EDF | IL（EXP-010） | 0.913 |
| L0：本地观测，学习 | A-mix / M | 0.923 / 0.934 |
| L∞：集中式逐时隙调度 | N_EDF | 0.992 |

探针（开发切片 1,000–1,399，另一组部署，所以数值不能与上表直接相减）：在不重新训练的策略上加 1 比特紧急标志与手写让路规则（L0 + L1），A-mix 的 F(8) 从 0.922 提到 0.949（标志在碰撞中丢失时为 0.945，要求 SINR ≥ 0 dB 才能读出时为 0.933）。

### 3.2 三个因素各自的证据

1. **信道机会：静态配置不能跟随衰落**（RES-DSA05-CG-OPT §6）
   - 优化分配之后，CG-opt 在资源共享上的损失大部分消失（N = 8 时，不含弱 UE 的失败部署从 28 个降到 8 个）。
   - 剩下的差距中，A-mix 能满足、CG-opt 不能的部署约 80% 含有"独占整个资源格也 > 0.01"的弱 UE。这些部署需要按信道选子信道。
2. **业务紧迫性：本地观测下看不到别人的紧迫性**
   - 学习策略失败的部署几乎都是弱 UE 部署，N_EDF 能满足其中除物理上不可行的以外全部（CG 报告 §5）。
   - 没有证据表明差距来自训练（RES-DSA05-EXP010）：用同一个本地 Actor 直接模仿 N_EDF，F(8) 为 0.913，不高于 A-mix；两者失败的部署几乎相同。
   - EXP-006、008、009 的各种训练方案下，学习策略的 F(8) 都在约 0.92–0.94。
   - 这些都支持"差距来自信息"的解释，但没有直接证明。
3. **相互干扰：进入者看得到占用，看不出紧迫**（RES-DSA05-PROBE-BROADCAST §1 第 5 点）
   - 失败 UE 被进入时，该子信道上一时隙的 RSSI 在 3–10 dB 余量的占 73%–84%；进入者几乎都不紧急（0.4%–1.1%）。
   - 紧急标志的增益主要来自"阻止不紧急的 UE 进入一个单独发送的紧急 UE 所在的子信道"，干预只占 0.05%–0.6% 的发送。
   - 标志不必在碰撞中送达，但必须在低信噪比下可读，因为紧急 UE 多是远处的弱 UE（RES-DSA05-PROBE-FLAGLOSS）。

## 4. 核心贡献与可检验的假设（第 3 版重写）

### 4.1 不作为贡献的部分

文献依据见[文献笔记](literature-problem-side_20260926.md) §1.5 与 §2.1（2026-10-10 重写）。

- **目标本身**：XR-SBPC（WCNC 2025）与 SeqDQN（EuCNC 2023）都以按期交付为目标。改用可靠性目标有助于组织论文，但不增加新颖性。
- **问题组合**："异步周期业务 + 截止期 + 分布式 MARL"已有覆盖：
  - SeqDQN：上行，碰撞信道；
  - XR-SBPC：另有子信道、功率与跨时隙累积服务。
- **单独的最差用户目标**：DCGFRA（TCCN）已经以最差用户的丢包率为目标（min-max）。
- **按紧迫性让路的原则**：已有 DCGFRA（按自身优先级调整接入）、SMART（SPAWC 2019）、black burst（JSAC 1999），以及 NR 的上行取消指示（DCI 2_4）。
- **用学习减少信令**：Valcarce 与 Hoydis（TCCN 2021）、Mota 等（2022）、Mostafa 等（2023）、Uyoata 等（EuCNC 2025）。

### 4.2 核心贡献

即 §1 的核心表述，分为三部分：

| 部分 | 内容 | 与最接近工作的区别 |
|---|---|---|
| 对象：紧迫状态摘要 | 每次发送附带 1 比特紧迫标志，AP 按子信道汇总为 K 比特广播；在低信噪比下仍可读出 | DCGFRA 指出精确求解需要共享优先级，但为保持免授权的开环操作而放弃；XR-SBPC 观测邻居的动作（约 5N 比特/时隙），不观测紧迫性；学习信令的工作让消息内容由训练决定 |
| 用法：由摘要驱动的分布式协调 | 不紧急的 UE 根据摘要避开紧急 UE 所在的子信道，或推迟发送；主方法学习对摘要的响应，NR 式强制让路作为对照 | 让路原则本身不新（§4.1）。可贡献的是它在衰落、多子信道、跨时隙累积服务下怎样起作用、何时失效 |
| 解释：收益的来源与成立条件 | 信息匹配对照、机制诊断、接收条件测试 | 现有工作各自固定一种信息结构。在本次检索范围内，没有找到在同一场景下按信息内容与接收条件逐级比较的工作 |

### 4.3 摘要的设计依据

- **来自集中调度**：
  - N_EDF 每个时隙按松弛量对有包的 UE 排序，依次给每个 UE 分配它最好的空闲子信道；所以一个 UE 不会拿走已分给更紧急 UE 的子信道。
  - 本地 UE 看得到自己的松弛量和各子信道的功率，缺的正是"这个子信道上有没有比我更紧急的人"（§3.2 第 3 点）。
- **当前的压缩方式**：
  - 用绝对门限（slack < 3 个时隙）代替相对次序；
  - 上行 1 比特，下行按子信道 OR 汇总为 K 比特。

  它是 N_EDF 排序信息的最粗近似。
- **为什么必须在低信噪比下可读**：
  - 紧急 UE 多是远处的弱 UE。探针中，要求 SINR ≥ 0 dB 时，只有 17%–42% 的紧急标志能被读到，N = 8 的增益基本消失（RES-DSA05-PROBE-FLAGLOSS）。
  - 所以接收条件不是实现细节，而是摘要设计的一部分。
- **可以深入的方向：提高分辨率**。
  - 例如按松弛量分级，每个子信道多于 1 比特，看最差 UE 的可靠性随比特数怎样接近 N_EDF。
  - 这需要另写设计（§7 第 3 项）。不在 EXP-011 中做，也不能在看到 EXP-011 的结果后临时加入。

- H-S2：占用内容与紧迫内容相当时，结论改为"检测到的占用已经足够"，摘要的内容随之改变。
- H-S3：信息更多的 XR-SBPC 在最差 UE 上更好时，结论改为"信息开销与可靠性的取舍"，不写成全面更好。

## 5. 指标（读取确认集之前冻结）

第 2 版起，首要指标是最差 UE 违约率 P2，F_{0.01}（P1）只用于服务达标评价。编号沿用第 1 版，以便对照。

### 5.1 首要指标：最差 UE 违约率（P2）

- **定义**：每个部署中违约率最高的 UE 的违约率，w = max_i V_i / M_i。V_i 是 UE i 未按期完成的计分包数，含物理上无法送达的包；M_i 是它的计分包数。
- **首要统计量**：w 在部署间的平均（原始尺度），方法间的配对差值及其区间（§5.4）。同时报告相对变化（两方法均值之比），便于解读。
- **不依赖任何违约率门槛**：违约率的任何下降都计入，不论是否跨过 1%。
- **为什么用原始尺度的平均**：对数尺度更灵敏，但 w 大量为 0，取对数需要人为选一个偏移量，这又多了一个可调的选择；所以对数尺度只作敏感性分析。

### 5.2 服务达标评价：F_{0.01}（P1）与 N\*_{0.01}

- **P1**：F_ε(N) 为全部 UE 违约数都不超过允许值 ⌊ε·M_i⌋ 的部署比例。服务达标评价用 **ε = 0.01**（2026-10-10 用户决定），与此前一直使用的服务要求相同。
- 它本身也是最差 UE 指标（"最差 UE 满足 ε"的部署比例）；ε ∈ {0.02, 0.03, 0.05} 的曲线只作描述。
- **N\*_{0.01}**：F_{0.01} 首次低于 0.95 的网格点的前一个网格点，定义同协议 v2。
- 两者都必须报告，但**不进入成败判据**。

### 5.3 预先写定的敏感性分析与次要指标

- **针对首要指标的敏感性分析**：
  - w 的 90% 分位；
  - 去掉"对任何策略都不可行"的部署后重算平均；
  - 对数尺度 log₁₀(w + δ) 的平均，δ 在协议修订中写定。
- **防止牺牲其他 UE**：全部 UE 的平均违约率必须报告。如果首要指标改善而它显著变差，报告须讨论这一取舍；它不作为成败门槛。
- **其他次要指标**：
  - 最差 5% UE 的平均违约率；
  - P2、P1 随 N 的变化（负载适应性与可扩展性）；
  - 按 UE 平均信噪比与业务类别分组的失败比例；
  - 机制诊断：让路率、碰撞类型、失败 UE 受到的进入（H-M1）。
- **解释收益的分析**（第 3 版加入，与 §4.4 的假设对应）：
  - **信息开销对 P2 的前沿**（论文的核心图）：每个 N 一张图。横轴是每个时隙的信息比特数（§6.4），纵轴是 P2。点依次为：
    - CG-opt：L2，只在配置时下发授权；
    - L0：M、XR-SBPC L0；
    - L0 + 摘要：提出的方法、XR-SBPC + 摘要；
    - XR-SBPC 信息更多变体；
    - N_EDF。
  - **信息 × 算法对照**：MAPPO 与 XR-SBPC 各在 L0 与 L0 + 摘要下训练，分出信息效应与算法效应（H-S4）。
  - **接收条件测试**：
    - 读出门限取预先写定的网格，报告每个 N 上 P2 改善仍显著的最大门限，称为"门限边界"（H-B1）；
    - 网格与主接收条件在 EXP-011 中写定。

### 5.4 统计

- 沿用协议 v2：两层 bootstrap，部署在方法间配对，学习方法的训练种子各自重抽，10,000 次，种子 20,260,930。
- 每个 UE 在 20,000 个计分时隙中有 2,000、1,000、500 个包（周期 10、20、40）。最差 UE 违约率是多个带噪估计的最大值，会偏高；方法间用同一批衰落与执行种子配对，比较差值。
- w 随 N 增大也有机械的上升（UE 越多，最大值越大）。所以 P2 只在同一个 N 内比较方法；跨 N 的变化只作描述，并与最差 5% UE 的平均违约率对照。

### 5.5 研究成败的判据（框架层面；具体检验与界限在协议修订与各实验设计中预先写定）

1. **可靠性**：在确认集上，提出的方法相对每个改编的学习方法与 CG-opt，在预先写定的负载集合上，首要指标 P2 的配对差值显著有利（最差 UE 违约率更低）。
   - 负载集合按各方法的 P2 不退化的范围选（例如 N = 6–16），**不按 1% 门槛选**；
   - 多个 N 的判定规则（每个 N 都显著，或把各 N 合成一个统计量）在协议修订中写定。
2. **来源**：
   - 同一算法下，加摘要后 P2 显著改善（H-S1）；在 MAPPO 与 XR-SBPC 两种算法上都成立时，才写"增益来自信息，而不是来自某一种算法"（H-S4）；
   - 机制检验（H-M1、H-M2）用 P2 衡量；去掉摘要后增益消失或显著变小。
3. **信息开销**：与信息更多的 XR-SBPC 相比，开销明显更低，P2 不更差（H-S3，非劣界限在 EXP-012 中写定）。
4. **成立条件**：接收门限与负载上的边界按预先写定的网格报告（H-B1、H-B2）。
   - 它们是解释，不是成败门槛。
   - 但若在主接收条件（EXP-011 写定）下 P2 没有显著改善，第 1 项即不成立，不能改用更乐观的接收条件来满足它。
5. **服务达标**：报告 P1 与 N\*_{0.01}。**达不到 0.95 不等于研究失败**，但须如实报告。

## 6. 方法与比较对象

### 6.1 提出的方法（框架层面）

- **观测**：L0 本地观测，加紧迫状态摘要。摘要由两部分组成：
  - 每次发送附带的 1 比特上行标志；
  - 每个子信道 1 比特的下行广播。

  接收模型在 EXP-011 中预先写定，含低信噪比可读性。
- **协调**：由摘要驱动。
  - 主方法学习对摘要的响应。
  - NR 式的强制让路作为可解释的对照：不紧急的 UE 遇到被标记的子信道即推迟，语义接近 DCI 2_4。
  - 两者中哪个进入最终确认，按 EXP-011 预先写定的规则选择。
- **训练**：沿用 M 的流程。
  - 混合 N 训练，静态困难分层采样，在登记的筛选集上按 N 选检查点，超参数相同。
  - 协议 v2 §4 的 2026-10-04 补充允许这种方式；EXP-009 第 1 步按预先写定的规则保留了混合训练。
  - 第 2 版此处写"每个 N 分别训练"，是错的，第 3 版更正。
