# DSA05 研究框架修订：有限本地信息下按期交付可靠性的分布式协调

状态：**已批准（第 1 版，2026-10-10）**。用户同时决定：主要 ε = 0.01；最终确认集为 v2-confirm1（§9）。§9 的其余各项在相应的实验设计中决定。

- 本文件规定研究目标、要解决的困难、贡献假设、指标与比较对象，是后续实验设计与论文表述的依据。
- 它不改变场景 v2.0 与协议 v2 的任何冻结数值。需要修改协议的地方列在 §8，在读取下一个确认集之前另立协议修订。
- §3 的数值都来自已读集合，只作描述。

## 1. 研究目标

- 针对时变衰落与多用户干扰下的**异步周期上行业务**，研究只用有限本地信息的**分布式资源分配**：每个 UE 决定子信道、发射功率与发送时机。
- 目标是提高有截止期的包的**按期交付可靠性**，**尤其关注可靠性最差的 UE**。
- 论文回答：一个方法怎样利用本地可得的信道状态、业务紧迫性与干扰反馈来做这三项决定；它带来多少可靠性增益，增益来自哪里。
- 比较对象：改编的现有学习方法，以及优化的配置授权基线 CG-opt。
- 考察不同的 UE 数 N，以评价负载适应性与可扩展性。
- 违约率目标（例如 1%）仍是服务要求之一，但**不再是判断研究成败的唯一标准**（§5.4）。

## 2. 要解决的困难

**UE 只能获得有限的本地信息，却必须在截止期前完成传输；与此同时，信道在变化，其他 UE 的资源选择又会改变干扰。算法需要协调信道机会、业务紧迫性与相互干扰，才能提高按期交付可靠性。**

三个因素在场景 v2.0 中的具体形式：

| 因素 | 场景 v2.0 中的体现 | UE 本地能看到的 | UE 看不到的 |
|---|---|---|---|
| 信道机会 | Jakes 衰落，f_D = 10 Hz；4 个子信道彼此独立；相干时间与业务窗口（10–40 ms）同量级 | 本时隙自己在各子信道上的增益 | — |
| 业务紧迫性 | 周期 10 / 20 / 40 ms，相位异步；截止期为下一次到达；一个包跨时隙累积互信息 | 自己的剩余比特、距截止期的时隙数 | **其他 UE 有多紧迫** |
| 相互干扰 | 单 AP 接收，TIN 解码，按子信道的 SINR | 上一时隙各子信道的公共 RSSI、自己上一次发送的结果 | 其他 UE 本时隙的选择（同时决策） |

**为什么三者必须一起协调**（已有证据中的典型失败）：
- 一个不紧急、信道好的 UE 进入某个子信道，而一个紧急、信号弱的 UE 正在那里单独发送，结果后者失败。
- 进入者从 RSSI 上通常看得到有人占用（余量 3–10 dB），但看不出对方有多紧迫，而它自己的信道在那里又正好最好。
- 反过来，静态独占的配置授权消除了干扰，却不能跟随信道；它的失败集中在需要按信道选子信道的弱 UE 上。

## 3. 已有证据：瓶颈在哪里（描述性，只用已读集合）

### 3.1 信息阶梯上的位置

exp010-eval512（开发池 4,000–4,511，512 个部署），N = 8，ε = 0.01：

| 信息条件 | 方法 | F_{0.01}(8) |
|---|---|---|
| L2：统计信息，静态独占（TSCAI 加配置授权） | CG / **CG-opt** | 0.805 / **0.848** |
| L0：本地观测，手写规则 | best_local | 0.895 |
| L0：本地观测，模仿 N_EDF | IL（EXP-010） | 0.913 |
| L0：本地观测，学习 | A-mix / M | 0.923 / 0.934 |
| L∞：集中式逐时隙调度 | N_EDF | 0.992 |

探针（开发切片 1,000–1,399，另一组部署，所以数值不能与上表直接相减）：在不重新训练的策略上加 1 比特紧急标志与手写让路规则（L0 + L1），A-mix 的 F(8) 从 0.922 提到 0.949（标志在碰撞中丢失时为 0.945，要求 SINR ≥ 0 dB 才能读出时为 0.933）。

### 3.2 三个因素各自的证据

1. **信道机会：静态配置不能跟随衰落**（RES-DSA05-CG-OPT §6）
   - 优化分配之后，CG-opt 在资源共享上的损失大部分消失（N = 8 时，不含弱 UE 的失败部署从 28 个降到 8 个）。
   - 剩下的差距中，A-mix 能满足、CG-opt 不能的部署约 80% 含有"独占整个资源格也 > 0.01"的弱 UE。这些部署需要按信道选子信道。
2. **业务紧迫性：本地观测下看不到别人的紧迫性**
   - 学习策略失败的部署几乎都是弱 UE 部署，N_EDF 能满足其中除物理上不可行的以外全部（CG 报告 §5）。
   - 没有证据表明差距来自训练（RES-DSA05-EXP010）：用同一个本地 Actor 直接模仿 N_EDF，F(8) 为 0.913，不高于 A-mix；两者失败的部署几乎相同。
   - EXP-006、008、009 的各种训练方案下，学习策略的 F(8) 都在约 0.92–0.94。
   - 这些都支持"差距来自信息"的解释，但没有直接证明。
3. **相互干扰：进入者看得到占用，看不出紧迫**（RES-DSA05-PROBE-BROADCAST §1 第 5 点）
   - 失败 UE 被进入时，该子信道上一时隙的 RSSI 在 3–10 dB 余量的占 73%–84%；进入者几乎都不紧急（0.4%–1.1%）。
   - 紧急标志的增益主要来自"阻止不紧急的 UE 进入一个单独发送的紧急 UE 所在的子信道"，干预只占 0.05%–0.6% 的发送。
   - 标志不必在碰撞中送达，但必须在低信噪比下可读，因为紧急 UE 多是远处的弱 UE（RES-DSA05-PROBE-FLAGLOSS）。

## 4. 贡献假设

### 4.1 不作为贡献的部分

- **目标本身**：XR-SBPC（WCNC 2025）同样最大化按期成功的包。改用可靠性目标有助于组织论文，但不增加新颖性。
- **问题组合**："异步周期业务 + 子信道与功率联合选择 + 跨时隙累积服务 + 分布式 MARL"已由 XR-SBPC 覆盖（文献笔记 literature-problem-side §2 已据此修改）。
- **单独的最差用户目标**：DCGFRA（TCCN）已经以最差用户的丢包率为目标（min-max），做分布式资源选择与功率控制。

### 4.2 C1 信息需求（主要贡献）

问题：**分布式 UE 要保护最差 UE 的按期可靠性，最少需要什么信息？**

- **H-I1（本地信息不够）**：只用本地信息（L0：自己的 CSI、自己的紧迫性、公共 RSSI 与自己的发送结果）时，最差 UE 的可靠性受限于看不到其他 UE 的紧迫性，而不是受限于训练。已有支持见 §3.2；正式检验在 EXP-011 中预先登记。
- **H-I2（压缩的紧迫信息足够有效）**：一个低开销、NR 可实现的紧迫信息（每个时隙下行 K = 4 比特、每次上行发送附带 1 比特；对应高优先级 SR 与 DCI 2_4），在预先写定的接收模型下（含碰撞丢失与低信噪比可读性），显著提高最差 UE 的可靠性。
- **H-I3（比邻居动作信息便宜）**：XR-SBPC 要观测邻居上一帧的子频带与功率。在单 AP 上行中，这相当于 AP 每个时隙广播全部 UE 的选择，约 N·⌈log₂21⌉ = 5N 比特（N = 8 时 40 比特）。与此相比，H-I2 的信息开销小得多，而最差 UE 的可靠性不更差。
- **否定时怎么写**：如果信息更多的 XR-SBPC 在最差 UE 上更好，结论改为"信息开销与可靠性的取舍"，不写成全面更好。

### 4.3 C2 协调机制（主要贡献，与 C1 配套）

问题：**拿到紧迫信息之后，UE 之间怎样协调，才能保护最差 UE？**

- **H-C1（让路机制）**：增益来自"不紧急的 UE 避开紧急 UE 所在的子信道或推迟发送"。可检验的量：让路率、谁给谁让路、失败 UE 受到的进入与共处碰撞、让路后被推迟 UE 自身的可靠性。
- **H-C2（消融）**：去掉紧迫信息，或保留信息但去掉协调方式，增益消失或显著变小。
- 探针中的让路是手写规则（确定性推迟在占用广播 B2 下造成同步再进入，反而有害）。正式方法中的协调方式（学习得到，或规则加学习）在 EXP-011 中写定，并保留手写规则版本作为可解释的对照。

### 4.4 C3 可靠性优化方式（次要，视实验结果）

- **H-O1**：直接针对最差 UE 训练（例如按 UE 违约风险加权的奖励、逐 UE 对偶权重或最大最小目标），比 XR-SBPC 式的成功包总数目标显著改善最差 UE，而平均可靠性没有明显下降。
- 目前没有实验支持；EXP-008 的训练信号筛选（固定 OBS 下）也没有找到有效因素。
- 只有在跨时隙累积服务、异步周期业务下得到 DCGFRA 未覆盖的具体结论时，才写成贡献。

### 4.5 与最接近工作的区别（新目标下）

| 工作 | 目标 | 执行时信息 | 协调方式 | 最差 UE |
|---|---|---|---|---|
| XR-SBPC（WCNC 2025） | 按期成功包数之和 | 自己的即时信道、逐子频带干扰、**邻居上一帧的子频带与功率** | 隐式（共享策略、邻居动作观测） | 只报告用户满足率 |
| MARLV2X（JSAC 2019） | V2I 和容量加 V2V 交付率 | 本链路与干扰链路的即时信道、上一时隙干扰、剩余负载与时间 | 隐式（共享奖励） | 无 |
| DCGFRA（TCCN） | 最差用户丢包率 | 本地队列与接入历史；模型辅助训练 | 优先级加导频选择与功率 | 目标本身 |
| MARLSPA（TCOM 2025） | 平均时延 | 邻域观测交换 | 邻域信息交换 | 无 |
| CG-opt（NR 配置授权） | 字典序最小化预测中断概率 | 统计信息（TSCAI） | 静态独占 | 目标本身 |
| **DSA05（拟）** | **最差 UE 的按期可靠性** | **本地 CSI、自己的紧迫性、公共 RSSI，加压缩的紧迫信息（K + 1 比特）** | **按紧迫性让路（显式机制）** | **主要指标** |

其他区别（单 AP 上行多址、异构周期、冻结协议与确认集）仍然成立，但属于场景与评价，不是方法贡献。

## 5. 指标（读取确认集之前冻结）

### 5.1 主要指标

- **P1 最差 UE 的可靠性曲线**：F_ε(N) 为全部 UE 违约数都不超过允许值 ⌊ε·M_i⌋ 的部署比例，报告 ε ∈ {0.01, 0.02, 0.03, 0.05} 的整条曲线。
  - 它本身就是最差 UE 指标：F_ε 等于"最差 UE 满足 ε"的部署比例，整条曲线近似于最差 UE 违约率在部署间的分布函数。
  - **主要 ε = 0.01**（2026-10-10 用户决定，§9 第 1 项），与此前一直使用的服务要求相同。其余 ε 只作描述。
- **P2 最差 UE 违约率**：每个部署中违约率最高的 UE 的违约率，报告它在部署间的平均与 90% 分位，以及方法间的配对差值。

### 5.2 辅助指标

- 最差 5% UE 的平均违约率；全部 UE 的平均违约率。
- 各 ε 下的 N\*_ε（承载能力），以及 P1、P2 随 N 的变化（负载适应性与可扩展性）。
- 按 UE 平均信噪比与业务类别分组的失败比例。
- 信息开销：每个时隙的下行与上行比特数（§6.4）。
- 机制诊断：让路率、碰撞类型、失败 UE 受到的进入（H-C1）。

### 5.3 统计

- 沿用协议 v2：两层 bootstrap，部署在方法间配对，学习方法的训练种子各自重抽，10,000 次，种子 20,260,930。
- 每个 UE 在 20,000 个计分时隙中有 2,000、1,000、500 个包（周期 10、20、40）。最差 UE 违约率是多个带噪估计的最大值，会偏高；方法间用同一批衰落与执行种子配对，比较差值。

### 5.4 研究成败的判据（框架层面；具体检验与界限在各实验设计中预先写定）

1. **可靠性**：在确认集上，提出的方法相对每个改编的学习方法与 CG-opt，在门槛附近的负载（N = 6–12）上，P1（主要 ε）与 P2 的配对差值显著有利。
2. **来源**：机制检验（H-C1、H-C2）把增益归于紧迫信息与协调方式；消融后增益消失或显著变小。
3. **信息开销**：与信息更多的 XR-SBPC 相比，信息开销明显更低，最差 UE 的可靠性不更差（非劣界限在 EXP-012 中写定）。
4. **服务要求**：报告各 N 是否满足主要 ε 下 F ≥ 0.95，以及 N\*_ε。**达不到 0.95 不等于研究失败**，但须如实报告。

## 6. 方法与比较对象

### 6.1 提出的方法（框架层面）

- 观测：L0 本地观测，加 L1 压缩的紧迫信息（接收模型在 EXP-011 中预先写定，含低信噪比可读性）。
- 协调：按紧迫性让路的显式机制（学习得到，或规则加学习），同时保留手写规则版本作对照。
- 训练：沿用已验证的 MAPPO 流程，每个 N 分别训练，超参数相同，只按 N 选检查点（协议 v2 §4 的 2026-10-04 补充）。

### 6.2 改编的现有学习方法

| 方法 | 改编方式 | 状态 |
|---|---|---|
| **XR-SBPC**（必选） | SAC-Discrete，原文的可靠性奖励（与新目标一致）；两个信息变体：**信息匹配**（L0，同 EXP-005）与**信息更多**（AP 每个时隙广播全部 UE 上一时隙的子信道与功率） | 需在 v2 上重新实现与训练（EXP-005 是 v1 的能耗口径） |
| MAPPO，L0（A-mix、M） | 循环 MAPPO，本地观测（与 MARLSPA 的算法同类） | 已有 |
| MARLV2X（可选） | 指纹 DQN，共享奖励；信息按 L0 匹配 | 待决定（§9 第 2 项） |

IL（EXP-010）只作诊断，不作比较对象。

### 6.3 非学习的比较对象

- **CG-opt**：优化的配置授权（L2），用来排除"静态基线太弱"的质疑，并量化"跟随衰落"的价值。
- **best_local**：按 N 校准的本地规则（L0）。
- **N_EDF**：集中式逐时隙调度（L∞），是参照上限，不是竞争对手。

### 6.4 信息开销

| 方法 | 下行（每个时隙） | 上行（附带） |
|---|---|---|
| L0：MAPPO、XR-SBPC 信息匹配、best_local | K 个子信道的公共 RSSI 与自己的发送结果（场景已有） | 无 |

| CG-opt | 只在配置时下发授权 | 无 |
| N_EDF | 集中式调度，逐时隙授权 | 需要全部 UE 的队列状态 |
