# EXP-DSA05-008 第 1 轮：训练信号的单因素筛选

## 1. 结论（按设计 §4.2、§4.3 预先写定的规则）

1. **没有因素被保留，B1 = R0。**
   - 五个因素相对 R0 的平均 ΔS_near 在 −0.011 到 +0.003 之间，都没有达到 +0.01 的门槛；
   - F3、F5 只差第 1 条（改善幅度），其余各条都满足；F1、F2、F4 还未通过退化保护。
   - 按设计，这只表示在 500 万时隙、两个种子和当前规则下没有通过，**不能写成这些机制无效**。
2. **R0 与 EXP-006 第 1 阶段的 A 逐位相同**（§4.4）：
   - 两个种子各 5 个检查点的全部张量与随机数状态相同；
   - 训练日志 2,791 行全部相同；
   - R0 选中检查点在旧验证集上的结果与第 1 阶段记录完全相同。
   - 第 1 轮的对照可信，默认路径与评估路径都没有改变。
3. **训练诊断（§8，描述性）显示门槛区几乎没有奖励事件**：
   - R0 训练到 300 万时隙以后，在 N = 6、8 的固定诊断 rollout 中，每个 N 的 12,800 个环境时隙里只有 0–2 个时隙出现违约；N = 20 有 770–1,280 个；
   - 训练中 N = 6 的 rollout 有 97–99% 没有任何违约，N = 8 为 93–97%；
   - R0 总梯度方向上，N = 16、20 的投影份额合计 0.93–1.03，N = 6、8 合计为 −0.01–0.01。
4. **F1、F2 确实改变了它们针对的东西，但门槛区可行率没有提高**：
   - 在 500 万检查点上，N = 6、8 的投影份额合计，F1 为 0.02–0.08，F2 为 0.13–0.41，R0 只有 −0.01–0.00；
   - 但 F1、F2 的 S_near 分别比 R0 低 0.011 和 0.008。
   - 结合第 3 条，较为一致的描述是：**门槛区的问题更像是训练中几乎遇不到有信息的事件，而不是这些事件的信号被大 N 淹没**。重新加权只能放大那里以价值残差为主的优势。这是描述性的解释，不是因果结论。
5. **其他观察**：
   - F5 用约 1/4 的优化器步数和少约 17% 的墙钟时间达到与 R0 相同的水平（S_near +0.003，末段 +0.020），但没有达到保留门槛；
   - F1、F4 早期学得快得多（100 万时 S_near 0.891、0.802，R0 为 0.655），但没有更高的终点；
   - F3 的方差下限在整个训练中都没有触发。
6. **下一步按设计是第 2 轮**：在 B1 = R0 上比较 A/C × 600/2,400 时隙，A-600 复用 R0 的两个运行。见 §8 的选项。

### 5.3 ValueNorm

F3 的方差下限在两个种子的 2,791 个 rollout 中都没有触发。训练末期 rollout returns 的标准差约 0.15–0.19，运行统计的标准差约 0.29–0.30，后者高于前者，与 §3.1 预计的统计滞后一致。

## 6. 解释与局限

- **规则层面**：没有因素通过，B1 = R0。门槛 0.01、两个种子、256 个部署是预先写定的探索性规则；F3、F5 的差值远小于门槛，不能据此判断它们有无小幅效应。
- **机制层面**（描述性）：
  - §5 显示门槛区在训练中几乎没有违约事件；
  - F1、F2 把更新方向转向门槛区后，门槛区可行率没有提高，F1 反而略降；
  - 两者合起来，更支持设计 §1.1 中"那里的信号本来就稀少"的解释，而不是"信号被大 N 淹没"。
  - 但诊断 rollout 从训练池随机抽取部署，评估中失败的往往是少数难部署（边缘快类 UE）。"遇不到难部署"与"遇到了也学不会"在本轮无法区分。
- **其他局限**：
  - 筛选集已被本轮反复使用 60 次，选中值有向上的选择偏差；
  - 两个种子不足以判断训练随机性；
  - 第 1 轮所有条件的 500 万终点都在 0.94–0.95 附近，仍低于 EXP-006 长训模型在验证集上的水平，所以第 1 轮的比较只代表 500 万预算下的情况。
