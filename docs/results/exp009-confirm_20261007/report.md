# EXP-DSA05-009 确认集评估（v2-confirm2）

## 1. 结论（按设计 §6 与 EXP-008 §7.3 预先写定的判读）

1. **H1、H2、H3 都不成立**，按预先写定的判读表，这是"当前机制、预算、筛选规则下的负结果"。它不能证明固定 OBS 不可行，也不能证明信用分配是必需的。
   - **H1**：N\*_{0.01}(M) = 6，等于 N\*_{0.01}(A-mix) = 6，不成立。
   - **H2**：F_{0.01}(8) 的差 M − A-mix = +0.006，95% 区间 [−0.011, +0.026]，下限不大于 0，不成立；N = 6 的非劣部分成立（+0.009，区间 [−0.003, +0.021]，下限大于 −0.01）。
   - **H3**：N\*_{0.01}(M) = 6，等于 N\*_{0.01}(best_local) = 6，不成立。
2. **M（S1，混合训练加静态困难分层，500 万时隙）在门槛区与 A-mix（EXP-006 长训，2,000 万时隙）相当，在高负载上较差**：
   - F(6) +0.009，F(8) +0.006，F(10) +0.020，F(12) −0.005，F(16) −0.095；
   - 门槛区的指标都与 A-mix 无显著差别：S_near +0.007 [−0.005, +0.021]，S_thr +0.008 [−0.012, +0.029]。
   - 这不是等效性检验，不能写成"用 1/4 的训练量达到同等水平"。
3. **两种学习方法都在可行比例上显著优于最好的本地规则，但 ε = 0.01 的容量点估计没有提高**：
   - M 对 best_local：F(8) +0.079，F(10) +0.167，F(12) +0.295；S_near +0.056 [+0.039, +0.076]，S_thr +0.144 [+0.122, +0.167]；
   - 但三者的 N\*_{0.01} 都是 6：best_local 在本集合上 F(6) = 0.950，正好压在门槛上；M 与 A-mix 的 F(8) 为 0.941 和 0.935，都略低于 0.95。
   - N\* 的 bootstrap 分布：M 为 6 的比例 0.74、8 为 0.26；A-mix 为 6 的比例 0.91、8 为 0.09；best_local 为 4 的比例 0.44、6 为 0.56。M − best_local > 0 的比例为 0.65，M − A-mix > 0 的比例为 0.19。这些频率不是后验概率。
4. **ε = 0.05（描述性）**：M 的 N\* = 10，A-mix = 12，best_local = 8，N_EDF = 20。在宽松的可靠性要求下，A-mix 更好：S_006 的差 M − A-mix = −0.024 [−0.041, −0.009]。
5. **最后检查点（M_last）不稳定**：N\*_{0.01} = 4，F(6) = 0.925。按 N 选模在相当程度上弥补了训练末期的下降（第 2 步报告 §1 第 4 条）。
6. **N_EDF = 20**（两版相同）。学习方法与中央参照之间的差距仍为 14 个 UE。

## 5. 判读

- **按预先写定的判读表**：全部未满足，是负结果。不能证明固定 OBS 不可行，也不能证明信用分配是必需的。
- **EXP-009 的机制**（第 1、2 步与本评估合起来，描述性）：
  - 逐 N 训练（同 N 经验约 7 倍）没有提高门槛区；
  - 在混合训练中提高困难部署的比例，在筛选集上有小幅提高，但在确认集上与更长训练的混合模型没有显著差别；
  - PLR 不比静态分层更好。
- **整条固定 OBS 学习路线**（EXP-006、008、009，跨 N 单一策略与按 N 两种口径）：
  - 学习方法在 N = 4–16 上的可行比例显著、大幅高于最好的本地规则；
  - 但在 ε = 0.01 下，N = 8 的可行比例一直停在约 0.93–0.94，没有越过 0.95；
  - 容量点估计因此一直与最好的本地规则持平，为 6。
  - 这条门槛对训练信号、更新方式、对偶反馈、回合长度、按 N 实例化、困难部署抽样的改变都不敏感。
- **与中央参照的差距不变**：N_EDF = 20，差 14 个 UE。
