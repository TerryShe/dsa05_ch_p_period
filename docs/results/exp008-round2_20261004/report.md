# EXP-DSA05-008 第 2 轮：A/C 与训练回合长度；EXP-008 的结论

## 1. 结论（按设计 §5.3 与 §6 预先写定的规则）

1. **B2 = A-600，即 R0（EXP-006 的变体 A、600 时隙回合）。**
   - A-2400、C-600、C-2400 都没有通过 §4.2 第 2、4、5 条的退化保护（相对 A-600），候选只剩 A-600。
   - 这个结果不依赖退化保护的边界情形：A-2400 的平均 S_near 为 0.949，A-600 为 0.948，即使 A-2400 通过保护，两者也在 0.005 的并列带内，按规则仍取较简单的 A-600。
2. **按设计 §6，EXP-008 到此结束**：
   - 第 1、2 轮都没有保留任何训练变化，不做 2,000 万时隙的长训；
   - 不读取确认集 v2-confirm1，它仍未被读取；
   - 本实验以校准结果结束，不包装成新方法。
3. **C（逐 UE 对偶反馈）明显更差**：
   - S_near 比 A-600 低 0.068（C-600）和 0.027（C-2400）；
   - 验证集 F(8) 低 0.117 和 0.008，S_thr 低 0.113 和 0.031。
   - 训练日志显示，这种 C 的 μ 在训练回合中几乎不动（§5），实际上相当于每个回合给每个 UE 一个 [0, 50] 内的随机奖励权重，而执行时从 μ0 = 5 开始。这是一个具体的机制缺陷，不能据此否定一般的逐 UE 约束方法。
4. **A-2400 与 A-600 在门槛区相当，在中等负载上较好**（描述性）：
   - S_near +0.001，末段 +0.017；
   - 验证集 F(10) +0.039、F(12) +0.047、S_thr +0.021；
   - 只因 F(4) 下降 0.016（两个种子合计 2 个部署）未通过第 2 条；
   - 它抽到的不同部署只有 A-600 的约 1/4（2,084 对 8,306）。

## 5. C 的 μ 诊断（§8）

训练最后 200 个 rollout 中，μ 按业务类别与回合四分位的平均值：

| 运行 | 快类（第 1→4 个四分位） | 中类 | 慢类 | μ = 0 或 50 的比例 |
|---|---|---|---|---|
| C-600 种子 101 | 25.5 → 26.3 | 25.1 → 25.7 | 25.1 → 26.3 | ≤ 0.01 |
| C-600 种子 202 | 25.6 → 26.5 | 25.7 → 26.3 | 24.9 → 26.4 | ≤ 0.01 |
| C-2400 种子 101 | 25.8 → 25.0 | 25.2 → 25.4 | 25.6 → 27.6 | ≤ 0.06 |
| C-2400 种子 202 | 24.3 → 22.9 | 25.0 → 25.0 | 26.0 → 27.8 | ≤ 0.06 |

- **机制**：
  - 每个结算的包使 μ 改变 η(c − ε)：准时 −0.02，违约 +1.98（η = 2，ε = 0.01）。
  - 600 时隙的回合内，没有违约的快类 UE 共下降约 1.2，中类约 0.6，慢类约 0.3。
  - 所以训练中的 μ 基本停留在回合开始时从 [0, 50] 均匀抽取的值，所有类别、所有回合位置的平均都约为 25。
  - 2,400 时隙的回合中，快类的 μ 略有下降，慢类略有上升（大 N 下慢类有违约）。
- **后果**：
  - 训练中，μ 实际上是每个回合随机给定的逐 UE 奖励权重，而不是反映该 UE 额度使用情况的反馈；
  - 执行时 μ 从 5 开始，与训练中的分布（约 25）明显不同；
  - 设计 §5.1 已指出这种 μ 不是精确的剩余额度，本轮的日志量化了这一点。
- **判读边界**：
  - 这说明的是现有 C 的具体参数与更新规则不适合；
  - 不能推论"逐 UE 约束方法无效"；
  - 按设计，不在本实验内调整 η、μ 初值或更新规则。

训练侧其他统计（训练最后 200 次迭代、最后 500 个 rollout）：

| 运行 | 包违约率（N = 6 / 8 / 16 / 20） | 无违约 rollout（N = 6 / 8） | 不同部署数 |
|---|---|---|---|
| A-2400 种子 101 | 0.000% / 0.047% / 1.68% / 6.66% | 0.98 / 0.97 | 2,083 |
| A-2400 种子 202 | 0.073% / 0.122% / 0.83% / 7.99% | 0.97 / 0.92 | 2,084 |
| C-600 种子 101 | 0.056% / 0.048% / 1.50% / 9.39% | 0.97 / 0.95 | 8,320 |
| C-2400 种子 101 | 0.023% / 0.043% / 1.48% / 8.21% | 0.97 / 0.91 | 2,084 |

所有条件下，门槛区（N = 6、8）的训练 rollout 都有 91–98% 没有违约，与第 1 轮相同。更长的回合没有改变这一点。

## 6. EXP-008 的总结

| 问题 | 结果（500 万时隙、两个种子、exp008-screen256） |
|---|---|
| 训练信号的尺度与权重（F1–F4）能否提高门槛区可行率？ | 不能。ΔS_near −0.011 到 −0.001；F1、F2 改变了梯度构成，但门槛区可行率没有提高 |
| 不切 mini-batch（F5）？ | 门槛区持平（+0.003），用约 1/4 的优化器步数、少约 17% 的墙钟时间 |
| 现有的逐 UE 对偶反馈 C？ | 明显更差；训练中的 μ 几乎是静态随机权重 |
| 更长的训练回合（2,400 时隙）？ | A：门槛区持平，中等负载较好；C：比 C-600 好，但仍差于 A |
| 最终设置 | B2 = A-600，即 EXP-006 的变体 A |

- **能说的**：在固定 OBS 与当前预算下，调整训练信号的尺度、更新方式、现有对偶反馈或回合长度，都没有在门槛区超过 EXP-006 的变体 A。门槛区在训练中几乎没有违约事件，这个现象在所有条件下都存在。
- **不能说的**：
  - 不能说这些机制无效，因为规则是探索性的，种子与预算都有限；
  - 不能说固定 OBS 不可能提高 N\*；
  - 不能说信用分配一定是唯一出路。
- **没有使用确认集**：v2-confirm1 仍未读取。
- **未执行的设计步骤**：A-near 的重选（§6）只在需要与新方法正式比较时才有决策价值，本实验没有正式比较，所以没有执行。
