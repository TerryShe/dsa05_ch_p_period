# EXP-DSA05-009 第 2 步：在混合训练上的困难部署抽样

## 1. 结论（按设计 §5.4 预先写定的规则）

1. **S1（静态困难分层）被保留，M = S1。** P1、P2 没有被保留，它们只差第 1 条（改善幅度）。
2. **S1 相对 M0 的结果**（两个种子平均，按 N 选中的模型）：
   - S_near 0.962 对 0.950，提高 0.012（种子 101 +0.006，种子 202 +0.018），刚过 0.01 的门槛；
   - 在中等负载上的提高更大：F(10) +0.033，F(12) +0.055，F(16) +0.023；
   - N = 2、4 不变，末段 0.924 对 0.917。
   - 但筛选集上 F(8) = 0.944（种子 101 0.938，种子 202 0.949），仍低于 0.95，所以 S1 在筛选集上的容量点估计仍是 6，与 M0 相同。门槛区的改善是小幅的。
3. **P1、P2 的改善更小**：ΔS_near 分别为 +0.008、+0.006。
   - P2 的 PLR 得分在门槛区几乎全部为 0（N = 6 时缓冲区内全为 0），重放实际上退化为均匀抽取加陈旧度；
   - 在 N = 8 的一个种子上，P2 集中重放少数部署（一个部署被重放 144 次）。
4. **训练后期的不稳定**（描述性）：S1 种子 101 与 P1 两个种子在最后一个检查点（500 万）都明显下降，例如 S1 种子 101 的 F(8) 从 400 万时的 0.938 降到 0.801。按 N 选模取了 400 万的检查点；末段规则（400 万与 500 万的平均）仍通过。
5. **在 EXP-009 内的含义**：
   - 第 1 步：在同一 N 上增加经验的数量（逐 N 训练）没有帮助；
   - 第 2 步：在混合训练中提高困难部署的比例有小幅帮助；
   - 随策略变化的优先级（PLR）没有比静态分层更好。
   - 这些都只是筛选结果，是否成立要看确认集。
6. **下一步按设计 §6**：定型（S1 增加种子 303）、主基线 A-mix 在新筛选集上按 N 重选，然后冻结方法清单，读取确认集 v2-confirm2。见 §7。

## 4. 训练侧的采样器行为（设计 §7）

训练全程（每个 N 组约 1,190 个回合）与最后 500 个 rollout：

| 运行 | N = 8 每个 rollout 的违约次数 | N = 8 无违约 rollout | 被训练部署难度中位数（N = 8） | 采样器（N = 8） |
|---|---|---|---|---|
| M0（R0） | 0.04–0.08 | 0.93–0.97 | 约 4.26（均匀） | — |
| S1 101 / 202 | 0.18 / 0.12 | 0.87 / 0.90 | 2.47 / 2.49 | 困难层 581 / 569 次，没有重复部署 |
| P1 101 / 202 | 0.24 / 0.07 | 0.84 / 0.95 | 4.16 / 3.91 | 重放 589 / 544 次；访问最多 34 / 12 次 |
| P2 101 / 202 | 0.97 / 0.21 | 0.55 / 0.85 | 3.13 / 3.35 | 重放 590 / 545 次；访问最多 144 / 31 次 |

- **S1**：几乎每个回合都是新部署（约 1,190 个不同部署），一半来自困难层。门槛区的违约事件约是 M0 的 2–3 倍。
- **P1**：得分（|GAE| 平均）在所有部署上都非零，重放较分散。
- **P2**：门槛区的可避免违约极少，N = 6 时缓冲区得分全为 0，N = 8 时为 96–100%。重放主要由陈旧度与并列决定；少数非零得分的部署被反复重放，N = 8、种子 101 最多一个部署 144 次。

## 5. 判读与局限

- **规则层面**：S1 通过全部五条，刚过改善门槛（+0.0117）。两个种子、256 个部署的筛选集上，这样的幅度本身不足以说明有效；正式判读只在确认集上进行。
- **门槛**：S1 在筛选集上的 F(8) 仍低于 0.95。确认集上的 H1（N\* 高于 A-mix）需要 F(8) 越过 0.95，可能性不大；H2（F(8) 的提高有统计支持）需要约 1–2 个百分点的真实提高。
- **机制**：S1 与 P0 的对比说明，有用的似乎不是同一 N 上更多的经验，而是让困难部署（弱 UE）更常出现在混合训练中。但 S1 的标签只反映弱 UE，没有反映干扰协调；它在 N = 10–12 上的收益大于在门槛上。
- **PLR**：在本问题上，原文得分（P1）与 DSA05 得分（P2）都没有超过静态分层。P2 的得分在门槛区几乎全为 0，这是设计 §5.3 预见的局限；β = 0.1 的集中重放也在 P2 中出现。
- **稳定性**：训练末期的下降说明 500 万时的最后检查点不可靠，按 N 选模在一定程度上掩盖了这一点。定型的第三个种子与确认集会给出更多信息。
