# 优化的静态配置授权 CG-opt：结果报告

## 1. 结论

1. **按预先写定的解读（设计 §7.3），结果为"CG-opt 低于学习策略"**：
   - exp010-eval512 上，ε = 0.01 时 F(8; CG-opt) = 0.848 [0.816, 0.879]；
   - CG-opt − A-mix = −0.076 [−0.098, −0.054]，区间上限 < 0。
   - N = 6、8、10 三个负载下，CG-opt 都低于 A-mix、M 与 N_EDF，所有配对差值的区间都不含 0（§3.2）。
2. **优化的增益确实存在，按设计 §7.3，主表的 N_CG 改用 CG-opt**：
   - exp010-eval512 上，CG-opt − CG 在 N = 6、8、10 分别为 +0.008、**+0.043**、+0.086，区间都在 0 以上；
   - 逐部署看，CG-opt 比 CG 多满足 4、22、44 个部署，而且没有一个部署是 CG 满足、CG-opt 不满足的；
   - 验证集上 F_{0.01} 在 N = 8、10、12 提高 0.06–0.09，但 N\* 不变（ε = 0.01 时为 2，ε = 0.05 时为 8）。
3. **增益几乎全部来自资源共享；含弱 UE 的部署，优化无能为力**（§6）：
   - "弱 UE 部署"指含有独占整个资源格也 > 0.01 的 UE 的部署。
   - 不含弱 UE 的部署中，失败数在 N = 6、8、10 从 CG 的 6、28、72 降到 2、8、31。
   - 弱 UE 部署上，优化前后一样：单 UE 搜索没有让任何 UE 从 > 0.01 降到 ≤ 0.01，改进后的近似上限与 CG 报告的规则上限相同（0.898 / 0.852 / 0.818）。
   - CG-opt 填补了 CG 与近似上限之间差距的 92%（N = 8）与 63%（N = 10）；验证集 N = 8 时填满。
4. **因此，与学习策略的剩余差距基本就是"不能跟随衰落"**：
   - N = 8 时，A-mix 满足、CG-opt 不满足的部署每个种子层约 37–40 个。其中 29–32 个是弱 UE 部署，这种时机结构下任何静态分配都满足不了（在近似的意义下）；只有 7–8 个是资源共享造成的（CG 为 27–28 个）。
   - 失败的 UE 已经拿到了全部时机：N = 8 时 114 个失败 UE 的窗口占比中位数为 1.0（CG 为 0.9），平均信噪比中位数 3.4 dB。
5. **与手写本地规则相比，结果随负载变化**：
   - CG-opt − best_local 在 N = 6、8 为 −0.051、−0.047（区间都 < 0），N = 10 为 +0.051 [+0.023, +0.078]。
   - CG 报告中"CG 甚至低于 best_local"对贪心 CG 仍然成立；优化后，N = 10 时已高于 best_local。
6. **独立检验没有发现对样本库 A 的过拟合**（§5）：
   - 在 CG 的样本库 B 上重算，q^B − q^A 的平均在 N = 6、8、10 为 −0.00001 到 −0.00006；
   - 在 A 上 ≤ 0.01、在 B 上 > 0.01 的 UE 分别只有 1、0、3 个（3,072–5,120 个 UE 中）；
   - B 上的预测与实际违约率一致，例如 N = 8 时 0.0141 对 0.0149、0.0320 对 0.0324。
7. **求解在冻结的预算内完成，碰到时间上限的部署不影响 F**（§7）：
   - 2,240 个部署中，6 次求解碰到时间上限，1 次求解崩溃后按修正 3 重试并到最优，31 次碰到节点上限；全部搜索都到达局部最优。
   - 碰到时间上限的 6 个部署，CG-opt 与 CG 的可行性都相同：要么贪心解已经很好（最大 q^A ≤ 0.0041），要么在 N = 32 时完全不可行。
8. **对后续的含义**（判读已由用户于 2026-10-10 确认）：
   - 从 EXP-011 起，主表的 N_CG 用 CG-opt，贪心 CG 作为描述性结果保留；
   - 论文可以说：在 ε = 0.01 下，即使是按明确目标优化过的静态配置（而且是对它有利的理想化版本），也不如固定本地观测的学习策略；差距主要来自静态配置不能跟随衰落。
   - 两个集合都已读过，这是开发阶段的依据。正式比较放到下一个确认集（备用池 31,000 起），与 EXP-011 一起（设计 §5 第 3 层）。

| 项目 | CG | CG-opt |
|---|---|---|
| 时机数：快类 / 中类 / 慢类 | 5.35 / 9.50 / 19.2 | 5.60 / 9.19 / 17.3 |

| 同组的预测中断概率 / 实际违约率 | 0.0080 / 0.0097 | 0.0064 / 0.0076 |
| 每个回合因放不下而停止加时机的 UE（碎片） | 4.0 | 1.1 |
| 资源单元的分配比例 / 实际使用比例 | 99.8% / 36.7% | 98.1% / 37.4% |
| 失败 UE 数（快 / 中 / 慢） | 138（70 / 51 / 17） | 114（58 / 36 / 20） |
| 失败 UE 的平均信噪比中位数 / 窗口占比中位数 | 3.6 dB / 0.90 | 3.4 dB / 1.00 |

- 优化把时机从慢类、强 UE 挪给快类、弱 UE，并基本消除了碎片。
- 碎片的口径两者略有不同：CG-opt 不强制分完资源（设计 §11.5）。
- 静态预留的空闲没有改变：分出去的时机仍有约 63% 没有用到。这是静态配置本身的性质，任何分配都改不了。
- 失败的 UE 已经拿到了全部时机，所以资源分配已没有余地，剩下的是 §6 的信道问题。
- 验证集 N ≥ 16 时，CG-opt 的失败 UE 比 CG 略多（N = 16 时 616 对 584），但 F 相同或更高：这些部署无论如何都不可行，字典序目标优先保护最差的 UE，代价由其他 UE 承担。

## 6. 近似上限与逐部署拆分（设计 §5，描述性）

**改进后的近似上限**（`ceiling-*.json`）：
- 对独占时 q^B > 0.005 的 UE（exp010-eval512 上 N = 6、8、10 时 87、129、154 个；验证集 5–73 个），从规则放置出发在样本库 A 上不限次数地搜索，再在 B 上评估。
- **没有一个 UE 被搜索从 > 0.01 降到 ≤ 0.01**，所以改进后的上限与规则上限完全相同。
- "每个时隙用当前最好子信道"的松的严格界在所有 N 上都是 1.000，没有信息量。
- 严格而紧的上界需要在所有放置中求最小，计算上不可行；这里的上限只是近似。

**解读**：
- 优化消除了 CG 在资源共享上的大部分损失：N = 8 时，学习策略能满足而静态配置不能的"其他部署"从每层 27–28 个降到 7–8 个，N = 10 时从 66–72 个降到 26–31 个。
- 剩下的差距以弱 UE 部署为主。N = 8 时 A-mix 的优势中约 80% 在弱 UE 部署上；N = 10 时资源共享的份额回升，弱 UE 部署约占 40%。
- 弱 UE 部署上，学习策略能满足相当一部分（N = 8 时，CG-opt 失败的弱 UE 部署中，A-mix 与 M 每层满足 29–43 个），N_EDF 能满足除物理上不可行的以外全部。这些部署需要按信道选子信道，也就是 CG 报告 §6 所说的"不能跟随衰落"。在这种时机结构下，任何静态分配都做不到（在近似上限的意义下）。
- 所以，"CG 低于学习策略"只有一部分是因为贪心分配做得不好：分配做好之后，差距缩小约三分之一（N = 8 时从 −0.118 缩到 −0.076），剩下的主要是静态配置本身的限制。

## 8. 对后续的含义

研究框架于 2026-10-10 修订（ε = 0.01 不再是唯一的判据，见研究框架修订草稿）。本报告的判读按预先写定的 ε = 0.01 规则作出，不受影响；下面第 3 点中论文的表述，以修订后的框架为准。

1. **主表**：从 EXP-011 起，主表的 N_CG 用 CG-opt（场景 v2 与协议 v2 的补充已于设计定稿时写入）；贪心 CG 作为描述性结果保留。
2. **CG 报告**：结论与数值不变。§1 第 2 点"CG 甚至低于 best_local"仍然只对贪心 CG 成立；CG-opt 在 N = 10 时高于 best_local。
3. **论文**：
   - 可以回应"静态基线太弱"的质疑：资源分配按明确目标、有限预算、样本外检验优化之后，与学习策略的差距从 −0.118 缩到 −0.076，但仍然显著；
   - 剩下的差距主要在弱 UE 部署上，来自静态配置不能按信道选子信道；
   - 这些仍需在确认集上正式确认。
4. **EXP-011**（L1 紧急度信息）：按原计划起草，参照为学习策略、N_EDF 与 CG-opt。正式比较时，CG-opt 与 EXP-011 一起在确认集（31,000 起）上评估。
