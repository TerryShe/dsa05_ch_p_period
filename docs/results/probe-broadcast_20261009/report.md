# 信息边界探针：AP 广播加让行规则（描述性）

背景：2026-10-08 的讨论认为，单 AP 上行中的干扰耦合发生在公共接收端，邻居信息基本没有意义，有用的只能是 AP 侧按子信道汇总的全局信息。讨论后约定先做两项检查（不训练，不改场景）：

1. **可见性**：失败 UE 被别的 UE "进入"同一子信道时，进入者从公共 RSSI 上看到了什么？
2. **广播加让行**：给现有策略加一条手写规则，比较两种广播内容。B2 广播每个子信道的占用数，B3 广播每个子信道上是否有紧急 UE。

## 1. 结论

1. **紧急标志 B3 在三个 N、三组策略上都提高了 F，而且干预极少**（ε = 0.01，配对差值及 95% 区间）：

   | 策略 | N = 6 | N = 8 | N = 10 |
   |---|---|---|---|
   | A-mix | +0.016 [+0.005, +0.028] | +0.027 [+0.014, +0.040] | +0.047 [+0.024, +0.073] |
   | M | +0.009 [+0.002, +0.020] | +0.015 [+0.004, +0.028] | +0.028 [+0.013, +0.044] |
   | best_local | +0.010 [+0.003, +0.020] | +0.048 [+0.028, +0.070] | +0.117 [+0.087, +0.152] |

   - B3 只推迟了 0.05%–0.6% 的发送，整体碰撞比例不变。
   - 在 21 个（种子层 × N）组合中，共修复 246 个原来失败的部署，破坏 7 个。
   - 增益随负载增大。
2. **B3 仍没有让 F(8) 越过 0.95**：
   - F(8) 分别为 A-mix 0.949 [0.927, 0.970]、M 0.946 [0.919, 0.971]、best_local 0.905。
   - 单个种子层中，A-mix 第 2 层（0.960）与 M 第 1 层（0.965）在 0.95 之上，其余层在之下。
   - 因此在本切片上不能说 N* 提高。
   - 本切片的物理上限约为 0.995：部署 1259 与 1395 对任何策略都不可行。
3. **占用广播 B2 加确定性推迟有害，且负载越高越糟**：
   - N = 6 时 +0.003 至 +0.013；
   - N = 8 时 −0.053 至 0.000；
   - N = 10 时 −0.21 至 −0.32。
   - 机制（§4.3）：推迟几乎消除了"进入"型碰撞，但被推迟的 UE 随后同时进入，"同时新进"型碰撞成倍增加。
   - **这说明的是这条规则失败，不能据此说占用信息没用**。没有随机化的推迟本来就会同步化。
4. **改为"换到最好的空闲子信道"更糟**（只在 N = 8 上跑）：
   - B2r 为 −0.10 至 −0.22，所有 UE 挤到少数空闲子信道；
   - B3r 与 B3 基本相同，因为 B3 触发太少，换信道和推迟差别不大。
5. **可见性：真正"看不见"的弱 UE 只占少数，"看得见但弱"的占多数**：
   - 失败 UE 被进入时，该子信道上一时隙的 RSSI 比噪声高：
     - 3–10 dB 的占 73%–84%；
     - 低于 3 dB（基本看不见）的占 11%–24%；
     - 10 dB 以上的占 2%–10%。
   - 策略几乎把低于 3 dB 的占用子信道当作空闲：相对空闲子信道的选择率为 0.70–0.92。
   - 对 3–10 dB 的子信道，选择率只降到 0.44–0.72。
   - 80%–97% 的进入发生时还有空闲子信道；50%–65% 进入的是进入者自己的最好信道，自身信道增益压过了 RSSI 信号。
   - 进入者几乎都不紧急（0.4%–1.1%）。
   - 策略对"有紧急 UE 占用"的子信道并不更回避，因为它们看不到别人是否紧急。
6. **对信息边界的含义（初步）**：
   - 公共 RSSI 已经给出各子信道的功率。再加"谁在占用"并配上简单规则，没有帮助。
   - 本地观测真正缺的是**别人有多紧急**。B3 每时隙下行 K = 4 比特，每次上行发送附带 1 比特，正好补上这一点，效果在所有 N 与策略上都是正的。
   - 这支持"压缩的全局紧急度信息"这一方向，而不是邻居信息。
   - 但这是**手写规则 + 未重新训练的策略 + 乐观的标志接收假设**（§5）。它不证明学习策略在 B3 观测下能达到 0.95，也远没有接近 N_EDF：exp010-eval512 上 N_EDF 的 F(8) 为 0.992。

## 2. 设置

- **策略**：取自 `outputs/exp010/methods-exp010.json`，按 N 取各自的检查点，不重新训练。
  - A-mix：EXP-006 三个长训练种子的最后 5 个检查点，3 个种子层；
  - M：EXP-009 的 S1，3 个种子层；
  - best_local：按 N 校准的本地规则。
- **实例**：开发切片 1000–1399，共 400 个部署，N ∈ {6, 8, 10}。执行种子与衰落种子同协议 v2（dev，repeat 0）。
- **模式**：
  - none 即原策略；
  - B2、B3 在三个 N 上都跑；
  - B2r、B3r 只在 N = 8 上跑。
- **紧急**：slack < 3 个时隙。
  - slack = 距截止期的时隙数 − ⌈剩余比特 / r_max⌉；
  - r_max 是在自己最好的子信道上、无干扰、最大功率时的速率；
  - 定义同第 0 步，只用本地信息。
- **让行规则**：只作用于有包、不紧急、且策略要求发送的 UE。若策略采样到的子信道被"封锁"：
  - B2/B3 模式下，该时隙关闭（推迟）；
  - B2r/B3r 模式下，以相同功率换到未封锁子信道中自身增益最好的一个；没有可换的就关闭。
  - 紧急 UE 不受影响。
- **广播内容**（都用上一时隙的广播，即有一个时隙的时延）：
  - B2（每子信道 2 比特，记录 0、1、2+ 个发送者，与功率无关）：除自己以外还有人发送，即视为封锁。
  - B3（每子信道 1 比特）：上一时隙有紧急 UE 在该子信道上发送，即视为封锁。每次上行发送附带 1 比特紧急标志。UE 若上一时隙自己就在该子信道上且紧急，则忽略该子信道的标志，因为 1 比特无法区分是不是自己的标志。
- **结果计算**：与 `capacity.run_capacity_episode` 完全一致。单元测试检查了 none 模式能复现它。
- **区间**：两级 bootstrap（种子层 × 部署），2000 次重抽样，与 none 配对。
- **在本切片内做过的选择**：
  - "推迟"作为主规则，是在 4 个实例（1020–1023，A-mix，N = 8）的冒烟运行后定的：重定向使碰撞约翻倍。这 4 个实例在本切片内。
  - 紧急阈值 3 直接沿用第 0 步，没有调。

## 3. 检查一：可见性（none 模式）

### 3.1 进入选择率（N = 8，各种子层合并）

统计范围：每个本时隙发送、但不是"原地继续发"的 UE，不包括它自己上一时隙用的子信道。对其余子信道，按上一时隙状态分类，计算被选中的比例。表中给出相对空闲子信道选择率的倍数。空闲子信道的选择率为 A-mix 0.316、M 0.321、best_local 0.326。

| 策略 | 占用者 | < 3 dB | 3–10 dB | 10–20 dB | ≥ 20 dB |
|---|---|---|---|---|---|
| A-mix | 不紧急 | 0.92 | 0.55 | 0.34 | 0.44 |
| A-mix | 有紧急 | 0.83 | 0.64 | 0.35 | 0.51 |
| M | 不紧急 | 0.81 | 0.54 | 0.34 | 0.24 |
| M | 有紧急 | 0.83 | 0.65 | 0.39 | 0.29 |
| best_local | 不紧急 | 0.79 | 0.47 | 0.29 | 0.27 |
| best_local | 有紧急 | 0.77 | 0.60 | 0.30 | 0.26 |

- 分档依据是上一时隙该子信道的公共 RSSI 比噪声高出多少。
- N = 6 与 N = 10 的模式相同：
  - 低于 3 dB 的不紧急占用子信道为 0.70–0.92；
  - 3–10 dB 的为 0.44–0.72。
- 策略会回避强信号，但对弱信号回避很少。在同一档内，对有紧急 UE 的子信道并不更回避；3–10 dB 档甚至略高，可能因为紧急 UE 多是远处的弱 UE。
- "有紧急 UE 占用"的选项只占所有选项的 0.05%–0.4%，所以这类碰撞次数少，但正落在最要紧的时刻。

## 5. 解读：能说什么，不能说什么

能说的（描述性，限于本切片）：

- 在固定策略之上，"别的 UE 是否紧急"这一位信息配合最简单的让行规则，在所有 N 与策略上都提高了 F。增益来自极少的干预。
- 现有策略对弱信号子信道的回避很弱，也无法区分紧急与不紧急的占用者。前者是 RSSI 观测的分辨问题，后者是观测里根本没有这个信息。
- 占用信息配确定性推迟，在高负载下会同步化。规则必须带随机化，或像 B3 那样只在少数时刻触发。

不能说的：

- **不能说 B3 广播能把 N* 提高到 8**：F(8) 0.946–0.949，区间覆盖 0.95 两侧，且是在开发切片上的描述性结果。
- **不能说占用信息没用**：B2 的失败可能是规则造成的。要区分，需要带随机推迟的 B2 变体。
- **B3 的增益依赖乐观的接收假设**：本探针假设 AP 能读到所有发送者的紧急标志，包括碰撞中、信号弱的发送者。现实中如果标志随数据一起只在解码成功时才收到，失败 UE 恰恰常在碰撞中，标志可能正好丢失。这是本结果最大的保留。
- **不能说学习策略在 B3 观测下会更好或更差**：本探针没有重新训练。策略只是被一条外部规则覆盖了 0.05%–0.6% 的动作，分布偏移很小，但规则不是最优的。
- **紧急阈值 3 没有调**，推迟规则是在本切片 4 个实例上看过冒烟结果后定的。若做正式实验，阈值与规则都应预先写定，并在新的切片上选择与评估。

## 6. 信令开销（初步对比）

| 方案 | 下行（每时隙） | 上行 | 需要的接收能力 |
|---|---|---|---|
| B0（现有 RSSI） | K 个功率值 | 无 | AP 测量各子信道总功率 |
| B2 占用数 | 2K = 8 比特 | 无 | AP 能检测每个发送者，包括弱信号 |
| B3 紧急标志 | K = 4 比特 | 每次发送附带 1 比特 | AP 能读到每个发送者的标志，包括碰撞中的 |
| N_EDF 授权 | 每个 UE 的（子信道，功率），⌈log₂ 21⌉ = 5 比特 × N（N = 8 时 40 比特） | 各 UE 的队列、截止期和 K 个子信道 CSI（本报告不量化） | 集中调度 |

B3 的下行开销与 N 无关，比集中授权小一个数量级。上行 1 比特的可靠接收是需要建模的关键点。

## 7. 下一步选项

1. **补充探针（仍在开发切片 1000–1399 上，与本报告配对，约 1–2 小时）**：
   - (a) **B3 标志丢失**：只有成功解码（或 SINR 高于门限）的发送才把标志送到 AP；

   其中 (a) 决定 B3 的增益是否主要来自乐观假设，最重要。
