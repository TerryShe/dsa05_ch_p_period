# N=4 中央最小能耗参照（精确最优）

本报告在冻结场景 v1.0 的 N=4 变体上，求每个实例在"所有包按期交付"约束下的精确最小发射能耗，把最优调度放回真实环境中重放核验，并在同一批实例上与三个本地启发式对比。本轮不涉及 MARL 训练。

## 结论

- **精确最优已得到并核验。** 100 个实例、49,500 个评价窗口内的包，中央最优平均为 **53.88 µJ/包**、**3.70 mW/UE**。最优调度在真实环境中重放，全部按期完成，每个包的实测能耗与计划一致（相对误差 < 1e-9）。
- **最优调度的形态是"独占子信道、低功率、拉长发送"。** 所用时隙中 5 dBm 占 67.7%，10 dBm 占 32.1%，15 dBm 占 0.2%，19/23 dBm 从未使用。平均每个 UE 在 68% 的时隙里发送。
- **本地启发式离最优很远。** random_max 与 sticky_max 的包能耗约为最优的 10–11 倍；lazy_pacing 约为 5.5 倍，而且在 18/100 个实例中有 UE 的按期完成率低于 0.95。N=4 对 MARL 留有很大的提升空间。
- **允许每 UE 5% 违约时**，最优能耗只再降低 4.7%（capped/strict = 0.953）。

## 1. 方法

### 1.1 为什么 N≤K 时正交分配是最优的

v1.0 的信道静态、频率平坦（g_{i,k}=g_i），能耗 E=τp 与子信道无关。任取一个可行调度，把每个 UE 固定到一个专属子信道（N≤K 保证放得下），功率和发送时隙保持不变：每个 UE 的 SINR 变为 SNR，只升不降，因此每个包都不会晚于原调度完成，而总能耗不变。所以最优值等于正交调度中的最优值。

在正交调度下，各 UE 互不影响；截止期等于下一次到达，同一 UE 的各个包占据互不重叠的时间窗。于是问题分解成独立的单包问题，而且同一 UE 的每个包是**同一个**问题：

min Σ_l n_l·e_l  s.t.  Σ_l n_l·b_l ≥ L，Σ_l n_l ≤ P，n_l ∈ ℕ

其中 e_l=τp_l 是功率档 l 的单时隙能耗，b_l=τB·log₂(1+p_l g/σ²) 是无干扰单时隙互信息。时隙之间可以互换，所以只需确定每个功率档用多少个时隙。

### 1.2 求解与核验

- **精确求解**（`central.optimal_packet_plan`）：枚举除最低档外各功率档的所有时隙数组合（P=40 时约 13.6 万组），最低档取满足互信息所需的最少时隙数。能耗相同时，取时隙数较少的解。
- **暴力对照**（`tests/test_central.py`）：12 组随机小算例上，对"每个时隙任选一个功率档或 OFF"的所有序列做穷举，最优值与求解器一致。
- **连续下界**：功率在 [0, 23 dBm] 内连续可调时，最优是在整个周期内均匀发送。所有 UE 的离散最优都不低于这个下界。
- **环境重放**（`central.act_central`）：UE i 固定使用子信道 i，在每个包的前若干个时隙按计划发送。核验项包括：所有已结算的包都按期完成；每个包的实测能耗和发送时隙数等于计划；窗口内的包数等于 `packets_due` 的解析计数；窗口能耗等于计划能耗。
- **违约上限**：在每 UE 违约率 ≤ ε 的约束下，最优做法是让每个 UE 直接放弃 ⌊ε·n_i⌋ 个包（同一 UE 的包能耗相同）。报告中的 capped 值就是按此计算的。

## 4. 解读

1. **N=4 时，协调只需要"错开子信道"。** 中央最优所需的信息除了一项之外都是本地的：本 UE 的周期、到截止期的剩余时隙数，以及由本 UE 增益决定的功率计划。唯一不是本地的是"UE i 用子信道 i"，因为 Actor 看不到自己的 ID。所以分布式策略能否逼近最优，取决于两点：UE 之间能否自发地分开子信道，以及能否学会低功率、拉长发送。
2. **启发式偏离最优的主要原因是"尽快发完"。** random_max 和 sticky_max 总是用 23 dBm，一两个时隙就发完一个包。但在 log 形式的速率下，把时间拉长、降低功率要省能得多（lazy scheduling）。
3. **lazy_pacing 是一个偏弱的基线。** 它在空闲之后会丢掉对自身增益的估计（估计只来自上一时隙的反馈），所以每个包的第一个时隙都用满功率。此外它按"剩余比特 ÷ 剩余时隙"来定每时隙目标，会随信道干扰波动，在 18 个实例中导致个别 UE 违约。在静态信道下，自身增益本可以跨包记住。后续比较 MARL 时，应补一个记住增益的强本地基线。
4. **功率菜单的影响。** N=4 的最优几乎只用 5/10 dBm，离散化损失只有 10.6%（按能耗加权）。高功率档的价值要到 N>K、时间变紧时才会显现，这与 v1.0 选择菜单时的理想分析一致。

## 5. 边界

- 精确性依赖 v1.0 的两个前提：N≤K，以及静态、频率平坦的信道。出现频率选择性衰落后，正交分配最优这一结论不再自动成立。
- 实例 0–99 只是本次参照用的集合，不是冻结的测试划分。MARL 的测试集应由实验协议另行冻结，再用同一入口计算参照（100 个实例约 1 分钟）。
- 启发式的结果对应单一 `policy_seed`，只作为同实例上的参考，不是经过校准的强基线。

## 7. 下一步：N>K

N=6/8/12 时 UE 数超过子信道数，正交分配不再总是可行，需要分时，同信道并发也可能出现。计划用上下界把最优值夹住：

- **下界**：去掉干扰和子信道数的限制，逐 UE 求单包最优（即本报告的方法）。任何可行调度的能耗都不会低于它。
- **上界**：限制每个子信道每个时隙最多一个 UE，按 40 时隙的超周期建立混合整数规划，得到一个可行的正交分时调度，并在环境中重放核验。

上下界之间的差距衡量了负载加重之后"时间变紧"的代价，也给出了同信道并发最多能带来多少收益。
