# N=4/6/8/12 中央最小能耗的上下界

本报告在冻结场景 v1.0 的四个 N 变体上，给出"所有包按期交付"时最小发射能耗的下界与上界。上界对应的调度会放回真实环境中重放核验；同一批实例上还运行了三个本地启发式作对照。本轮不涉及 MARL 训练。N=4 部分的结果与[N=4 精确参照报告](../central-reference-n4_20260924/report.md)完全一致。

## 结论

- **N≤6 基本已知最优。** N=4 的 100 个实例全部精确（上界 = 下界）。N=6 中有 45 个实例精确，其余实例的上界/下界均值为 1.021，最大 1.120。
- **负载越重，区间越宽。** N=8 时上界/下界均值为 1.121（p90 1.215）；N=12 时为 1.423（p90 1.556，最大 1.615），没有一个实例精确。区间变宽的同时，上界调度的子信道占用率从 0.68 升到 1.00，说明缺口来自子信道容量吃紧，而下界完全不考虑容量。
- **下界几乎不随 N 变化，上界随 N 上升。** 每 UE 平均功率的下界约为 3.7–3.8 mW（每 UE 的负载相同）；上界从 3.70 mW（N=4）升到 5.48 mW（N=12）。
- **本地启发式离最优很远。** 在所有 N 下，random_max 与 sticky_max 的能耗都是上界的 8–10 倍（中位数）。lazy_pacing 随 N 增大越来越难满足截止期：N=12 时 100 个实例全部有 UE 的按期完成率低于 0.95，最差 UE 平均只有 0.52。
- **更紧的下界尝试没有成功。** 用多址信道（MAC）和速率约束构造的线性规划下界，在抽查的 10 个实例中只收紧了 1 个（+1.14%）。N=12 的真实最优目前只能确定在 [下界, 上界] 之内；§4.2 给出了它更可能靠近上界的理由。

## 1. 方法

### 1.1 下界：逐 UE 单独最优

在任意可行调度中，同信道干扰只会降低 SINR，所以 UE i 的 SINR 不会超过它单独发送时的 SNR。于是在任何调度下，它的每个包的能耗都不低于"在整个包窗口内单独发送"的最优值 E_i*，也就是 N=4 报告中逐 UE 求解的单包问题。下界 = Σ_i n_i·E_i*（n_i 为评价窗口内的包数）。这个下界同时忽略了干扰和子信道数量限制，对任何 N 都成立，也涵盖允许同信道并发的调度。

### 1.2 上界：正交分时的循环调度

上界只考虑"每个时隙最多 K 个 UE 发送、各占一个子信道、彼此无干扰"的调度。v1.0 的信道静态、频率平坦，UE 在各子信道上增益相同，所以只需关心每个时隙有几个 UE 发送，不必区分具体是哪个子信道。

三类周期（10/20/40 时隙）的最小公倍数 C=40，到达模式每 40 个时隙重复一次。在这个 40 时隙的循环上，每个 UE 的包窗口把循环切成 40/P_i 段（可以跨越循环边界）。只要一个循环调度满足了每一段的需求，把它周期性重复，就能服务真实运行中的每一个包。

MILP（HiGHS，通过 `scipy.optimize.milp` 调用）：
- 整数变量 n[w,l]：窗口 w 中使用功率档 l 的时隙数；
- 连续变量 y[i,t] ∈ [0,1]：UE i 是否在循环时隙 t 发送。

约束为：窗口内发送时隙数 Σ_{t∈w} y = Σ_l n[w,l]；每个时隙 Σ_i y[i,t] ≤ K；互信息 Σ_l b[i,l]·n[w,l] ≥ L_i。目标是最小化 Σ e_l·n[w,l]。

n 取整数时，y 的约束是"窗口—时隙"二部图上的运输问题，约束矩阵全幺模，因此一定存在整数的 y，用最大流就能精确恢复。每个窗口内的功率档按从高到低的顺序排进分到的时隙。

**上界取调度在环境中重放时的实测能耗**：只要调度可行，它的实际能耗就是合法上界，不依赖 MILP 是否求到最优。重放时核验以下各项：所有已结算的包都按期完成；每个时隙最多 K 个 UE 发送；每个包的实测能耗不超过计划值；窗口内的包数等于解析计数；下界不高于上界。

**数值单位**：MILP 以 µJ 和 kbit 建模。最初按焦耳建模时，每个循环的能耗只有约 1e-3 J，HiGHS 的默认绝对间隙容差（1e-6）相当于允许约 0.1% 的相对误差，N=4 中有 4 个实例因此停在最优值之上（最多 +0.15%）。改用 µJ 后全部精确，其中两个实例已加入回归测试。

### 1.3 允许每 UE 5% 违约

在违约率上限 ε 下，下界和上界都按"每个 UE 放弃 ⌊ε·n_i⌋ 个包"计算：下界中每个包的能耗相同；上界放弃每个 UE 能耗最高的那几个包。正交调度中 UE 之间互不影响，所以放弃之后调度仍然可行。

## 4. 解读

### 4.1 区间为何随 N 变宽

三类业务每 UE 的平均负载相同，所以单独发送时的最优功率与 N 无关，下界稳定在约 3.8 mW/UE。上界则受子信道容量约束：到 N=8 时，上界调度几乎用满所有子信道时隙（0.995），N=12 时完全用满。可用时间变少，UE 只好用更短的时间、更高的功率发完一个包：N=12 时，上界所用时隙中 15 dBm 占到 34%。

额外能耗主要落在远端 UE 上（N=12 时 75–100 m 占 71%）。但按比例看，吃亏最多的是中距离 UE：MILP 把更多时隙分给远端 UE（发送时隙比例 0.44，中距离为 0.33），中距离 UE 被压缩得更厉害（N=8 时上界/下界 1.28，N=12 时 1.57）。

### 4.2 N=12 的真实最优在哪里

两个界都是严格成立的，缺口来自两方面：下界不考虑容量，上界不允许同信道并发。有两条证据表明，同信道并发不太可能明显低于正交上界：

1. **对称两 UE 的解析比较。** 两个增益相同的 UE 共用一个子信道，各自单独占用整个窗口时所需的 SNR 为 s₀。若它们在整个窗口内同时发送（接收端把干扰当噪声），各自需要 SNR s = s₀/(1−s₀)，能耗是单独发送的 1/(1−s₀) 倍（且要求 s₀<1）。若改为分时、各用一半时隙，各自需要 (1+s₀)²−1，能耗是 1+s₀/2 倍。由于 1/(1−s₀) ≥ 1+s₀ > 1+s₀/2，分时总是更省能耗。
2. **MAC 和速率下界。** 同一子信道上 UE 的速率之和不会超过多址信道的和容量；对 K 个子信道再用 Jensen 不等式，每个时隙的总互信息不超过 τB·K·log₂(1+ΣSNR/K)。把这个上限用切线线性化，功率档放松为分数，再加入"每个包的能耗 ≥ 单独最优"的割平面，得到一个线性规划下界（[`scripts/explore_mac_sum_rate_bound.py`](../../../scripts/explore_mac_sum_rate_bound.py)）。在 N=8 与 N=12 各 5 个实例上，它只收紧了 N=12 的实例 2（+1.14%），其余 9 个与单独下界相同。原因是这个松弛允许类似 SIC 的叠加，并允许功率档取分数，在当前 SNR 下，超过 K 个 UE 同时发送几乎不需要额外代价。所以这个下界太弱，不能用来缩小缺口，也没有并入正式的界。

第 1 条只覆盖对称的两 UE 情形，并不证明正交分时就是最优。要直接检验，下一步可以在上界 MILP 中加入"两 UE 同信道"的组合模式：这仍然是可在环境中重放核验的合法上界。如果它相对正交上界几乎没有改进，就能更有把握地把正交上界当作 N=12 的实际参照。

### 4.3 对 MARL 的意义

- 在所有 N 下，现有本地启发式的能耗都是上界的 8–10 倍（lazy_pacing 为 5–8 倍），节能空间很大。
- N 越大，满足截止期越难。lazy_pacing 按"剩余比特 ÷ 剩余时隙"逐时隙降功率，在 N=12 时既不省能（43.5 mW，接近 random_max 的 46.9 mW），最差 UE 也严重违约。协调接入是负载加重后的核心问题。
- MARL 的结果可以同时报告"能耗/下界"与"能耗/上界"：前者是最保守的最优差距，后者在 N≤6 时几乎就是到最优的差距。

### 4.4 功率菜单

在四个 N 下，上界调度都几乎不用 19 dBm（最多 0.1%），也从不用 23 dBm。v1.0 选菜单时的理想化分析假设每个 UE 平分时隙，而最优分时会把更多时隙分给远端 UE，所以 15 dBm 就够用。分布式策略存在碰撞和干扰，可能仍然需要高功率档，因此冻结的菜单不做改动。这个现象可以作为以后比较菜单的依据。

## 5. 边界

- 两个界都依赖 v1.0 的静态、频率平坦信道。引入频率选择性衰落后，"只需关心每个时隙有几个 UE 发送"这一简化不再成立。
- 上界只在"周期性重复的正交分时"中取最优；非周期调度和同信道并发没有计入。它是合法上界，但不一定是最优。
- 实例 0–99 只是参照用的集合，不是冻结的测试划分。
- 启发式对应单一 `policy_seed`，没有经过校准，只作为同实例上的参考。
