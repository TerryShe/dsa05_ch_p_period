# 场景 v2.1 第 0 阶段：实现与量级检查

## 1. 结论

1. **实现完成**（提交 0a98e0e）：场景规范 v2.1 §6 的实现与测试全部完成；全部 348 项测试通过，其中新增 7 项；v2.0 的冻结测试照常通过。
2. **量级检查**（开发实例 0–63，非正式，只跑非学习的方法）：
   - 未受影响的部署上，v2.1 与 v2.0 的每个回合逐 UE 违约数完全相同（三个方法、六个 N 全部如此）。这直接核对了"种子不变、只重抽近 UE"的实现。
   - 受影响的部署（64 个中 3–7 个）上，N_EDF 基本不变；CG-opt 与 best_local 在大 N 下略差，因为被重抽的近 UE 换成了更远、更难服务的 UE。
   - 整体 P2 的变化在 N ≤ 12 时不超过约 8%，F_{0.01} 几乎不变。
3. **建议冻结 v2.1**，冻结清单的内容见 §4。

## 2. 实现

| 部分 | 内容 |
|---|---|
| `topology.py` | `generate_shadowed_topology` 加 `min_distance_m`：每次抽取同时满足覆盖规则与距离不小于它才接受，否则在同一随机流中重抽；`ShadowedTopology` 记录这一距离，拓扑记录的抽样说明中写明（v2.0 的记录不变） |
| `config.py` | `Scenario.min_distance_m`（默认 0），由配置的 `[spatial] min_distance_m` 读入；只允许用于 v2 场景，取值在 [0, 半径) 内 |
| 配置 | `configs/scenario-v2.1.toml`：除注释、`[experiment]` 的版本与 `[spatial] min_distance_m = 10.0` 外，与 `configs/scenario-v2.toml` 相同 |
| 测试 | `tests/test_scenario_v21.py`，7 项 |

- **实现中的澄清**（已写入规范 §6）：这一项不放进 `SpatialConfig`，因为拓扑记录会写出 `SpatialConfig` 的全部字段，放进去会改变 v2.0 的拓扑记录。
- **新增的测试**（实例 0–299，N = 20）：
  - 配置与 v2.0 只差版本与最小距离；
  - v2.0 场景的最小距离为 0，拓扑记录不变；
  - v2.1 的所有 UE 距 AP ≥ 10 m；部署在 N 之间嵌套；
  - 第一个近 UE 之前的 UE（位置、阴影、重抽次数）与 v2.0 逐位相同，相位不变；未受影响的部署比例在 70–92% 之间（预期约 82%）；
  - 接受的 UE 的距离与阴影，与"v2.0 中 ≥ 10 m 的 UE"同分布（KS 检验）；距离在圆环上按面积均匀；
  - 参数的合法性检查。
