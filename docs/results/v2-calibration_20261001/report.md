# 场景 v2.0 验证集校准：本地规则按 N 选参数与 N_EDF

## 1. 结论

1. **集中式因果调度 N_EDF = 20**（ε = 0.01 与 0.05 相同），与开发实例上的量级检查一致。
   - F(20) = 1.00，F(24) = 0.83 [0.73, 0.92]，F(28) = 0.17；
   - N\* 的 bootstrap 分布中 20 占 99.7%。
2. **校准后最好的本地规则在 ε = 0.01 时 N\* = 4**，有三类规则达到：p 坚持（a = 8）、机会式（θ = 1）、paced_sticky_csi（N = 4–12 上 margin = 16–∞）。
   - ε = 0.05 时最好的是 paced_sticky_csi，N\* = 8。
   - random_max、sticky_max、周期预约分别为 < 2、2、< 2（ε = 0.01）。
3. **分布式与集中式的差距约为 5 倍**（4 对 20）。
   - 本地规则在 N = 6–10 失败时，信道占用率只有 0.25–0.48（paced_sticky_csi），失败的通常是单个远端快类 UE，违约率约 2–3%。这不是容量耗尽，而是缺少协调。
   - EDF 直到 N = 20 都没有任何 UE 超过 1%；它在 N = 24 失败时，信道占用率为 0.90，是真正的过载。
   - 这个差距就是 EXP-DSA05-006 学习型协调要缩小的对象。
4. **参数表的补充已完成，N\* 不变**（用户批准，§6）。第一次运行中，paced_sticky_csi 在多数 N 上选中参数表的上端（margin = 8），机会式在 N ≤ 8 上选中下端（θ = 1）。补跑 5 个设置后：
   - paced_sticky_csi 在 margin = 16、32、∞（始终满功率）上进入平台：F(6) 从 0.92 升到 0.94，F(8) 从 0.83 升到 0.89，仍低于 0.95，所以 N\* 仍为 4（ε = 0.05 时仍为 8）；
   - 机会式的 θ = 0.5、0.75 与 θ = 1 的结果完全相同。原因是 θ ≤ 1 时，凡是"速率低于节奏"的时隙，按该速率算的松弛量已经为负，规则照样发送；所以 θ ≤ 1 都等价于"始终在估计速率最高的子信道上发送"，θ = 1 实际上不是一个端点。
   - 两类规则现在都覆盖到了各自参数的有效端点，基线已经尽力。

- F 全部为 0 的 N 上，选择只由次级规则决定（F_{0.05}、最差 UE 违约率、表中顺序），没有实际意义。
- p 坚持的 a = 8 在表的内部（表为 2–64），是一个清楚的内部最优。
- paced_sticky_csi：第一次运行在 2 ≤ N ≤ 12 上几乎都选 8（当时的上端）；补充后选 16–∞，而这几个设置的 F 相差不超过 0.05，已经是平台。margin 很大时功率几乎总是满功率：发得更快、占用的时隙更少（N = 6 时信道占用率从 margin = 8 的 0.34 降到 ∞ 的 0.25）。
- 机会式的 θ 在 N ≤ 8 上都选 1。补充的 0.5、0.75 与 1 完全等价（见 §1 第 4 条），按"表中靠前"的平局规则仍选 1。

## 5. 失败的形态（验证集）

| 方法与 N | 超过 1% 的 UE 比例 | 其中快类 / 中类 / 慢类 | 远端（≥ 80 m）超过 1% 的比例 | 失败 UE 的违约率中位数 | 失败回合占比（其中只有 1 个 UE 失败） | 信道占用率 |
|---|---|---|---|---|---|---|
| paced_sticky_csi (∞)，N = 6 | 0.013 | 0.031 / 0.008 / 0 | 0.037 | 0.021 | 6%（5%） | 0.25 |
| paced_sticky_csi (32)，N = 8 | 0.016 | 0.036 / 0.005 / 0 | 0.038 | 0.030 | 11%（9%） | 0.36 |
| paced_sticky_csi (32)，N = 10 | 0.031 | 0.062 / 0.016 / 0.005 | 0.058 | 0.022 | 28%（25%） | 0.48 |
| p 坚持 (8)，N = 8 | 0.229 | 0.27 / 0.20 / 0.21 | 0.39 | 0.019 | 80%（27%） | 0.39 |
| 机会式 (1)，N = 8 | 0.258 | 0.42 / 0.21 / 0.09 | 0.39 | 0.029 | 74%（22%） | 0.41 |
| sticky_max，N = 8 | 0.070 | 0.13 / 0.05 / 0.02 | 0.14 | 0.030 | 47%（39%） | 0.50 |
| N_EDF，N = 20 | 0 | 0 / 0 / 0 | 0 | — | — | 0.74 |
| N_EDF，N = 24 | 0.102 | 0.09 / 0.11 / 0.11 | 0.13 | 0.120 | 17%（3%） | 0.90 |

（失败回合指至少一个 UE 超过 1% 的回合；括号内为其中只有一个 UE 失败的回合占全部回合的比例。信道占用率为发送的 UE·时隙除以子信道·时隙。）

- **本地规则的失败集中在远端、快类 UE，而且是边缘性的**：
  - 违约率中位数约 2%；
  - 近端（< 50 m）UE 在 N ≤ 6 时从不超过 1%；
  - paced_sticky_csi 在 N = 6 时信道只占用 25%，N = 10 时 48%；失败的回合绝大多数只有一个 UE 失败。
  - 快类的窗口只有 10 个时隙，与同信道 UE 碰上几次就没有补救的时间；远端 UE 的 SINR 余量小，一次碰撞就送不完。
- **p 坚持与机会式在 N = 8 时迅速恶化**（多数失败回合有 2 个以上 UE 失败），各类别都受影响。按松弛量决定何时发送，会让多个 UE 在相近的时刻、同一个最好的子信道上竞争。
- **paced_sticky_csi 最稳**：粘滞的子信道选择减少了重复碰撞。
- **EDF 的失败是过载**：在 N = 24 信道占用率达到 0.90 时才出现，失败 UE 的违约率中位数 12%，各类别相近。

所以，本地规则与 EDF 之间的差距来自**协调**，而不是来自信道资源：本地规则在资源远未用完时，就因少数远端 UE 的冲突而失败。这为 EXP-006 指出了方向：学习型协调需要保护边缘、快类 UE，例如让近端 UE 让出子信道、在时间上错开，同时不浪费总资源。
