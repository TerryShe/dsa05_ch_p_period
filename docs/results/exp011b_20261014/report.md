# EXP-DSA05-011B 结果报告：防饿死选模与延长训练下的紧迫摘要复验

本报告是实验记录，用于判读本实验与之后的决策。论文的表述在写作时另行决定，不直接取自本报告。

## 1. 结论

1. **按预先写定的主判据（设计 §5.2），结果为"有效"**：
   - D_N = P2(U) − P2(M) 在 N = 8、10、12 的 95% 区间上限都 < 0：

     | N | D_N | 95% 区间 | 均值比 |
     |---|---|---|---|
     | 8 | −0.00040 | [−0.00068, −0.00017] | 0.73 |
     | 10 | −0.00102 | [−0.00162, −0.00052] | 0.72 |
     | 12 | −0.00175 | [−0.00304, −0.00071] | 0.77 |

   - N = 6 也显著（0.76），N = 16 不显著（0.92）。没有任何 N 上 U 显著变差。
   - 五个种子在 N = 6–12 上全部是 U 低于 M（§8.1）。
2. **饿死：所有方法在评估集与近 AP 部署上都没有饿死单元**（§4.6）：
   - 近 AP 部署的覆盖与原来的 512 个部署相同（N = 6–16 为 9、12、13、17、23 个）。
   - 近 AP UE（< 5 m）的违约率最高为 0.051（M），U 最高 0.028。
   - **局限**：本切片中离 AP 最近的 UE 在 1.51 m，没有 1.5 m 以内的 UE。在压力集上，已知会饿死的三个检查点的饿死单元大多在 1.5–5 m（46 个中 41 个、33 个中 28 个、14 个中 11 个），所以本切片能暴露这类问题；只因 0.74 m 的 UE 被排除的那一类（M101 5M、6M，U202 10M），本切片没有覆盖。
3. **按 §5.4，U 满足"提出的方法"的三个条件**：主判据至少部分有效；U 没有饿死单元；M+Y 没有在两个以上的 N 上显著优于 U。
4. **但学习的响应没有优于手写规则，M+Y 在 N = 12 上显著优于 U**（§4.2）：
   - E_N = P2(U) − P2(M+Y) 在 N = 8、10、12 分别为：
     - +0.00007 [−0.00014, +0.00027]；
     - +0.00036 [−0.000005, +0.00077]，区间下限几乎为 0；
     - **+0.00098 [+0.00003, +0.00198]**。
   - 均值比为 1.07、1.17、1.21。五个种子在 N = 10、12 上全部是 M+Y 更低（§8.1）。
   - N = 8–12 上 P2 平均：U 0.00311，M+Y 0.00264。
   - 设计在 §5.3 第 2 项预先说明了检验力有限，预期"未检出差别"；实际结果是规则在一个 N 上显著更好。
5. **内容对照（H-S2）不支持"紧迫"这一内容有特别价值**（§4.2）：
   - U − O、U − L 在所有 N 上都不显著；N = 8–12 上，均值比 U/O 为 1.00–1.03，U/L 为 0.98–1.06。
   - EXP-011 中这一结论受训练预算的保留，O、L 那时还没收敛。本实验所有方法同等训练到 10M，这一保留不再成立。
   - 描述性（§8.2）：O、L、M+Y 都显著优于 M，幅度与 U 相当或更大（N = 8–12 上 P2 低 25–39%）。数据支持的是"加一层 L1 摘要并据此协调"，而不是某一种内容。
6. **机制：U 依赖广播，作用经过不紧急的 UE**（§4.3、§5）：
   - H-M1、H-M2 在 N = 6–16 上全部成立：对全部 UE 隐藏广播（U∅），P2 升高 37–70%，比 M 还差；只对不紧急的 UE 隐藏（U−N），几乎同样差。
   - 诊断：不紧急的 U 换信道时，选被标记子信道的比率只有未标记的 0.12–0.50 倍（M 为 0.74–1.13 倍）。M+Y 从不进入被标记子信道，最佳子信道被标记时约一半时隙推迟。
   - 失败 UE 卷入的同信道碰撞，M+Y 在 N = 8、10、12 上都最少（N = 10：M 171,960，U 117,709，M+Y 90,146），与 M+Y 的 P2 最低一致。
7. **0 dB**（§4.4）：
   - 在 0 dB 下训练的 U₀ 在 N = 10、12 上显著优于 M，N = 8 不显著。
   - U₀ − U@0 dB 在三个 N 上都显著为负。U@0 dB 与 M 没有差别（均值比 1.00–1.09）。
   - 按预先写定的解释：N = 10、12 上，U 在 0 dB 下的损失来自训练与评估条件不一致；N = 8 上"0 dB 下摘要信息不够"得到支持。
8. **敏感性与服务达标**（§4.5，不进入判据）：
   - 全部 UE 的平均违约率、log₁₀(w + δ) 在 N = 6–12 上都是 U 显著低于 M；p90 在所有 N 上 U < M；没有"牺牲其他 UE"的迹象。
   - 评估网格上的 N\*_{0.01}，U、M、M+Y、O、L 都是 8。N = 10 上 F_{0.01} 最高的是 M+Y（0.947），U 为 0.936。
9. **跨切片对照**（§6，描述性）：EXP-011 的 D_N 区间很宽，主要来自种子 101 的饿死；本实验在 N = 8、10、12 上的区间宽度约为它的 1/10、1/3、1/5。本实验同时改了防饿死、训练预算、种子数与切片，变化不能归因到单独一项（设计 §7）。
10. **最小 UE–AP 距离**（§7，修正 2 预先声明的描述性分析，不作判定）：
    - 只保留所有 UE 距 AP ≥ 5 m 或 ≥ 10 m 的部署，主判据仍是"有效"，内容对照仍无差别。
    - 在 ≥ 10 m 的子集上，M+Y 在 N = 10 与 12 上都显著优于 U。若在这一子集上套用 §5.4 第 3 项，U 不满足。
    - 其中 N = 10 的区间下限从全集的 −0.000005 变为 +0.00002，是在 0 附近的穿越，不是实质的变化。但协议修订将采用 10 m（设计 §15.4），这一点与最终确认的设计直接相关（§10）。

  - 压力集上已知会饿死的检查点：U101 5M 的 46 个单元中 5 个 < 1.5 m、41 个在 1.5–5 m；U101 8M 33 个中 5 个、28 个；U₀202 6M 14 个中 3 个、11 个。所以本切片的距离范围能暴露这类问题。
  - M101 5M、6M 与 U202 10M 只因部署 3122 中 0.74 m 的 UE 被排除，这一类本切片没有覆盖。

### 4.7 提出的方法（§5.4）

| 条件 | 结果 |
|---|---|
| 1. 主判据至少"部分有效" | 是（"有效"） |
| 2. U 在评估集上的饿死单元为 0 | 是（exp011b-eval128 与 exp011b-near 合计为 0） |
| 3. E_N 不在两个以上的 N 上显著 > 0 | 是（只有 N = 12） |

- 判定：U 是提出的方法。M+Y 作为规则对照，与 U 一起进入最终确认（§5.4）；最终确认的具体比较在协议修订时写定。
