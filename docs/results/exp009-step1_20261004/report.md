# EXP-DSA05-009 第 1 步：逐 N 训练（P0）与混合训练（M0）

## 1. 结论（按设计 §4 预先写定的规则）

1. **逐 N 训练没有被保留，B = M0（混合训练）。** 第 2 步在混合训练上进行。
   - P0 在筛选集上的平均 S_near 为 0.931，M0 为 0.950，差 −0.020（种子 101 −0.004，种子 202 −0.035）；
   - 第 1、2、3、5 条都没有通过，只有第 4 条（F(2) ≥ 0.95）通过。
2. **两者的差别随 N 改变方向**（按 N 选中的模型，两个种子平均）：
   - N = 6、8、10 上 P0 较差：F(6) −0.020，F(8) −0.020，F(10) −0.049；
   - N = 12、16 上 P0 较好：F(12) +0.014，F(16) +0.102；
   - N = 2、4 上两者都约为 0.98–1.00。
3. **逐 N 训练确实大幅增加了门槛区的训练经验，但门槛区可行率没有因此提高**（§4）：
   - 以 N = 8 为例，P0 的训练 rollout 中只有 57–59% 没有违约，M0 为 93–97%；
   - 每个 rollout 的违约次数，P0 为 0.67–0.73，M0 中 N = 8 的两个环境合计为 0.04–0.08。
   - 设计 §1.2 假设门槛区缺的是"有信息的经验"。至少在 500 万时隙、当前算法下，单纯增加同一 N 的经验数量不够。
4. **一个描述性的解释（未经检验）**：混合训练中，较大 N 的环境违约频繁，在那里学到的让路或回避行为可能迁移到较小的 N；逐 N 训练时，N = 6–8 的模型只能从稀疏的事件中学习。N ≥ 12 时，逐 N 训练本身已有足够的违约事件，所以表现较好。本步没有为检验这一点设计对照。
5. **下一步按设计 §5**：在 B = M0 上比较 S1（静态困难分层）、P1、P2（PLR），每个 N 组一个采样器，各 2 个种子、500 万时隙。

## 5. 判读与局限

- **规则层面**：P0 没有通过，B = M0。按设计，这不是"逐 N 训练无效"的结论：只有两个种子、500 万时隙；两者的学习曲线都没有平台；P0 在 N ≥ 12 上反而较好。
- **对假设的含义**（描述性）：
  - EXP-008 的诊断提示门槛区缺少有信息的经验；
  - 本步把同 N 的经验提高到约 7 倍、违约事件提高 10 倍以上，门槛区可行率没有提高；
  - 所以门槛区的困难不只是经验数量问题。
  - §1 第 4 条的"跨 N 迁移"只是一个解释，本步没有检验。
- **公平性**：
  - P0 的总计算量约为 M0 的 7 倍，但在 N ≤ 10 上没有因此受益；
  - 两者都按 N 选检查点，M0 从同一个混合策略的 5 个检查点中按 N 选择，P0 从各 N 自己运行的 5 个检查点中选择。
- **选择偏差**：每个 N 从 5 个检查点中选最高者，选中值偏乐观，对两者相同；判读只在确认集上进行。
