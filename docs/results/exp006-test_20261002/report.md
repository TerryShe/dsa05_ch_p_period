# EXP-DSA05-006：测试集评估

按设计 §6 与 §13，在协议 v2 的测试集上一次性评估冻结的模型与参照：
- 学习型策略：变体 A，3 个种子，选中检查点与最后检查点；
- 6 类校准本地规则与 `best_local`（每个 N 上验证集最好的校准规则）；
- N_EDF 两版。

测试集为 200 个实例，每个实例 1 次执行，所有方法共用协议 v2 冻结的执行与衰落种子。这是协议 v2 测试集第一次被读取；此后不再根据测试结果修改任何方法、超参数或选模规则。

> **更正（2026-10-02）**：本报告原先把小 N 上的失败表述为"只用本地信息无法保护边缘 UE""学习没有缩小保护差距"。这超出了证据范围：EXP-006 只说明**这个方法**（变体 A，当前的训练设置）在 ε = 0.01 下没有提高 N\*，没有证明任何只用本地信息的策略都做不到。下文相应的表述已改为对本方法的描述。之后的分析（[固定 OBS 文献笔记](../../research/literature-fixed-obs-marl_20261002.md)）还发现，混合 N 训练中大 N 环境主导了梯度（N = 16、20 占约一半的演员样本，每时隙奖励量级是 N = 8 的约 180 倍，优势统一标准化），这可能是门槛处（N = 6–8）没有改善的原因之一，有待检验。

## 1. 结论（按预先写定的判读）

| 判读 | 结果 |
|---|---|
| **H1**：N\*_{0.01}(MARL) > N\*_{0.01}(best_local) | **不成立**：两者都是 6。bootstrap 中 MARL 的 N\* 大于本地规则的比例为 0.30 |
| **H2**：N ∈ {6, 8, 10, 12} 上 F_{0.01} 配对差的 95% 区间下限 > 0 | **N = 8、10、12 成立，N = 6 不成立** |
| 缩小的差距比例（ε = 0.01） | 0（N\* 都是 6，N_EDF = 20） |
| 补充一：S 的配对差（§13） | **+0.129 [+0.108, +0.150]** |
| 描述：ε = 0.05 的 N\* | MARL 12，本地规则 8，N_EDF 20；缩小的差距比例 1/3；bootstrap 中 MARL 的 N\* 更大的比例为 1.00 |

H2 的配对差（MARL 选中检查点，3 个种子合并 − best_local）：

| N | ε = 0.01 | 95% 区间 | ε = 0.05 | 95% 区间 |
|---|---|---|---|---|
| 6 | +0.013 | [−0.003, +0.035] | 0 | [0, 0] |
| 8 | +0.070 | [+0.032, +0.112] | 0 | [0, 0] |
| 10 | +0.188 | [+0.133, +0.248] | +0.068 | [+0.035, +0.105] |
| 12 | +0.252 | [+0.180, +0.323] | +0.153 | [+0.105, +0.207] |

**总的结论**：
- 只用本地信息、集中训练的分布式策略，在中等负载上显著提高了可靠性（N = 8–12 时 F_{0.01} 提高 0.07–0.25，S 提高 0.13），在 ε = 0.05 下把承载能力从 8 提高到 12。
- 但在 ε = 0.01 下没有提高 N\*。小 N 时，两类分布式策略都受限于少数远端快类 UE（§4）；集中式调度在 N ≤ 16 时没有任何失败。
- 本方法缩小了负载带来的差距（N = 8–12），没有改善由少数边缘 UE 决定的门槛（N = 6）。这不说明只用本地信息的方法都不能改善它（见上面的更正）。

## 6. 解释范围与局限

- 只有一个场景（v2.0）、一组参数（K = 4，f_D = 10 Hz，σ_SF = 6 dB）和一种学习方法（变体 A）。C 只在第 1 阶段比较过。
- 3 个训练种子。种子间差别不大（ε = 0.01 时 F(8) 为 0.92–0.95），但 N\* 对门槛附近的波动敏感（种子 303 为 8，其余为 6）。
- `best_local` 的参数与每个 N 上的规则类都在验证集上选定，测试前冻结；它在测试集上的 N\*（6）高于验证集（4），说明本地规则也受益于测试集上较少的极端部署。
- H1 不成立的原因是 N\*_{0.01} 由少数边缘部署决定，而不是学习型策略整体不如本地规则：S 与 N = 8–12 的 F 都显著更高。这一解释来自 §4 的描述性分析，不是预先写定的检验。
- 测试集已被读取。之后任何新的最终比较都要从备用池（30,000 起）另取确认集，并预先登记。

## 7. 研究上的含义与下一步（待用户决定）

1. **两种差距**。在可靠性 ε = 0.01 下，分布式与集中式之间的差距有两部分：
   - **负载带来的协调差距**：集中训练的本地策略能显著缩小。碰撞更少，N = 8–12 时 F 提高 0.07–0.25；ε = 0.05 时承载能力从 8 提高到 12。
   - **边缘 UE 决定的门槛**：远端快类 UE 余量很小。本方法没有在它们需要时让出资源，门槛处的 N\* 没有提高；集中式调度能完全保护它们。只用本地信息的方法能否做到，本实验没有回答（见开头的更正）。
2. **可能的下一步**（任选或组合，均需另立设计）：
   - **EXP-DSA05-007：极少量信令**。例如 AP 为紧迫的边缘 UE 广播"保留某个子信道"，或广播每个子信道的占用。问题是：多少信令能把 ε = 0.01 下的 N\* 从 6 推向 N_EDF 的 20。这直接针对第二部分差距，也最符合"分布式协调"的主线。
   - **学习方法本身**：大 N 时 MARL 与 N_EDF 仍差很多（ε = 0.05 时 12 对 20）。可以考虑在第一部分差距上进一步改进（例如 C 变体的稳定化、更长的训练、记忆）。但本实验显示，在 ε = 0.01 下这部分不是瓶颈。
   - **场景的敏感性**：f_D = 2、50 Hz 的评估（规范 §13 已登记为只评估、不重训）。
