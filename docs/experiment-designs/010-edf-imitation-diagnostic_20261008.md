# EXP-DSA05-010：判别实验——只用本地信息能否学到越过 N = 8 门槛的策略？

状态：**已定稿（2026-10-08，用户批准；第 1 版）**。

- 下一步是第 0 阶段（§5）；第 0 阶段的实现提交并通过验收之前，不训练，不读取 exp010-eval512。
- 定稿时已核查：v2 的开发实例只用过 0–63、1,000–1,399、2,000–2,255、3,000–3,255，开发实例 4,000–4,511 未被使用。

## 1. 问题

### 1.1 背景

EXP-006、008、009 的所有学习变体，在 ε = 0.01 下 N = 8 的可行比例都停在约 0.93–0.94（[EXP-009 确认报告](../results/exp009-confirm_20261007/report.md) §5），容量点估计因此一直与最好的本地规则持平，为 6。这条门槛对以下改变都不敏感：
- 训练信号与更新方式；
- 逐 UE 对偶反馈与回合长度；
- 逐 N 训练；
- 困难部署抽样。

中央调度 N_EDF 在 N = 8 上的可行比例为 1.000。

### 1.2 要回答的问题

0.94 这个上限，是 RL 没有找到更好的本地策略，还是只用本地信息本来就做不到？

- 若前者成立，改目标（文献路线 A）或信用分配（路线 C）才有依据；
- 若后者成立，继续在固定 OBS 下改训练基本无用，应如实报告这一极限，或重新讨论信息边界。

### 1.3 方法：用本地观测模仿中央调度

- **学生**：与现有 Actor 完全相同的网络（CSG GRU）、输入特征与动作集，执行时只用本地信息。
- **老师**：N_EDF（规范版），用全部 UE 的当前状态做决策，只在训练时提供标签。
- **训练**：DAgger（Ross et al., 2011）。在学生自己访问到的状态上取老师的标签，聚合数据后做监督学习，避免只在老师的状态分布上学习造成的偏移。

这符合固定 OBS 的边界：特权信息只用于训练标签（[文献笔记](../research/literature-fixed-obs-marl_20261002.md) §1），学生的输入字段、维度与运行时观测都不变。

### 1.4 结论只在一个方向上成立

- **学生明显超过 RL 的上限**：证明存在只用本地信息、表现更好的策略，瓶颈在 RL 优化。
- **学生没有超过**：不能严格证明本地信息不够。模仿 EDF 得到的只是"对老师决策的最好本地预测"，不一定是最好的本地策略：老师的决策依赖别的 UE 的状态，学生只能猜，猜错就会碰撞或空闲。这只是支持"信息受限"的旁证。

## 2. 设置

### 2.1 不变的部分

- 场景 v2.0、协议 v2 的冻结核心、训练池；
- Actor 结构与本地特征（含自身当前 CSI）、21 个动作（OFF，或 4 个子信道 × 5 个功率档）；
- 执行方式：按策略分布采样，与所有学习方法相同（`MarlPolicy`）。

### 2.2 老师与标签

- **老师**：`CentralEdfPolicy`（规范版，不推迟无望的 UE）。
  - 每个时隙按松弛量对有包的 UE 排序，依次给每个 UE 分配它当前最好的空闲子信道并用最大功率，每个子信道至多一个 UE；
  - 它只用当前状态，不用未来信息。
- **标签**：每个时隙、每个有包的 UE，老师给它的动作（OFF，或（子信道，最大功率））映射到学生的动作编号。没有包的 UE 只有 OFF 一个合法动作，不进入损失。

### 2.3 DAgger

- **按 N 训练**（协议 v2 §4 的补充）：N ∈ {6, 8, 10}，每个 (N, 种子) 一个运行，14 个环境都取这个 N；种子 101、202；共 6 个运行。
- **迭代**：共 6 次迭代，每次收集 14 个环境 × 30 个回合（600 时隙）= 252,000 个环境时隙。
  - 第 1 次迭代由老师执行（β₁ = 1），以后各次由学生执行（β = 0），每次都记录老师在实际访问状态上的标签。这是 Ross et al. 推荐的简单 β 安排。
  - 衰落与执行随机数每个回合重新抽取；部署从训练池均匀抽取，不做困难抽样。
- **训练**：每次迭代后，在聚合到当前为止的全部数据上训练。
  - 交叉熵，只对有包的 UE 时隙求平均，不按类别重新加权；
  - 每个回合按 128 时隙一段做截断 BPTT，段间传递但不反传 hidden state，回合开始时 hidden state 为 0，与 RL 训练相同；
  - Adam，学习率 3e-4，每次迭代 4 个 epoch，每个 mini-batch 16 个回合段，梯度裁剪 0.5。
- **检查点**：每次迭代结束保存一个学生检查点，每个运行共 6 个，格式可由 `load_capacity_policy` 加载。
- **存储**：特征以 float16 存储，训练时转为 float32。按 N = 10 估计，聚合 6 次迭代约 2–3 GB/运行。

这些超参数在定稿时冻结，不在看到筛选或评估结果后修改。第 0 阶段只在已用过的开发实例与训练池上检查损失能否下降、动作预测准确率是否合理。

### 2.4 选模

- 每个 (N, 种子) 的 6 个检查点在 exp009-screen256 的对应 N 上评估（256 个部署），按 (F_{0.01}(N), F_{0.05}(N), 迭代序号) 选择，规则同 EXP-009 §3。
- exp009-screen256 已被 EXP-009 反复使用，这里只用于学生的检查点选择，不用于判别。

## 3. 判别评估

### 3.1 评估集

**新开发切片 exp010-eval512**：开发池 4,000–4,511，512 个部署，N ∈ {6, 8, 10}，每个部署 1 次执行。

- 只用于本实验的判别评估，按 EXP-009 的方式登记（机器清单、摘要、`--screen exp010-eval512 --formal`），定稿时核查未被使用；
- 不读取任何确认集：本实验得出的是开发阶段的决策依据，不是论文的正式结论。

在 exp010-eval512 上评估以下方法，全部公共随机数配对：

| 方法 | 内容 |
|---|---|
| IL | 学生，两个种子，各 N 选中的检查点 |
| A-mix | EXP-009 冻结方法清单中 A_mix 的三个种子层（N = 6、8、10 的模型） |
| M | EXP-009 的 S1 三个种子层（描述性） |
| best_local | 按 N 冻结的最好本地规则 |
| N_EDF | 老师本身（参照） |

### 3.2 主统计量与判别规则

- **主统计量**：D₈ = F_{0.01}(8; IL) − F_{0.01}(8; A-mix)。
  - IL 按两个种子平均，A-mix 按三个种子平均；
  - 两层配对 bootstrap，部署配对，各方法的训练种子各自重抽，10,000 次，种子 20260930。
- **判别**（预先写定）：

| 结果 | 条件 | 解释与下一步 |
|---|---|---|
| **优化受限** | D₈ 的 95% 区间下限 > 0，且 F_{0.01}(8; IL) ≥ 0.95 | 存在只用本地信息、在 N = 8 上越过门槛的策略，RL 没有找到它。下一步：信用分配（路线 C），或以 IL 初始化再用 RL 微调可靠性 |
| **部分优化受限** | D₈ 的 95% 区间下限 > 0，但 F_{0.01}(8; IL) < 0.95 | 本地信息允许比 RL 更好的协调，但模仿本身还不能越过门槛。下一步同上，但门槛能否越过仍不确定 |
| **无证据** | D₈ 的 95% 区间下限 ≤ 0 | 模仿中央调度没有带来更好的本地策略，这是"信息受限"的旁证（不是证明）。下一步：整理论文，如实报告这一极限，或重新讨论信息边界 |

- **描述性**：
  - N = 6、10 上的 F 与差值；
  - M 与 best_local 的比较；
  - 学生与老师的差距（N_EDF 的 F）；
  - 动作一致率：学生采样的动作与老师在同一状态下的动作相同的比例，在开发实例上按 N 统计；
  - 同信道碰撞率；
  - 失败分解：用第 0 步的脚本在开发实例 1,000–1,399 上分解，看干扰类违约是否减少。

## 4. 风险与局限

- **结论只在一个方向上成立**（§1.4）："无证据"不能写成"本地信息不够"。
- **老师的选择**：EDF 是正交调度，每个子信道至多一个 UE，并总用最大功率，所以学生学不到"同信道低功率共存"这类非正交行为。这是对 EDF 的模仿，不是对最优中央策略的模仿。
- **随机执行**：老师是确定的，学生按分布采样；采样可能造成老师不会出现的碰撞。只报告采样执行，与所有学习方法的评估一致。
- **训练预算**：每个运行 1.5M 个环境时隙，少于 RL 的 5M。模仿学习通常更省样本，但若学生的学习曲线在第 6 次迭代仍明显上升，判别偏向"无证据"。此时如实报告，不在本实验内追加迭代。
- **选择偏差**：检查点在 exp009-screen256 上选择，判别在独立的 exp010-eval512 上进行。

## 5. 第 0 阶段（定稿后）

- 新模块 `marl/imitation.py`：
  - DAgger 训练器：同步运行老师与学生，学生用 `LocalMemory` 生成特征，老师用全部 UE 的 `UEObservation` 给出动作并编码为学生的动作编号；
  - 按回合存储的聚合数据集（float16），截断 BPTT 的监督训练；
  - 检查点格式与 `load_capacity_policy` 兼容。
- 命令行 `train_imitation`：配置文件（按 N），`--num-ues`、`--formal`、manifest。
- 集合登记：exp010-eval512（机器清单、摘要、守护测试）。
- 驱动：训练 6 个运行；检查点在 exp009-screen256 上按 N 筛选并选择；在 exp010-eval512 上评估 IL、A-mix、M、best_local、N_EDF；做判别分析。
- **测试**：
  - 老师动作到学生动作编号的映射；
  - 没有包的 UE 不进入损失；
  - 第 1 次迭代由老师执行，以后由学生执行；
  - 截断 BPTT 与 hidden state 的传递；
  - 检查点可加载并能在任意 N 上执行；
  - 判别分析的统计在合成数据上正确。

## 7. 定稿时确认的决定（2026-10-08）

1. **范围**：只做判别（模仿 EDF），不在本实验内做 RL 微调或信用分配。
2. **老师**：N_EDF 规范版。
3. **DAgger 设置**：N ∈ {6, 8, 10}、种子 101 与 202、6 次迭代 × 252,000 个环境时隙、β₁ = 1 之后为 0、交叉熵不加权，以及 §2.3 的训练超参数。
4. **评估集**：新开发切片 exp010-eval512（开发池 4,000–4,511，N = 6、8、10），不读确认集。
5. **判别规则**：D₈（IL 对 A-mix）与 F(8) ≥ 0.95 的组合，三类结果及其对应的下一步（§3.2）。
