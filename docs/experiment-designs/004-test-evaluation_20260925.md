# EXP-DSA05-004：冻结模型的测试集评估计划（草案）

状态：**草案**。N=4、N=6 长训（EXP-DSA05-001 第 2c 阶段）完成、用户确认后定稿。定稿后才读取测试集，此后不再根据测试结果修改任何方法、超参数或选模规则（[MARL 实验协议 v1](../research/marl-protocol-v1.md) §7）。

## 1. 评估对象

**主结果（长训，N ∈ {4, 6, 8, 12}）**：EXP-DSA05-001 第 2a、2b、2c 阶段的正式运行，每个 N 各 6 个（A 固定惩罚 w=10 与 C 逐 UE 对偶 η=2，各种子 101、202、303）。每个运行评估两个检查点，都使用该运行在验证集上选出的 μ0：
- 按协议规则在验证集上选中的候选（主结果）；
- 最后一个检查点（辅助结果，检验选模是否带来偏差）。

**次要结果（短训，N=8）**：EXP-DSA05-001 第 1 阶段三个变体的入选设置（A w=10，B η_B=20，C η=2），各 3 个种子，只评估选中的候选。目的是在测试集上确认全局乘子（B）的失败，以及短训与长训的差距。

**基线（每个 N）**：
- 参照基线：按验证集校准选出的 paced_sticky（N=4 margin=0，N=6 0.25，N=8 0.5，N=12 8）；
- random_max、sticky_max、lazy_pacing。

**中央参照**：测试集的逐实例上下界已经存档（[协议 v1 参照](../results/protocol-v1-references_20260924/report.md)），作为能耗/上界与能耗/下界的分母。

## 2. 执行

- 入口：`python -m dsa_period.experiments.evaluate_marl --split test --confirm-test --formal`，从干净的提交运行。
- 每个 N 一次调用：包含全部长训运行、四个基线，参照基线为校准选出的 paced_sticky。N=8 另加一次调用评估短训的 A、B、C。
- 测试集：200 个实例 × 2 次执行，使用协议冻结的执行种子；所有方法共用同一组执行种子。

## 3. 指标与判读（协议 §5）

每个方法报告：
- 可行率 F 及其 95% 区间；
- 能耗/上界、能耗/下界及其 95% 区间；
- 最差 UE 完成率、每 UE 功率；
- 逐 UE 违约率的分布（中位数、95% 分位数、最大值）。

区间使用两层 bootstrap：先对训练种子重抽样，再对实例重抽样，10,000 次，种子 20260926。

**预先写定的判读**：
1. **满足约束**：测试集 F ≥ 0.95。
2. **显著节能**（只在满足约束的方法之间判断）：与参照基线逐实例配对，能耗/上界之差的 95% 区间上限 < 0。
3. **A 与 C 的比较**：逐实例配对的能耗/上界之差及其区间。区间包含 0 时报告为"没有显著差异"。
4. **与最优的差距**：报告能耗/上界和能耗/下界的均值与区间。N=4 时上界等于下界（精确最优）。
5. **次要结果**：B 在测试集上 F < 0.95 视为确认了验证集上的失败；否则如实报告不一致。

所有结果都报告，不做事后挑选。选中检查点与最后检查点分别列出。

## 4. 需要确认的决定

1. 主结果为长训的 A 与 C（选中检查点），最后检查点作辅助；次要结果为 N=8 短训的 A、B、C。
2. 参照基线为验证集校准选出的 paced_sticky；random_max、sticky_max、lazy_pacing 一并报告。
3. 判读规则如 §3。
