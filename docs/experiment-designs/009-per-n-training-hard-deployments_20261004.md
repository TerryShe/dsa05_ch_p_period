# EXP-DSA05-009：逐 N 训练与困难部署抽样（固定 OBS）

状态：**已定稿（2026-10-04，用户批准；第 2 版）**。用户确认 §11 的各项，并选定 A-mix 只用每个种子最后 5 个检查点（§6）。

- 下一步是第 0 阶段（§9）。第 0 阶段的实现提交并通过验收之前，不训练，也不读取筛选集或确认集。
- 定稿时已核查：v2 的开发实例只用过 0–63、1,000–1,399、2,000–2,255，没有任何 v2 运行读取过备用池实例；开发实例 3,000–3,255 与备用池 30,500–30,999 都未使用。

第 2 版按 2026-10-04 的决定改写：
- 学习方法改为同一种算法在每个 N 分别训练、分别评价（[场景 v2.0](../research/scenario-v2.md) 与[协议 v2](../research/marl-protocol-v2.md) §4 的补充）；
- 第 1 步比较逐 N 训练与混合 N 训练，第 2 步在胜出的训练方式上检验困难部署抽样；
- 跨 N 泛化列为后续工作，不在本实验中评估。

## 1. 动机与问题

### 1.1 已有证据

1. **门槛区的失败集中在少数部署**（[第 0 步](../results/step0-failures_20261002/report.md)）：
   - 失败 UE 多为远端（距离中位数约 90 m）、阴影约 −9 dB 的快类与中类 UE；
   - 错过的包以干扰类为主；
   - 真正受物理限制的失败 UE，每个 N、每 400 个部署只有约 2 个。
2. **门槛区在训练中几乎没有违约事件**（[EXP-008 第 1 轮](../results/exp008-round1_20261003/report.md) §5，[第 2 轮](../results/exp008-round2_20261004/report.md) §5）：
   - 所有条件下，N = 6、8 的训练 rollout 有 91–99% 没有违约；
   - 300 万时隙以后，固定诊断 rollout 中 N = 6、8 每 12,800 个环境时隙只有 0–2 个违约时隙；
   - 训练回合加长到 2,400 时隙也没有改变这一点。
3. **混合 N 训练的更新方向由大 N 决定，重新加权没有用**（EXP-008 第 1 轮 §5.2、§3）：
   - R0 训练后期，N = 16、20 的投影份额合计约为 1，N = 6、8 约为 0；
   - F1、F2 把一部分方向转向门槛区，但门槛区可行率没有提高。

### 1.2 假设与两个杠杆

假设：**门槛区缺的不是信号的权重，而是有信息的经验太少。**

两种方式可以增加门槛区的经验：
- **逐 N 训练（第 1 步）**：每个 N 的模型只在自己的 N 上训练。同样每个运行 500 万时隙，N = 8 的模型见到的 N = 8 部署约是混合训练（14 个环境中 2 个为 N = 8）的 7 倍，而且不再与大 N 共享更新方向。
- **困难部署抽样（第 2 步）**：在同一个 N 内，提高困难部署出现的频率。这正好针对 1.1 第 1 条：失败集中在少数部署。

两步分开，才能区分收益来自"同一 N 见得更多"还是"见得更难"。

### 1.3 研究问题

在执行 OBS、网络结构与更新规则都不变的条件下：

- **第 1 步**：逐 N 训练能否比混合 N 训练提高门槛区可行率？两者都按 N 选择检查点。
- **第 2 步**：在第 1 步胜出的训练方式上，静态困难分层抽样或优先级部署重放（PLR）能否进一步提高？
- **确认**：选出的算法在独立确认集上能否提高 ε = 0.01 的容量点估计？

**范围**：
- 不新增 OBS、信令、辅助任务或逐 UE 信用分配；
- Actor 不接收部署编号、难度标签或 N；
- 不评估跨 N 泛化（后续工作）。

### 1.4 目标的含义

- **逐 N 训练**改变的是"算法怎样实例化"，不改变每个 N 上的训练目标。
- **困难部署抽样**改变了训练目标中各部署的权重。本实验**不做重要性加权**，明确把它作为课程或稳健训练的目标。评估分布不变：筛选集与确认集都按协议均匀抽取部署，所以收益是在真实部署分布上测得的。

## 2. 共同设置

- **算法 R0**：EXP-006 的变体 A 的更新（EXP-008 确定 B2 = A-600 = R0）。
  - 网络、PPO 超参数、奖励、600 时隙回合、rollout 128 都不变；
  - 所有 N 的超参数相同，不按 N 调整。
- **逐 N 训练的运行**：
  - 14 个并行环境都取同一个 N，mini-batch 仍按 4 个环境切分，与混合训练的批结构相同，每次迭代的 UE 样本数为 14N；
  - 训练的 N 为 {2, 4, 6, 8, 10, 12, 16, 20}；
  - 每个 (N, 种子) 一个运行，各 500 万环境时隙，每 100 万一个检查点。
- **混合训练的对照 M0**：
  - 直接复用 EXP-008 第 1 轮 R0 的两个运行（种子 101、202，与 EXP-006 第 1 阶段 A 逐位相同），不重训；
  - 它的每个检查点是一个跨 N 策略，在新筛选集的每个 N 上评估，然后与逐 N 训练一样按 N 选择检查点。
- **训练池与随机性**：
  - 只从 train 池（1,000,000–1,999,999）抽部署；
  - 每次进入一个部署（包括重放）都重新抽取衰落与执行随机数。
- **禁止**：把开发、验证、旧测试或任何确认集的实例放入训练，也不把在这些集合中发现的困难部署当作训练"种子"。

## 3. 筛选集、选模与确认集

- **新筛选集 exp009-screen256**：开发池 3,000–3,255，256 个部署，N ∈ {2, 4, 6, 8, 10, 12, 16, 20}，每个部署 1 次执行。
  - 逐 N 训练的检查点只在自己的 N 上评估，每个检查点 256 个回合；
  - M0 的检查点在全部 8 个 N 上评估。
  - 定稿时核查 v2 开发实例的使用记录（目前用过 0–63、1,000–1,399、2,000–2,255），并按 EXP-008 的方式登记机器清单与摘要。
  - 不沿用 exp008-screen256：它已被 EXP-008 反复用于选择，而且只覆盖 N = 6、8。
- **按 N 选模**：对每个条件、种子与 N，选择筛选集上 F_{0.01}(N) 最高的检查点；相同时取 F_{0.05}(N) 较高者，再相同时取较晚者。
  - 一个"种子层"是该种子在 8 个 N 上的选中模型的组合。
- **旧验证集（64 个实例）不再参与本实验的选择与保护**：新筛选集已覆盖全部训练的 N，且部署更多。
- **确认集 v2-confirm2**：备用池 30,500–30,999，500 个部署，每个 1 次执行，只读一次，需要 `--confirm-c2 --formal`。
  - v2-confirm1 已登记给 EXP-008，EXP-008 结束时没有读取；仍不把它转给本实验，以保持登记清楚。

## 4. 第 1 步：逐 N 训练（P0）与混合训练（M0）

- **运行**：P0 在 8 个 N × 种子 101、202 上各训练一次，共 16 个运行；M0 复用。
- **评估**：
  - P0：16 × 5 × 256 = 20,480 个回合；
  - M0：10 个检查点 × 8 个 N × 256 = 20,480 个回合。
- **保留规则**（沿用 EXP-008 §4.2 的思路，全部在新筛选集上，均为按 N 选中的模型、两个种子的平均，相对 M0）：
  1. **改善**：S_near = [F_{0.01}(6) + F_{0.01}(8)] / 2 的平均提高 ≥ 0.01，且每个种子（按编号配对）都 ≥ 0；
  2. **其他 N 不退化**：N ∈ {2, 4, 10, 12} 的 F_{0.01}(N) 各自下降都不超过 0.01；
  3. **末段**：N = 6、8 上，最后两个检查点的平均 F_{0.01} 不低于 M0；M0 取它在这两个 N 上的最后两个检查点；
  4. **低负载**：F_{0.01}(2) ≥ 0.95；
  5. **逐 N**：F_{0.01}(6)、F_{0.01}(8) 各自下降都不超过 0.01。
- **基线 B**：P0 通过全部 5 条时 B = P0（逐 N 训练），否则 B = M0（混合训练）。
  - 两种结果都是关于"训练方式"的有用信息。
  - N = 16、20 的 F 只作描述，不进入规则。

## 5. 第 2 步：在 B 上的困难部署抽样

每个 N 组各有一个采样器：逐 N 训练时每个运行只有一个 N；混合训练时，同 N 的两个环境共用一个采样器。

| 代号 | 训练部署分布 | 依据 |
|---|---|---|
| U | 均匀抽样（对照，即 B 的运行，复用） | — |
| S1 | 静态困难分层：每次以概率 q = 0.5 从该 N 的困难层抽取（拒绝抽样），否则均匀抽取 | 文献笔记建议的最小对照第 2 项；与策略无关 |
| P1 | PLR，原文得分：回合内 GAE 绝对值的平均（L1 value loss） | Jiang et al., ICML 2021，式 (2) |
| P2 | PLR，DSA05 得分：回合内最差 UE 的可避免违约率 | 本课题的扩展，不称为原文算法 |

### 5.1 S1 的困难层

- **难度标签**（训练侧，与策略无关，不含衰落）：
  - 对部署中每个 UE，计算大尺度服务裕量 m_i = c_i / r_i；
  - c_i 是该 UE 独自以最大功率发送时、按路径增益与阴影计算的每时隙香农容量；
  - r_i 是该 UE 每个时隙平均需要的比特数（包大小 ÷ 周期）。
  - 部署的难度 h = min_i m_i。
- **困难层**：h 低于该 N 的 10% 分位数 τ_N。
  - τ_N 在第 0 阶段用训练池中按固定种子抽取的 20,000 个实例计算，写入配置后冻结。
  - 它只用 train 池实例计算，不读取任何评估集合。
- **局限**：这个标签只反映"弱 UE"，不反映干扰协调的难度，这正是 S1 与 P1、P2 对照的意义。

### 5.2 PLR 的共同设置（P1、P2）

- **重放决定**：每个回合开始时，以概率 p = 0.5 从该 N 的缓冲区重放，否则从训练池均匀抽取一个新部署；缓冲区少于 50 个部署时不重放。
  - 原文在有限训练集上让重放概率随已访问比例增加；在无限池上使用滚动的有限缓冲区（原文附录 B.3，尚未核对）。
  - 本实验的训练池实际上无限，固定的 p、缓冲区大小与最小填充数是**本设计的选择**，不是原文参数。
- **缓冲区**：每个 N 组最多 500 个部署。满了以后，新部署替换得分最低的一个；若新部署得分更低，则不进入缓冲区。
  - 逐 N 训练时，每个运行 500 万时隙约有 8,330 个回合；p = 0.5 时约 4,170 个新部署，缓冲区保留其中得分最高的 500 个。
  - 混合训练时，每个 N 组约 1,190 个回合，缓冲区能容纳其中的大部分新部署。
- **重放分布**：P_replay = (1 − ρ) P_S + ρ P_C。
  - P_S：按得分排序的秩优先级，h(S_i) = 1/rank(S_i)，温度 β = 0.1；
  - P_C：按陈旧度 c − C_i 成比例；
  - ρ = 0.1。β、ρ 取原文 Procgen 主实验的值（原文 §5.1）。
- **得分更新**：每个部署在每次回合结束后更新一次得分与时间戳。
  - P1 的得分要用回合中每个时隙的 GAE，而 GAE 在包含该回合最后一段的那次更新时才算出，所以得分晚一个 rollout 生效；
  - P2 的得分在回合结束时即可算出。
- **随机数**：
  - 新部署照旧用训练器原来的随机流抽取，因此 U 的路径逐位不变；
  - 重放决定与重放抽样使用独立的随机流（由种子派生）。

### 5.3 P2 的得分

回合结束时，对每个 UE i：
- v_i 为本回合结算的违约包数；
- u_i 为其中物理上不可送达的包数，即在截止窗口内每个时隙都用最好的子信道、最大功率，独自也送不完，判据与 `capacity.undeliverable` 相同；
- M_i 为本回合结算的包数。

得分 S = max_i (v_i − u_i) / max(M_i, 1)。

- **依据**：门槛区失败以可避免的违约为主（第 0 步）；扣除不可送达的包，避免反复重放怎么做都会失败的部署。
- **局限**：600 时隙的回合里，快类 UE 只有约 60 个包，得分很粗；多数回合的得分为 0，此时秩排序退化为并列。并列者取平均秩，相当于在得分为 0 的部署之间均匀抽取。

### 5.4 运行、规则与选择

- **运行**：S1、P1、P2 在 B 的训练方式上各训练一次，种子 101、202。
  - B = P0 时，每个条件在 8 个 N 上各一个运行，共 48 个运行；
  - B = M0 时，每个条件是一个混合训练运行，共 6 个运行。
- **规则**：沿用 §4 的五条，对照换成 U（B 的运行）。
- **选择**：在保留的条件中取平均 S_near 最高者；与最高者相差不超过 0.005 时，按 S1、P1、P2 的顺序取较简单者。
- **结论**：
  - 选出的算法记为 M。没有条件被保留时，M = B。
  - 若 M = M0，即第 1、2 步都没有保留任何改变，本实验以负结果结束：不确认，也不读确认集。
- **不做的事**：不做条件组合（例如 S1 + P2），也不在看到结果后调整 q、p、β、ρ、缓冲区大小或 τ。

## 6. 定型与确认

- **定型**：
  - M 增加种子 303，与 101、202 相同的预算；
  - 若 M 是逐 N 训练，即 8 个新运行；
  - 三个种子都按 §3 的规则在新筛选集上按 N 选模，同时报告最后检查点。
- **主基线 A-mix**：EXP-006 三个长训种子（2,000 万时隙，混合训练）**最后 5 个检查点**（1,200 万–2,000 万时隙）在新筛选集全部 8 个 N 上评估，按同一规则按 N 选模。
  - 15 个检查点 × 8 个 N × 256 = 30,720 个回合，约 4 小时；
  - 只用后半段检查点是用户的选择（定稿时），用来控制成本；混合训练在前 1,000 万时隙的检查点不参与选择。
- **确认**：在 v2-confirm2 上评估：
  - M 的 3 个种子层；
  - A-mix 的 3 个种子层；
  - best_local 与六类冻结本地规则（各自已按 N 校准）；
  - N_EDF 两版。
  - 学习方法 N ≤ 20 用各自 N 的模型，N ≥ 24 用 N = 20 的模型（只作描述）。
- **判读**（只在 v2-confirm2 上，口径同 EXP-008 §7.2、§7.3）：
  - **H1**：N\*_{0.01}(M) > N\*_{0.01}(A-mix)；
  - **H2**：F_{0.01}(8; M) − F_{0.01}(8; A-mix) 的 95% 区间下限 > 0，且 N = 6 的差值区间下限 > −0.01；
  - **H3**：N\*_{0.01}(M) > N\*_{0.01}(best_local)。
  - **主张的范围**：H1、H3 是容量点估计，不是显著性检验。若 M 是逐 N 训练且没有采样器（M = P0），结论只针对"逐 N 训练"这一训练方式。
- **描述性结果**：ε = 0.05，N ≥ 24，各种子层，失败分解（第 0 步的脚本，开发实例 1,000–1,399），与 N_EDF 的差距。

## 7. 诊断（描述性）

- **门槛区事件**：训练中 N = 6、8 的违约率、无违约 rollout 比例。逐 N 训练时，同一诊断脚本以该 N 的 14 个环境运行，种子 8008001。
- **梯度构成**：只对混合训练的运行有意义（M0 与 B = M0 时的第 2 步），沿用 EXP-008 §8。
- **采样器**：重放比例、缓冲区的得分分布、新部署与重放部署的比例、训练全程抽到的不同部署数、被重放次数最多的部署及其次数。
- **难度覆盖**：被训练的部署按难度 h 的分布（与均匀抽样比较），以及按业务类别和服务裕量分组的有包 UE 时隙数。
- **过拟合检查**：选中模型在被重放最多的训练部署上（换新衰落）与在新筛选集上的可行率之差。

## 8. 风险与局限

- **逐 N 训练的收益来源**：可能来自"同一 N 的经验更多"，也可能来自"不与大 N 共享更新方向"，第 1 步不区分这两者。两者都是训练方式的性质，不作进一步拆分。
- **计算量不对等**：逐 N 训练的总计算量约是一次混合训练的 7 倍（各 N 的计算量随 N 增长）。比较按每个运行相同的环境时隙对齐，同时报告总 UE 时隙与墙钟时间。A-mix 的长训（2,000 万时隙）是对混合训练更有利的对照。
- **训练更难不等于方法更好**：困难抽样的收益可能只来自"多见了难部署"。S1 是这一解释的对照；P1、P2 只有在明显优于 S1 时，才能说是随策略变化的优先级在起作用。
- **得分噪声**：P1 在门槛区可能主要反映价值残差，P2 的得分粗、多数为 0。两者的失败都不能推广为"PLR 无效"。
- **按 N 选模的多重选择**：8 个 N × 5 个检查点 × 多个条件都在同一筛选集上选择，选中值偏乐观。判读只在确认集上进行。
- **部署假设**：执行时按 N 选用模型，需要 N 在配置时已知；N 在运行中变化的情形（跨 N 泛化）不在本实验内。

## 9. 第 0 阶段（定稿后）

- **配置**：逐 N 训练的配置（`env_ues` 为 14 个相同的 N），每个 N 一个，或一个配置加 N 参数；其余设置与 R0 逐项相同（测试核对）。
