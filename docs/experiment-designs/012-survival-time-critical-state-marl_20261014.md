## 1. 问题

### 1.1 工程问题

- **需求**：工业时间敏感通信（TSC）的周期业务有生存时间要求（3GPP TS 22.104）：应用能容忍少量连续丢包；连续丢包超过生存时间，服务即中断。工业控制关心的是"不连续丢包"，不只是平均丢包率。
- **在本场景中的定义**：每个 UE 的传输间隔就是它的业务周期（10、20、40 ms），截止期为下一次到达。生存时间取 s 个传输间隔：
  - 一个 UE 连续 s + 1 个包违约，记为一次**服务中断**（起止时刻见 §2）；
  - 主条件 s = 1（容忍 1 个丢包，连续 2 个即中断），敏感性 s = 2。
  - s 的取值须在定稿前对照 TS 22.104 的用例表核对（§9 第 1 项）。
- **场景**：工业周期上行，多个设备共享 K 个子信道（类比共享或超配的配置授权资源），每个设备每个时隙只用本地信息自主选择（子信道, 功率）或不发送；衰落、TIN 干扰、HARQ-IR 跨时隙累积。场景 v2.1 不变。

### 1.2 现有方案与不足

| 方案 | 做法 | 在本问题上的不足 |
|---|---|---|
| Rel-17 生存时间状态 | 一次失败后进入生存时间状态，激活 PDCP 复制 | 固定的反应式规则；复制占用额外资源；不同设备之间不协调 |
| 网络侧 RL（Ericsson/KTH，PIMRC 2023、TII 2023） | gNB 与上层为各设备配置下行功率与 HARQ 次数，以生存时间定义的可用度为目标 | 网络集中决策，下行；不是设备自主接入 |
| 单链路 RL（in-X 子网，arXiv 2025） | SAC 按连续中断次数调整功率与码长 | 其他链路是外生干扰；不处理多个设备为各自的生存时间竞争同一资源 |
| 静态配置授权（CG-opt） | 按统计信息独占分配 | 跟不上衰落；连续违约在 CG-opt 上最严重（§1.3） |
| 本项目已有方法（M、U、M+Y） | 以失败包总数为训练目标 | 降低了平均违约率，也降低了一部分违约之后的风险，但违约后的风险仍在 10–15% 量级；训练目标不直接控制中断（§1.3） |

**多设备时特有的难点**：一个设备进入生存状态后，若它采取保护动作（换到更好的子信道、提高功率、更积极地发送），会提高其他设备的失败风险，可能把它们也推入生存状态。保护需要协调，而每个设备只有本地信息。

### 1.3 已有证据（描述性，只用已读集合）

- **违约成串出现**（RES-DSA05-SURVIVAL-CHECK，exp011b-eval128，v2.0；与 v2.1 相同的部署子集上结论一致）：
  - M、U、M+Y 中，一个包违约后，下一个包违约的概率为 10–15%，而平均违约率只有 0.016–0.10%；
  - 按每个 UE 自己的违约数作独立参照，相邻违约对是参照的 4–14 倍；
  - s = 1 时，N = 8–12 上 7–24% 的部署在 20 秒内至少中断一次；
  - 多数连续违约在集中调度下可以避免：N_EDF 的违约几乎全部是物理上无法送达的包（53/53、63/64、68/70）。这提示存在改善空间，不证明有限信息的分布式策略能取得同样的收益；
  - U、M+Y 把违约后下一包的违约概率降低了 10–28%（例如 N = 12：M 13.3%，U 9.6%，M+Y 9.5%），但仍在 10–15% 量级。
  - （2026-10-14 更正：第 2 版原写"已有方法没有降低违约之后的风险"与"N_EDF 只在物理上无法送达的包上违约"，与数值不符，已改正，不改变任何判据。）
- **关键状态稀少，学习策略恰好在那里最弱**（RES-DSA05-EXP011B）：
  - 违约之后的包只占全部包的 0.02–0.1%，却贡献 10–15% 的违约；
  - 规则 M+Y 只在 0.1–0.3% 的决策上起作用，却得到约 40% 可挽回的差距；
  - 学习的响应没有学到紧迫信息的语义（U ≈ O ≈ L），在 U 自己的训练目标上也不如 M+Y。
- **据此的判断**：均匀采样时隙、按 N 平均团队奖励的 MAPPO，从关键状态得到的训练信号极少。这是本设计方法的出发点（§3）。

## 2. 指标

### 2.1 定义（时间以时隙边界计；截止期与送达时刻都是边界）

- 每个包有截止期 d（下一次到达）。在截止期之前译码成功，送达时刻 c 是译码所在时隙之后的边界（c ≤ d）；否则在 d 处结算为违约。
- **生存时间状态**：UE 的包在截止期结算为违约时进入；该 UE 之后的某个包**译码成功的时刻**退出。k_i 为当前连续违约的包数，译码成功即清零。UE 从自己的译码反馈就能知道成功，这是本地信息。
- **服务中断**：
  - **开始**：第 s + 1 个连续违约包的截止期 d，即生存时间耗尽的时刻；
  - **恢复**：之后第一个成功送达的包的**实际送达时刻** c，**不按**它的截止期结算时刻；
  - 中断时长为 c − d 个时隙。同一串中之后的违约延长这次中断，不另计次数。
  - 第一次违约到中断开始之间（生存时间状态）不算不可用。
- **评估窗口**：(W, H]（预热 W = 200，H = 20,200 个时隙）。中断时长截到窗口内；窗口结束时仍未恢复的，算到 H。开始时刻落在窗口内的中断才计入次数。连续违约的判定使用全部已释放的包（含预热期的包）。
- **不可用度** U_i：UE i 在评估窗口内处于中断的时隙数 / (H − W)。**可用度** A_i = 1 − U_i。
- **中断次数** O_i：评估窗口内开始的中断数。

### 2.2 首要与辅助指标

- **首要指标 Q_U**：每个部署中 max_i U_i（最差 UE 的不可用度）在部署间的平均；方法间的配对差值与两层 bootstrap 区间（同协议 v2：10,000 次，种子 20,260,930）。
- **重要的辅助指标 Q_O**：每个部署中 max_i O_i（最差 UE 的中断次数）的部署平均。它反映中断的频繁程度，与按时间计的不可用度互补。
- **其他辅助指标**：
  - 全部 UE 的平均不可用度；至少出现一次中断的部署比例；
  - 违约后下一个包的违约概率；
  - P2 与全部 UE 的平均违约率（H4 的非劣检验）；
  - 资源代价：平均发射功率与占空比（类 Rel-17 对照的代价比较）。
- **实现**：评估记录增加逐包违约与每个 UE 在 s = 1、2 下的中断次数与中断时隙数，由环境的逐包记录（截止期、送达时刻、是否成功）计算；已有字段不变。

## 3. 方法

### 3.1 共同基础

所有学习方法沿用 M 的流程：循环 MAPPO、共享 Actor、集合 Critic、混合 N 训练（N = 4–20）、静态困难分层采样、按 N 选检查点，超参数不变；在场景 v2.1 的训练池上从头训练。

### 3.2 提出的方法（暂称 SC：survival-critical MARL）

| 组件 | 内容 |
|---|---|
| C1 生存状态输入 | Actor 的上下文中加入 min(k_i, 2) 的独热编码与"距中断还剩几个包"（s − k_i，截到 0） |
| C2 生存标志广播 | 沿用 EXP-011 的 L1 链路与接收模型（θ_f = −10 dB，按子信道 OR，一个时隙的时延），上行比特的内容改为"我处于生存状态"；Actor 看到 K 比特广播 |
| C3 训练目标 | 每个时隙每个 UE 的代价 c_i(t) = 1[t 时结算出违约] + λ_d · 1[UE i 在时隙 t 处于中断]，λ_d = 1；团队奖励 −(1/N) Σ c_i。处于中断的时隙按 §2.1 计（从中断开始到实际送达） |
| C4 关键状态分支训练 | 见下 |

**C3 的定位**：C3 是代理目标。它惩罚的是全体 UE 的平均"违约加中断时隙"，不等于最差 UE 的不可用度；固定的 λ_d 也**不提供生存时间约束的任何保证**。方法是否有效，只由评估在 §2 的指标上判定，结论中不写"满足约束"。λ_d = 1 时，快类 UE 每多中断一个周期（10 个时隙）的代价为 10，慢类为 40，与按时间计的不可用度一致。

**C4 关键状态分支训练**（针对 §1.3 的训练信号稀少）：
- 训练中，任一环境里某个 UE 因违约进入生存状态时，以概率 p_snap 保存快照：环境、本地记忆、L1 链路、循环隐状态与采样器状态。保存与恢复已在第 0 阶段核查中验证可行：复制后的继续运行与原运行逐位相同。
- 每次重置环境时，以概率 f_branch 从快照缓存中取一个快照开始分支回合（策略的采样随机数重新派生，衰落沿用快照的未来），否则照常抽取新部署。
- 分支回合运行 L_branch 个时隙（覆盖该 UE 之后若干个周期），然后截断并自举，与普通回合相同。
- 效果：提高训练样本中关键状态的比例。代价：训练的状态分布偏离自然分布，优化的是"自然分布与关键状态分布的混合"下的目标。这一偏差如实记录，由评估在自然分布上检验。
- 参数 p_snap、f_branch、L_branch、缓存大小在第 0 阶段写定（§9 第 3 项）。

### 4.1 先导（阶段 1）

- **训练**：SC、SC−B、M-S、M，各 2 个种子，各 5M 时隙（8 个运行，并行约 3–4 小时）。
- **评估**：最后一个检查点（不选模），先导切片（§5）上 N = 10，另跑 N = 8、12 作描述；规则对照 M+S、M+Y、R17-like 都建立在先导的 M 上。
- **关口 A 的判据**（两个种子，按点估计；预先写定）：
  - 继续，须同时满足：
    1. SC 的 Q_U 比最好的规则对照（M+S、M+Y、R17-like 中 Q_U 最低者）低至少 20%；
    2. SC 的 Q_U 比 M-S 低至少 20%（否则"只改奖励"就够了，整套方法没有必要）；
    3. SC 的 P2 不高于 M+S 的 1.10 倍。
  - 调整：SC 的 Q_U 低于 M，但不满足上面任一条。与用户讨论修改方法，修改作为设计修正记录。
  - 停止：SC 的 Q_U 不低于 M。
  - 同时报告 SC 对 SC−B（分支训练的作用）与各项辅助指标，只作描述。
- 先导只有两个种子，判据按点估计，区间只作描述，不据此声称任何显著或非劣。
- 先导的结果只用于决定是否继续及选择变体，不进入阶段 4 的判据；先导切片之后不再用于评估。
- （第 3 版）阶段 1b 属于先导的"调整"分支，再次使用先导切片（§10.5）；阶段 1b 之后先导切片不再用于评估。

### 4.2 主判据（阶段 4，写定后冻结）

- **主比较（H1）**：D_N = Q_U(SC) − Q_U(M+S)，N ∈ {8, 10, 12}。三个 N 的 95% 区间上限都 < 0 为"有效"，一个或两个为"部分有效"，没有为"无证据"。
- **非劣检验（H4）**：
  - 参照方法：M+S（主比较的对照）。
  - 指标：P2 与全部 UE 的平均违约率，各自检验。
  - 界限：相对 10%，即均值比 P2(SC) / P2(M+S) 的非劣界为 1.10。
  - 判定：在 N = 8、10、12 上，均值比的两层 bootstrap 95% 区间上限都 < 1.10，判为非劣；否则不能判为非劣，如实报告。区间上限 ≥ 1.10 时，"差别不显著"不作为非劣的依据。
- **次要比较**（预先写定解释，不改变主判据）：SC 对 R17-like、M、M-S、U 的 Q_U；四个消融（H3）；Q_O；s = 2 的敏感性；资源代价。

## 7. 风险与局限

- **分支训练可能不稳定或无效**：状态分布的偏移可能伤害自然分布上的表现。先导直接检验它（SC 对 SC−B）。
- **规则可能难以超越**：EXP-011b 中 M+Y 优于 U。先导的关口 A 直接针对这一点。
- **R17-like 只是近似**：没有复制，不能代表标准机制的全部效果；忠实实现需要新的场景版本。
- **生存时间的取值**：s 的选择影响事件的稀少程度与结论；s = 2 作为敏感性。
- **事件稀少的统计功效**：中断在 20 秒的回合中很少（每个部署零到数次），Q_U 的区间可能较宽；评估切片取 512 个部署。
- **v2.0 的证据只是动机**：§1.3 的数值来自 v2.0 的已读切片，不作为本实验的结果。

## 8. 与框架的关系（提议框架第 4 版，另行批准）

- 核心表述从"紧迫状态摘要驱动的协调降低最差 UE 违约率"，改为"面向生存时间要求的分布式上行接入：一种面向关键状态的 MARL 方法"。
- 首要指标由 P2 改为 Q_U（最差 UE 的不可用度），P2 与全部 UE 的平均违约率降为 H4 的非劣检验指标。
- 紧迫摘要的链路与接收模型保留，内容改为生存状态。
- 以上需要单独修订框架文件，经用户批准；本设计只在框架批准后定稿。

## 9. 定稿时的决定（2026-10-14，用户按推荐全部采用）

1. **生存时间 s**：主条件 s = 1，敏感性 s = 2。阶段 4 的判据冻结前，对照 TS 22.104 的用例表核对。
2. **C3**：第 1 版为"每个造成或延长中断的违约代价 λ_s = 10"；第 2 版改为按中断时隙计，λ_d = 1（§3.2）。
3. **C4 的参数**：f_branch = 0.25，L_branch 为该 UE 之后 3 个周期；p_snap 与缓存大小在第 0 阶段写定（§10）。
4. **复制基线**：本实验只用 R17-like 近似，不另立场景 v2.2。
5. **关口 A 的门槛**：Q_U 比最好的规则对照与 M-S 都至少低 20%，P2 不高于 M+S 的 1.10 倍（第 2 版，§4.1）。
6. **U 进入全量实验**（阶段 2）。
7. **切片**：先导 1,400–1,655，评估 2,256–2,767。
8. **框架第 4 版**：按 §8 修订；修订稿在阶段 2 之前提交用户批准。阶段 0、1 是开发阶段，不依赖它。

### 10.2 核对

- **全部测试**：378 项通过（原 364 项加新增 14 项）；lint 通过。不使用新选项时，训练器、评估策略与评估记录的已有部分不变（原有测试照常通过）；EXP-008 至 EXP-011B 的六份切片清单重新生成后逐字节相同。
- **定义的一致性**：在一个 3,000 时隙的回合上，`SurvivalTracker` 逐时隙累计的中断时隙数与 `service_record` 由逐包记录算出的不可用时隙数逐 UE 相等（测试）。
- **分支回合**：恢复后的环境、生存状态与循环隐状态与快照相同；复制后继续运行逐位相同；带分支的训练中 PPO 的重放误差为 0（测试与冒烟训练）。
- **C3**：同一种子下，有无 λ_d 的第一个 rollout 动作相同，奖励之差等于中断的 UE-时隙数（测试）。
- **冒烟训练**（非正式，6 万时隙，两个运行并行）：SC 约 608 时隙/秒，M 约 657 时隙/秒；SC 在 34 次迭代中保存 2,592 个快照、产生 34 个分支回合。按此估计，先导每个 5M 运行约 2.5 小时。

### 10.3 实现中的澄清（不改变判据）

1. **C4 的 p_snap = 1.0，每个 N 保留最近的 64 个快照。** 分支回合短（3 个周期），f_branch = 0.25 时，估计约 4% 的环境时隙在分支回合中；分支中只有触发的 UE 处于关键状态，所以关键状态的样本比例只提高到自然比例的数倍。参数按第 1 版的决定不变；作用由先导的 SC 对 SC−B 检验。
2. **分支回合的随机性**：衰落沿用快照的未来（由种子确定）；动作采样来自训练器的随机流，与原回合不同。
3. **训练池与采样器**：在 v2.1 的训练池上训练；困难分层采样的门限 τ_N 沿用 EXP-009 在 v2.0 训练池上的取值（v2.1 只改变含近 AP UE 的部署）。
4. **best_local 在 v2.1 上的重新校准**移到阶段 2 之前完成：先导不使用 best_local，校准结果只在阶段 4 用到。
5. **关口 A 的 P2 参照**按第 2 版为 M+S；规则对照 M+S、M+Y、R17-like 都建立在同一种子的先导 M 上。
