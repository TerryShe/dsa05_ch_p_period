# 配置授权（CG）基线：部署中的半静态集中调度参照

状态：**已定稿（2026-10-09，用户批准；第 1 版）**。

- 下一步是第 0 阶段（§6）；第 0 阶段的实现提交并通过测试之前，不运行任何评估。
- 定稿前核对了 §3.6 引用的 NR 条款（§3.7），草稿中两处凭记忆写的内容都已证实，表述按条款原文改得更准确。

## 1. 为什么需要

**锚定**：2026-10-09 讨论后，用户决定信息阶梯以 5G NR 为参照系（方案 A），侧链模式 2（方案 C）保留为备选。每一级信息都对应一个 NR 机制：

| 级别 | 内容 | NR 对应 | 现有参照 |
|---|---|---|---|
| L0 | 本地观测（当前固定 OBS） | 无直接对应：上行由 gNB 调度 | 本地规则、学习策略 |
| L1 | 紧急度 | 高优先级 SR（Rel-16）+ 组公共取消指示（DCI 2_4） | 探针 B3，尚未正式 |
| **L2** | **周期与平均信道，半静态** | **TSCAI + 配置授权** | **缺失（本设计）** |
| L∞ | 所有 UE 的当前信道与队列，逐时隙 | 动态授权，信道与缓存上报 | N_EDF |

**缺口**：
- NR 部署周期确定性业务的方式是：核心网通过 TSCAI 告诉 gNB 突发到达时间、周期与生存时间，gNB 据此用配置授权、半持续调度或动态授权调度这类业务（TS 38.300 §16.8.1）。
- 现有参照只有两端：
  - N_EDF 逐时隙集中调度，知道所有 UE 的当前增益与队列，信令不计；
  - 本地规则与学习策略只用本地信息。
- 缺少"部署中实际使用"的半静态方案。期刊审稿人很可能问"为什么不用配置授权"。

**CG 的特点**：
- 每时隙零信令；资源独占，没有碰撞；
- 不能跟随衰落，没有选择分集，只能多占资源来换可靠性。

它与学习策略谁高，事先不知道。CG 的结果可能削弱"分布式"的论点，这一点需要尽早知道。

**方案 C 保留**：若之后需要一个部署中的分布式参照，可按侧链模式 2 的基于感知的半持续调度（SB-SPS）写一个本地规则。它与现有的周期预约规则接近，但多了感知。本设计不涉及。

## 2. CG 知道什么

| 信息 | CG | N_EDF | 理由 |
|---|---|---|---|
| 各 UE 的周期 P_i、包长 L_i、到达相位 φ_i | 知道 | 不直接用 | TSCAI 提供周期与到达时间 |
| 各 UE 的平均增益 ḡ_i（路损 × 阴影） | 准确知道 | 不直接用 | 设备固定；gNB 可长期平均 RSRP / SRS |
| 衰落的统计（近似 Rayleigh、Jakes f_D = 10 Hz、子信道间独立） | 准确知道 | 不用 | 链路自适应所需的信道统计 |
| 当前增益、实际衰落 | 不知道 | 知道 | 半静态，配置后不变 |
| 队列、其他 UE 的结果 | 不知道 | 知道队列 | 同上 |

- 平均增益与衰落统计都按"准确知道"处理，对 CG 有利。若学习策略仍超过它，结论更稳；若 CG 更高，结果略偏乐观，报告中注明。
- UE 一侧只用自己是否还有待发比特：没有数据就跳过该时机。

## 3. 配置

### 3.1 资源与配置形式

- **资源单元**：（时隙，子信道）。三类周期 10、20、40 的最小公倍数为 40，每 40 个时隙有 4 × 40 = 160 个资源单元，此后重复。
- **UE i 的配置**：一组时机 {(r, k)}，r ∈ {0, …, P_i − 1} 为时隙对 P_i 的余数，k 为子信道。
  - 同一 UE 的时机余数互不相同：每个时隙只能发一个子信道，所以每个周期最多 P_i 个时机。
  - 一个时机 (r, k) 占用的资源单元是 {(r + nP_i) mod 40, k}，共 40 / P_i 个：快类 4 个，中类 2 个，慢类 1 个。
- **独占**：任何资源单元至多分给一个 UE，所以没有同信道干扰。
- **窗口**：截止期为下一次到达，窗口正好一个周期。每个周期窗口中，UE 的每个时机恰好出现一次。所以包能否送达只取决于窗口内各时机累积的互信息，与时机的先后无关。

### 3.2 发送规则

每个时隙，UE 若还有待发比特，且本时隙是它的某个时机，就在该时机的子信道上以 23 dBm 发送；否则 OFF。

- 资源独占，没有干扰，也不计能耗，所以满功率总是最好。
- 包提前译码后，剩余时机空闲，也不能给别人用。这对应 NR 中 UE 无数据时跳过配置授权的时机。

### 3.3 分配：使最差 UE 的预测中断概率最小的贪心

**预测中断概率**：q_i(O) 是 UE i 在时机集合 O 下，一个包在窗口内累积的互信息低于 L_i 的概率。它按衰落统计计算（§3.5），O 为空时 q = 1。

**分配步骤**（确定性）：
1. 所有 UE 从零个时机开始。
2. 在还能再加一个时机的 UE 中，取 q_i 最大者，按 §3.4 放置一个时机：
   - q 相同时，取 m_i / need_i 最小者，其中 m_i 为已有时机数，need_i = L_i / E[每时隙互信息]，期望按 UE 自己的平均信噪比与衰落统计计算；
   - 再相同时，取序号小者。
3. 重复第 2 步，直到没有 UE 能再加时机：资源单元用完，或该 UE 已有 P_i 个时机。

**为什么不设可靠性目标**：
- 资源独占，没有能耗；分出去而用不上的时机，只是空着。
- 所以把全部资源分完不会伤害任何人。贪心本身不需要中断目标这一参数，也就没有可调的参数。
- 判据"最差 UE 的中断概率最小"与承载能力的口径一致：要求每个 UE 都满足 ε。

### 3.4 放置规则

给 UE i 加一个时机时，候选为满足 §3.1 约束的全部 (r, k)。按以下顺序选择：
1. **频率分集**：取 UE i 已有时机最少的子信道；
2. **减少碎片**：取 (k, r mod 10) 这一列中已被别的 UE 部分占用者。
   - 快类的时机要占满一整列，中类、慢类的时机只占一列的一半或四分之一；
   - 中类、慢类尽量填进已被部分占用的列，留出空列给快类。
3. **时间分集**：取在窗口内位置 (r − φ_i) mod P_i 上，与 UE i 在同一子信道上已有时机距离最小值最大者；
4. 取 (k, r) 字典序最小者。

报告中记录"总资源未用完、但某 UE 因碎片放不下"的次数，作为放置规则的损失。

### 3.5 预测中断概率的计算

- 用场景自己的衰落生成器（SoS，M = 32，f_D = 10 Hz，单位平均功率）预先生成一个样本库：S = 20,000 个独立实现，每个实现 4 个子信道 × 40 个时隙。
  - 样本库使用单独的种子基准 20,261,009，与协议 v2 的执行种子基准（20,260,930）、衰落种子基准（20,261,001）不同；
  - 每个进程生成一次，所有回合共用。
- q_i(O) 是样本库中满足 Σ_{(r,k)∈O} 1000 · log₂(1 + γ̄_i · |h_s[(r − φ_i) mod P_i, k]|²) < L_i 的样本比例。
  - 其中 γ̄_i = 23 dBm · ḡ_i / 噪声功率；
  - P_i < 40 时取每个实现的前 P_i 个时隙作为窗口（过程平稳）。
- 分辨率：S = 20,000 时，q = 0.01 附近的标准误约为 0.0007。

### 3.6 与 NR 的对应，以及理想化之处

| 方面 | NR | 本设计 | 对 CG 的影响 |
|---|---|---|---|
| 配置 | Type 1 配置授权：授权完全由 RRC 配置，不需要 DCI 激活 | 回合开始时配置一次，此后不变 | 一致 |
| 周期 | 15 kHz 常规 CP 下为 2、7 或 n × 14 个符号，n 的取值含 10、20、40；Rel-16 另有 periodicityExt（1–640 个时隙） | 等于业务周期 10、20、40 个时隙 | 一致 |
| 每周期多个时机 | Rel-16 起每个 BWP 最多 12 个配置授权，各有自己的偏移与频域资源；每个配置可重复 repK ∈ {1, 2, 4, 8} 次（连续时隙） | 每周期至多 P_i 个时机，位置任意 | 略宽松：慢类最多 40 个时机，位置不受连续重复的限制 |
| 跳频 | 一个配置内，时隙间跳频只在两个频率位置间交替（Type 1 的偏移由 frequencyHoppingOffset 给出）；不同配置可用不同的频域资源 | 可分散到全部 K 个子信道 | 对 CG 有利：需要多个配置才能实现 |
| 速率 | 固定 MCS，加重复与 HARQ 合并 | 理想的增量冗余互信息累积，与所有方法相同 | 对 CG 有利 |
| 信道统计 | 由测量估计 | 准确 | 对 CG 有利 |

各项理想化都偏向 CG，所以这个基线是部署方案能力的乐观估计。

## 4. 变体

| 变体 | 内容 | 地位 |
|---|---|---|
| **CG** | §3 全部规则 | 主参照 |
| CG-单信道 | 每个 UE 的全部时机放在同一个子信道：第一个时机按 §3.4 第 2–4 步选择，以后的时机只能放在这个子信道上（第 1 步改为这一限制）；该子信道放不下时，这个 UE 不再加时机 | 描述性：频率分集对 CG 的价值，对应不跳频的配置授权 |

两个变体都在定稿时写定，不在看到结果后增加或修改。

**第 0 阶段修正（2026-10-09，实现时发现，在任何评估之前；用户已于 2026-10-09 确认）**：
- **问题**：按上表的写法，CG-单信道的第一个时机按 §3.4 第 2–4 步选择。此时每个 UE 在第 1 步都打平（还没有时机），第 2、3 步也多半打平，于是按字典序取子信道 0。所有 UE 都挤在子信道 0 上，其余 3 个子信道空着，变体退化。
- **发现方式**：开发实例 0 的冒烟测试，时域缩短为 1,200 个时隙，只看分配，不看任何评估集。N = 8 时只分出 25% 的资源单元，8 个 UE 全部因放不下而关闭。
- **修正**：CG-单信道的第一个时机取**空闲资源单元最多、且放得下**的子信道（并列时取序号小者），其余步骤不变。修正后同一冒烟测试中，UE 分布在 4 个子信道上，资源单元全部分出。
- **主变体不受影响**，没有修改：它的第一个时机同样多落在子信道 0，但以后的时机按第 1 步分散到各子信道，冒烟测试中分出 99%–100% 的资源单元。

### 5.2 统计与报告

- **主表**：
  - 验证集上 CG、CG-单信道、N_EDF 与各本地规则的 F_{0.01}(N)、F_{0.05}(N) 与 N\*；

- **诊断**（描述性）：
  - 每个 UE 的时机数，按类别与平均信噪比分组；
  - 资源单元的分配比例与实际使用比例（提前译码后空闲的部分）；
  - 预测的中断概率与实际违约率逐 UE 对照，检查 §3.5 的预测是否准确；
  - 失败 UE 的类别、距离、阴影与时机数；
  - 碎片造成的放置失败次数。

### 5.3 预先写定的解读

以 exp010-eval512 上 N = 8 为主，验证集上的 N\* 为辅：

| 结果 | 条件 | 含义 |
|---|---|---|
| CG 越过门槛 | F_{0.01}(8; CG) ≥ 0.95，且 CG − A-mix 的 95% 区间下限 > 0 | 部署中的半静态方案已超过固定 OBS 下的学习策略。EXP-011 的目标要以 CG 为参照：分布式加 L1 须超过 CG，或以更少的信令接近 N_EDF；论文的论点需要相应调整 |
| CG 低于学习策略 | CG − A-mix 的 95% 区间上限 < 0 | 不能跟随衰落的损失大于分布式竞争的损失。CG 作为参照列入主表，EXP-011 按原计划起草 |
| 不能区分 | 其他情形 | 如实报告两者相当；EXP-011 同时以 CG 与学习策略为参照 |

这只是描述性的解读，不是假设检验。结果交用户确认后再决定下一步。

## 6. 第 0 阶段（批准后）

**代码**：
- `rules_v2.ConfiguredGrantPolicy`，在 `RULES` 中注册为 `configured_grant`，参数 `single_channel`（0 或 1）。
  - 新增可选接口 `configure(mean_gain_linear, traffic, fading)`；
  - `capacity.run_capacity_episode` 在 `reset` 之前，对实现了该接口的策略传入该回合的平均增益、业务（周期、包长、相位）与衰落配置（§2 的衰落统计，实现时加入）；
  - 另一个可选接口 `episode_diagnostics()`：回合结束后其结果存入回合记录的 `policy_diagnostics`，供 §5.2 的诊断使用；
  - 其他策略不受影响。
- 样本库与预测中断概率：同一模块，按进程缓存。
- 汇总脚本：两个集合的主表、配对差值与诊断。

**测试**：
- 任何时隙、任何子信道上至多一个 UE 发送；同一 UE 的时机余数互不相同。
- UE 只在自己的时机、且有待发比特时以最大功率发送。
- 贪心每一步取 q 最大者，平局规则正确；停止时没有 UE 能再加时机。
- 单个时机的 q 与 Rayleigh 的解析值 1 − exp(−(2^{L/1000} − 1)/γ̄) 相符，容差按样本库的有限 M 与抽样误差设定。
- 放置规则的四步在构造的例子上正确。
- 加入接口后，现有策略的回合结果逐位不变；冻结哈希不变；全套测试通过。

**运行**：
- `--formal`，在干净的已提交代码上运行；
- 验证集全网格与 exp010-eval512 的 N = 6、8、10。

## 8. 定稿时确认的决定（2026-10-09）

1. **CG 的知识**：周期、相位、准确的平均增益与衰落统计；不知道当前衰落与队列（§2）。
2. **分配规则**：使最差 UE 的预测中断概率最小的贪心，把资源分完，不设可靠性目标（§3.3）；放置规则（§3.4）。
