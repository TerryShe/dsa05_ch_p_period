# EXP-DSA05-009：固定 OBS 下的训练部署分布——静态困难分层与优先级部署重放

状态：**草案第 1 版，待用户审阅**。定稿前不实现、不训练、不读取新的筛选集或确认集。本实验的基线取决于 EXP-008 第 2 轮的结果（§2）。

## 1. 动机与问题

### 1.1 已有证据

1. **门槛区的失败集中在少数部署**（[第 0 步](../results/step0-failures_20261002/report.md)）：
   - 失败 UE 多为远端（距离中位数约 90 m）、阴影约 −9 dB 的快类与中类 UE；
   - 错过的包以干扰类为主；
   - 真正受物理限制的失败 UE，每个 N、每 400 个部署只有约 2 个。
2. **训练中几乎遇不到这类事件**（[EXP-008 第 1 轮](../results/exp008-round1_20261003/report.md) §5）：
   - N = 6 的训练 rollout 有 97–99% 没有违约，N = 8 为 93–97%；
   - 300 万时隙以后，在固定诊断 rollout 中，N = 6、8 每 12,800 个环境时隙只有 0–2 个违约时隙。
3. **只调整训练信号的权重没有用**（EXP-008 第 1 轮 §3、§5.2）：F1、F2 把更新方向转向门槛区，但门槛区可行率没有提高，F1 反而下降。

这三点合起来提出一个可检验的假设：**门槛区缺的不是信号的权重，而是训练分布中有信息的部署出现得太少。** 均匀抽样训练部署时，评估中决定 N\* 的那 5% 困难部署在训练中同样只占约 5%，其中真正产生违约的时隙更少。

EXP-008 第 1 轮无法区分"遇不到难部署"与"遇到了也学不会"。本实验改变训练部署的分布来区分二者。

### 1.2 研究问题

在执行 OBS、网络结构与更新规则都不变的条件下，只改变训练时抽取部署的分布：

- 静态的、与策略无关的困难分层抽样，能否提高门槛区可行率？
- 随策略变化的优先级部署重放（PLR），能否做得更好？用哪种得分更好？
- 选出的方法在独立确认集上能否提高 ε = 0.01 的容量点估计？

**范围**：
- 不新增 OBS、信令、辅助任务或逐 UE 信用分配；
- 执行 Actor 不接收部署编号、难度标签或 N；
- 难度与得分只存在于训练系统。

### 1.3 目标的含义

改变训练部署分布等于改变训练目标中各部署的权重。本实验**不做重要性加权**，明确把它作为课程或稳健训练的目标。评估分布不变：筛选集、验证集与确认集都按协议均匀抽取部署，所以任何收益都是在真实部署分布上测得的。

困难部署权重提高，可能伤害普通部署或低负载下的表现，因此保留 EXP-008 的退化保护（§5.2）。

## 2. 基线与不变的部分

- **基线 B**：EXP-008 的最终训练设置 B2。
  - 若 B2 = A-600（R0，即 EXP-006 的变体 A），对照直接复用 EXP-008 第 1 轮 R0 的两个运行（种子 101、202，已证实与 EXP-006 第 1 阶段逐位相同），不重训；
  - 若 B2 是其他条件，对照复用 B2 在 EXP-008 第 2 轮的两个运行，本设计各条件也改为在 B2 之上。
  - 在 EXP-008 第 2 轮结束之前，本设计不定稿。
- **不变**：
  - 场景 v2.0 与协议 v2 的冻结核心、训练池（只从 train 池 1,000,000–1,999,999 抽部署）；
  - 每个环境的 N 与 N 的混合（各 N 两个环境）、回合长度、PPO 与网络设置；
  - 预算：每个运行 500 万环境时隙；
  - 每次进入一个部署（包括重放）时，衰落与执行随机数都重新抽取。这样重放的是"同一个拓扑、阴影与业务相位"，而不是同一条衰落轨迹。
- **禁止**：把开发、验证、旧测试或任何确认集的实例放入训练，也不把在这些集合中发现的困难部署当作训练"种子"。

## 3. 条件

"部署"（level）= 训练池中的一个实例编号 i 在某个 N 下的拓扑、阴影与业务相位。每个 N 组（同 N 的两个环境）各维护自己的采样器，避免高负载的得分尺度压过低负载（文献笔记中的风险）。

| 代号 | 训练部署分布 | 依据 |
|---|---|---|
| U0 | 均匀抽样（对照，即基线 B 的运行） | 原设置 |
| S1 | 静态困难分层：每次以概率 q = 0.5 从该 N 的"困难层"抽取（拒绝抽样），否则均匀抽取 | 文献笔记建议的最小对照第 2 项；与策略无关 |
| P1 | PLR，原文得分：回合内 GAE 绝对值的平均（L1 value loss） | Jiang et al., ICML 2021，式 (2) |
| P2 | PLR，DSA05 得分：回合内最差 UE 的可避免违约率 | 本课题的扩展，不称为原文算法 |

### 3.1 S1 的困难层

- **难度标签**（训练侧，与策略无关，不含衰落）：
  - 对部署中每个 UE，计算大尺度服务裕量 m_i = c_i / r_i；
  - c_i 是该 UE 独自以最大功率发送时、按路径增益与阴影计算的每时隙香农容量；
  - r_i 是该 UE 每个时隙平均需要的比特数（包大小 ÷ 周期）。
  - 部署的难度 h = min_i m_i。
- **困难层**：h 低于该 N 的 10% 分位数 τ_N。
  - τ_N 在第 0 阶段用训练池中按固定种子抽取的 20,000 个实例计算，写入配置后冻结。
  - 它只用 train 池实例计算，不读取任何评估集合。
- **局限**：这个标签只反映"弱 UE"，不反映干扰协调的难度（同信道 UE 的数量与紧迫程度）。这正是 S1 与 P1、P2 对照的意义。

### 3.2 PLR 的共同设置（P1、P2）

- **重放决定**：每个回合开始时，以概率 p = 0.5 从该 N 的缓冲区重放，否则从训练池均匀抽取一个新部署；缓冲区少于 50 个部署时不重放。
  - 原文在有限训练集上让重放概率随已访问比例增加；在无限池上使用滚动的有限缓冲区（原文附录 B.3，尚未核对）。
  - 本实验的训练池实际上无限，固定的 p、缓冲区大小与最小填充数是**本设计的选择**，不是原文参数。
- **缓冲区**：每个 N 组最多 500 个部署。满了以后，新部署替换得分最低的一个；若新部署得分更低，则不进入缓冲区。
  - 按 R0 的预算，每个 N 组在 500 万时隙内约有 1,190 个回合；p = 0.5 时其中约 600 个是新部署，缓冲区能容纳其中的大部分。
- **重放分布**：P_replay = (1 − ρ) P_S + ρ P_C。
  - P_S：按得分排序的秩优先级，h(S_i) = 1/rank(S_i)，温度 β = 0.1；
  - P_C：按陈旧度 c − C_i 成比例；
  - ρ = 0.1。β、ρ 取原文 Procgen 主实验的值（§5.1）。
- **得分更新**：每个部署在每次回合结束后更新一次得分与时间戳。
  - P1 的得分要用回合中每个时隙的 GAE，而 GAE 在包含该回合最后一段的那次更新时才算出，所以得分晚一个 rollout 生效；
  - P2 的得分在回合结束时即可算出。
- **随机数**：
  - 新部署照旧用训练器原来的随机流抽取，因此 U0 的路径逐位不变；
  - 重放决定与重放抽样使用独立的随机流（由种子派生）。

### 3.3 P2 的得分

回合结束时，对每个 UE i：
- v_i 为本回合结算的违约包数；
- u_i 为其中物理上不可送达的包数，即在截止窗口内每个时隙都用最好的子信道、最大功率，独自也送不完，判据与 `capacity.undeliverable` 相同；
- M_i 为本回合结算的包数。

得分 S = max_i (v_i − u_i) / max(M_i, 1)。

**依据**：
- 第 0 步表明，门槛区失败以可避免的违约为主；
- PLR 原文的直觉是重放"在能力边界上"的部署，而只重放最失败的部署并不等于学习潜力（文献笔记 PLR 分析）；
- 扣除不可送达的包，避免反复重放怎么做都会失败的部署。

**局限**：
- 600 时隙的回合里，快类 UE 只有约 60 个包，得分很粗；多数回合的得分为 0，此时 P_S 的秩排序退化为并列。
- 并列的处理：并列者取平均秩，相当于在得分为 0 的部署之间均匀抽取。

## 5. 第 1 轮：筛选

### 5.1 运行

- S1、P1、P2 × 种子 101、202，各 500 万时隙，每 100 万时隙一个检查点，共 6 个新运行。
- U0 复用基线 B 的两个运行，不重训。
- 全部检查点在新筛选集上评估：(6 + 2) × 5 × 512 = 20,480 个回合。
- 选中模型在旧验证集上评估 N ∈ {2, 4, 6, 8, 10, 12, 16}：8 × 448 = 3,584 个回合。

### 5.2 保留与选择（沿用 EXP-008 §4.2 的五条规则，对照换成 U0）

1. 新筛选集上两个种子平均 ΔS_near ≥ 0.01，且每个种子的 ΔS_near ≥ 0；
2. 旧验证集上平均 F(4)、F(6)、F(8)、S_thr 的下降都不超过 0.01；
3. 400 万与 500 万检查点的末段平均 S_near 不低于 U0；
4. 旧验证集上 F(2) ≥ 0.95，且下降不超过 0.01；
5. 新筛选集上 F(6)、F(8) 各自的下降都不超过 0.01。

在保留的条件中取平均 S_near 最高者；与最高者相差不超过 0.005 时，按 S1、P1、P2 的顺序取较简单者，记为 M0。没有条件被保留时，本实验以负结果结束：不长训，不读确认集。

不做条件组合（例如 S1 + P2），也不在看到结果后调整 q、p、β、ρ、缓冲区大小或 τ。

## 6. 第 2 轮：长训与确认

- **长训**：M0 从头训练，种子 101、202、303，各 2,000 万时隙，每 200 万一个检查点；每个种子按新筛选集上的 (S_near, 时隙) 选模，同时报告最后检查点。
- **主基线 A-near9**：把基线 B 的长训检查点在新筛选集上补评，按同一规则重选。
  - 若 B = R0，即 EXP-006 三个长训种子的 30 个检查点，15,360 个回合；
  - 若 B 不是 R0，按其长训结果处理（EXP-008 §6）。
- **确认**：在 v2-confirm2 上，方法清单与分析脚本同 EXP-008 §7（`analyze_exp008_confirm.py` 换成新的集合名）。
  - **H1**：N\*_{0.01}(M) > N\*_{0.01}(A-near9)；
  - **H2**：F(8) 差值的 95% 区间下限 > 0，且 F(6) 差值的区间下限 > −0.01；
  - **H3**：N\*_{0.01}(M) > N\*_{0.01}(best_local)。
  - 判读表与 EXP-008 §7.3 相同，不另加成功条件。

## 7. 诊断（描述性）

- **采样器**：每个 N 的重放比例、缓冲区填充与得分分布、新部署与重放部署的比例、训练全程抽到的不同部署数、被重放次数最多的部署及其次数。
- **难度覆盖**：被训练的部署按难度 h 的分布（与均匀抽样比较），以及按业务类别和服务裕量分组的有包 UE 时隙数。
- **门槛区事件**：训练中 N = 6、8 的违约率、无违约 rollout 比例、固定诊断 rollout 中的违约时隙数与梯度投影份额，与 EXP-008 第 1 轮 §5 直接比较（同一诊断脚本与诊断种子）。
- **失败分解**：选中模型在开发实例 1,000–1,399 上重做第 0 步的分解，报告干扰类违约的绝对数、失败 UE 数与失败部署数。
- **过拟合检查**：选中模型在被重放最多的训练部署上（换新衰落）与在新筛选集上的可行率之差。

## 8. 风险与局限

- **训练更难不等于方法更好**：收益可能只来自"多见了难部署"。S1 是这一解释的对照；P1、P2 只有在明显优于 S1 时，才能说是随策略变化的优先级在起作用。
- **得分噪声**：P1 的得分在门槛区主要来自价值残差（EXP-008 第 1 轮 §5.1），可能无法区分真正有违约的部署。P2 得分粗、多数为 0。两者的失败都不能推广为"PLR 无效"。
- **分布偏移**：困难部署权重提高可能降低普通部署的表现。退化保护只覆盖 N ≤ 16 的选中模型；N ≥ 20 的变化在确认集上描述性报告。
- **预算与吞吐**：S1 的拒绝抽样与 P2 的不可送达判定会增加采集时间。比较按环境时隙对齐，同时报告墙钟时间。
- **与 EXP-008 的关系**：本实验在 EXP-008 的 B2 上做单一的分布改变。若 EXP-008 选出 C 或长回合，部署分布与这些因素的交互不在本实验内检验。

## 11. 需要用户决定的事项

1. **范围**：只改训练部署分布，不加重要性加权，明确作为课程或稳健训练目标。
2. **条件**：U0（复用）、S1、P1、P2 四个，不做组合。
3. **S1**：难度用大尺度服务裕量的最小值，困难层取每个 N 的 10% 分位数，q = 0.5。
4. **PLR**：p = 0.5、每个 N 的缓冲区 500、最小填充 50、β = 0.1、ρ = 0.1，每次重放都换新衰落。
5. **P2 得分**：最差 UE 的可避免违约率。
6. **集合**：新筛选集 exp009-screen256（开发池 3,000–3,255），确认集 v2-confirm2（备用池 30,500–30,999）。
7. **规则与判读**：沿用 EXP-008 的五条保留规则与 H1–H3，只换对照与集合。
8. **定稿时机**：等 EXP-008 第 2 轮确定 B2 后再定稿，以确定基线。
