## 研究问题

长期平均回报意义下的约束 MDP：最大化目标回报 V0，同时要求每个约束回报 Vi ≥ ci。作者提出两个观察：

- **O1**：存在一类约束问题，任何固定权重的奖励线性组合都无法诱导出满足约束的策略。例子是"监控问题"：智能体需要在两个区域分别停留规定比例的时间。
- **O2**：一般情况下，经典的原始—对偶方法不会收敛到最优的约束策略。原因是即使对偶间隙为零，也不一定能从最优对偶变量恢复出最优的原始策略。

## 方法

- **状态增广（A-CRL）**：把拉格朗日乘子 λ 视为 MDP 状态的一部分，策略写成 π(s, λ)。
- **训练（算法 1）**：在增广空间 S×Λ 上抽取 (s, λ)，用加权奖励 r_λ = r0 + Σ λi (ri − ci) 训练；任何强化学习算法都可以。目标是学到一个对所有 λ 都成立的拉格朗日最优策略族。
- **执行（算法 2）**：从 λ0 = 0 开始。时间分成长度为 T0 的时段；每个时段内用 π(s, λk) 执行，时段结束时按对偶梯度更新，λ_{k+1} = [λ_k − (η/T0) Σ (ri − ci)]₊。对偶动态在执行时持续运行，作用是在已学到的策略族之间切换。

## 理论结论

**定理 1**：若满足
- (A1) 存在严格可行的策略；
- (A2) 奖励有界；
- (A3) 时段内的累计奖励是价值函数的无偏估计（例如能从平稳分布采样），

那么按 λ_k 执行、并按上式更新 λ 所得的状态—动作轨迹**几乎必然满足约束**，期望回报与最优值相差不超过 η·B²/2。

定理保证的是轨迹层面的可行与近似最优，**不保证**某个固定的 λ_k 对应一个最优策略。因此必须在执行时持续运行对偶动态，不能在训练结束时把 λ 冻结。

## 实验

只有监控问题（第 IV 节），用策略梯度训练。实验展示了 A-CRL 能满足固定权重和标准原始—对偶方法都无法满足的比例约束。没有无线或多智能体实验。

## 与 DSA05 的关系

**相同**
- 变体 C 正是按 A-CRL 的思路设计的：μ_i 作为 Actor 输入，奖励中含 μ_i·c_i，执行时在线更新 μ_i。
- 我们的约束也是长期平均意义下的（每 UE 违约率 ≤ ε）。

**不同**
- A-CRL 是单智能体、全状态可观测。DSA05 有 N 个匿名 UE 共享同一个 Actor，每个 UE 只看到自己的 μ_i 和本地观测；联合"增广状态"包含所有 μ_i，但任何一个 Actor 都看不到全部。定理 1 不能直接套用。
- A-CRL 按固定长度 T0 的时段做平均后更新。我们在每次截止期结算时更新，步长为 η(c_i − ε)；更新频率随业务周期变化（P=10 的 UE 更新得比 P=40 的 UE 更频繁）。
- A-CRL 执行时 λ0 = 0。我们的 μ0 在验证集上从 {0, 5, 25} 中选定。第 1a 步中变体 C 选中的是 μ0 = 5，而 μ0 = 25 时 F 往往更高。这说明在有限的 1800 时隙评价窗口里，初始值确实有影响，与 A-CRL 的渐近论证不同。
- 训练时 λ 的抽样方式：A-CRL 在增广空间上抽样。我们在每个回合开始时让 μ_i ~ U[0, μ_max]，之后随回合演化。

**可借鉴**
- 论文里论证"固定惩罚（变体 A）为何不够"时，可以引用 O1 和 O2。不过第 1a 步中 A（w=10）实际表现很好，这个论点需要用我们自己的数据检验，不能直接照搬。
- 如果要做理论贡献，可以把定理 1 推广到"匿名多智能体、各自持有本地乘子、干扰耦合、事件触发更新"的情形。难点在于：每个智能体的策略只以自己的 μ_i 为条件，而约束通过干扰耦合在一起。
