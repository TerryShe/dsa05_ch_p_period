## 问题与方法

- 这是 Hou、Borkar、Kumar 的 "A Theory of QoS for Wireless"（INFOCOM 2009）框架的推广。那篇原文没有找到可下载的全文，这里记录的是本文第 IV 节对它的回顾。
- **模型**：AP 服务 N 个客户端，时隙化，时间分成长度为 T 的周期（帧同步）。每个周期开始时，每个客户端最多到达一个包。客户端 n 的包须在本周期的前 τ_n 个时隙内送达，否则丢弃。信道不可靠，时变的信道状态决定成功概率或所需时隙数。
- **QoS 要求**：每个客户端 n 有**交付率（timely-throughput）要求** q_n，即长期平均每周期按时交付的包数至少为 q_n。
- **结果**：
  - 静态信道、相同截止期时，一组要求可行，当且仅当对所有子集 S，Σ_{n∈S} w_n < T − E[I_S]（I_S 为只服务 S 时被迫空闲的时隙数）；
  - "最大债务优先"（largest debt first）类策略是**可行性最优**的：债务 = 应得的服务（按 q_n 累计）减去已得到的服务，每周期按债务从大到小排优先级；
  - 本文推广到时变信道、异构截止期与速率自适应，给出可行性最优的充分条件（"伪债务"）。

## 与 DSA05 的关系

- **DSA05 的约束就是交付率要求**：每 UE 违约率 ≤ ε 等价于按时交付率 ≥ 1 − ε。这是本课题在截止期调度文献中的"约束类型"定位。
- **"债务"与 DSA05 的逐 UE 对偶（变体 C）同源**：债务按要求累加、按实际交付扣减，与逐 UE 的虚拟队列 / 拉格朗日乘子的更新形式相同。可以用这条线说明变体 C 的动机：让欠账多的 UE 获得更高的发送优先级。我们的测试结果显示 C 并不优于固定惩罚 A，这也值得在讨论中联系起来。
- **主要差别**：
  1. 本文是 AP 集中调度（下行或轮询），一个时隙服务一个客户端；DSA05 是上行、完全分布式，UE 只看本地因果信息；
  2. 本文所有客户端同步于同一个周期 T；DSA05 的周期异构（10/20/40 ms）、相位异步；
  3. 本文的目标是可行性（支持尽可能大的要求向量），不计能耗；DSA05 的目标是满足要求前提下的最小能耗，还有功率控制与同信道干扰。
