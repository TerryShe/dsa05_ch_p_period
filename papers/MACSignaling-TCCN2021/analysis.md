## 论文实际做了什么

- 单 BS、单上行共享信道，碰撞与包擦除模型；UE 选择空闲、发送、删除队头包，同时选择上行消息。BS 是**固定专家**，解释 SR 并返回 SG / ACK。
- UE 学习何时使用既定消息、如何回应下行消息；采用带历史记忆的两个共享 Q 表，分别处理数据动作和信令动作。**本文不是 BS 与 UE 双端从零学习任意消息语义**；后者在 §V-A 被列为后续目标。
- 上下行控制链路明确假设专用、无误、无成本、无碰撞（§II-D）。目标为尽快送完并清除给定数量的包；没有逐包截止期、最差 UE 违约率、衰落下连续累积服务。
- §IV-D 已问收益来自接入策略还是通信，并用下行消息与下一步动作的互信息衡量即时协调。它报告该指标与性能相关，但这不是信息的因果效应证明。

## 与 DSA05 V2 rev3 的关系

**必读、必引，优先级 P0。** 它已覆盖“有限消息支持分布式 MAC 学习”及“分析信令对行为的影响”。所以 DSA05 不能以“首次学习响应控制信令”或“首次解释信令收益”为创新点。

当前 DSA05 的候选区别是：业务相关的逐子信道紧迫摘要、弱 UE 的截止期尾部保护、跨时隙服务，以及把摘要读出错误和资源成本纳入评价。与该论文相比，这些区别必须产生可复核的结果，不能只靠更复杂的场景。

## 对照与复现建议（本课题推演）

1. 保持 DSA05 的 MAPPO、训练预算与业务不变，比较无摘要、占用摘要、紧迫摘要和可学习比特。原文 Q 表仅适合微型验证，不应作为主要性能基线。
2. 学习响应与强制让路都使用相同消息、同样接收错误和时延；报告被保护 UE 与被推迟 UE 的代价。
3. 可报告消息与避让动作的互信息，但须增加消息隐去、置乱、替换及对照重训练；相关性可能由共享队列/信道状态引起，不能替代因果消融。
4. 清楚区分固定语义的可学习用法和自由学习消息内容。前者是本篇，后者参见 [Mota 2022](../ScalableMAC-VTC2022/analysis.md)。

## 使用限制

这是早期概念验证，主要训练场景只有 1–2 个 UE，表格方法训练可达数百万回合。不要把其“最优”措辞移植为 DSA05 的理论最优保证，也不要把原文的免费控制信道当作真实开销模型。
